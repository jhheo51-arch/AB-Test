## 전자책 소개

### 그래서, 이 캠페인 계속할까요?

**저자: 허재혁**

“어느 쪽의 숫자가 더 높은가?”에서 멈추지 않고, **그 결과를 믿을 수 있는지, 누구에게 적용할 수 있는지, 그래서 어떤 행동을 할지**까지 연결하는 CRM A/B 테스트 실무서입니다.

캠페인 결과를 해석하고 다음 실행을 제안해야 하는 CRM·마케팅 실무자, 분석 담당자와 판단 근거를 함께 정리하려는 독자를 대상으로 합니다. 교육용 합성 CRM 사례를 따라 실험 설계부터 결과 검토와 결정 기록까지 살펴봅니다.

**책에서 다루는 내용**

- **비교 가능한 실험 만들기:** 배정, 분석 단위, 분모와 관측 기간 등 결과를 해석하기 전에 확인할 조건.
- **평균 아래의 고객 읽기:** 전체 결과와 고객군별 결과를 구분하고 적용 범위를 검토하는 방법.
- **차이와 불확실성 이해하기:** 효과 크기, 신뢰구간, 유의확률과 필요한 정보량을 판단에 연결하는 방법.
- **회사에서 실행할 결정으로 옮기기:** 사업적 충분성, 고객 보호와 운영 조건, 다음 행동과 재검토 기준을 함께 기록하는 방법.

TRI-V는 저자가 기존 통계 원칙과 실무 판단을 연결하기 위해 제안한 프레임워크이며, 새로운 통계 검정법이나 현장 성과가 입증된 이론이라는 뜻은 아닙니다. 판단 기록 양식과 작성 예시도 함께 제공합니다.

## 도구 소개

### CRM A/B 테스트 작업실

**실험 결과를 가져와 차이와 한계를 확인하고, 자신의 판단 근거를 남기는 로컬 분석 앱**입니다. CRM 발송이나 고객 관리를 대신하는 플랫폼이 아니라, 외부에서 수행한 A/B 테스트 한 건의 검토에 집중합니다.

CSV나 표를 가지고 있지만 열 연결, 통계 결과 해석, 판단 기록과 공유 과정이 끊겨 있는 실무자를 대상으로 합니다.

가상 정기점검 사례에서 두 군의 입력값, 확대 기준, 보류 이유 네 가지를 바로 볼 수 있습니다. [공유 보고서 예시 보기](tool/app/examples/ROUTINE_SERVICE_ROLLOUT_REPORT.md)

**현재 할 수 있는 작업**

1. **자료 확인:** CSV·표 입력, 열 역할과 원본 A/B 값 연결, 입력 오류 확인.
2. **결과 분석:** 성공 여부·비율형 두 군 결과와 지원 조건을 충족한 집단별 비교.
3. **해석과 판단:** 관측 차이와 통계적 판정을 구분해 읽고, 검토 방향·근거·확인 조건·재검토 시점 작성.
4. **저장과 공유:** 방문 완료율과 수신 철회 기준으로 확대 여부를 판단하고, 수용량과 비용 확인 상태, 입력값과 보류 이유를 프로젝트와 HTML/PDF 보고서에 기록합니다.
5. **선택적 설명:** 별도 설정과 동의 후 LLM에 최소 판정 상태를 전달해 설명 요청. 계산 자체는 LLM이 수행하지 않습니다.

기본 계산은 브라우저 안에서 처리합니다. 시연 영상은 앱 안에서 열고 닫을 수 있어 입력하던 작업을 이어갈 수 있습니다. 자동 적용 승인을 내리거나 고객 목록을 만들어 발송하지 않습니다.

**아직 지원하지 않는 것:** 자유로운 상황 설명에서 후보·실험 계획을 생성하는 전체 설계 대화, 시간·금액·순차·군집 분석, CRM 고객 관리·발송 운영. 책에서 설명하는 모든 방법이 앱에 구현된 것은 아닙니다.

[도구 안내](tool/README.md) · [새 실행 ZIP](https://github.com/jhheo51-arch/AB-Test/releases/download/tool-rollout-report-20261123/AB_Test_Workspace_rollout_report_20261123.zip) · [시연 영상](tool/app/help/walkthrough.mp4) · [지원 범위와 실행 방법](tool/app/README.md)

**책과 도구의 관계:** 책은 실험과 판단의 기준을 설명하고, 도구는 그중 현재 지원하는 입력·계산·기록 절차를 실행하도록 돕습니다. 계산 결과가 실제 적용 승인이나 현장 효과의 증명을 대신하지는 않습니다.

## 처음 방문하셨나요?

- **책 읽기:** [전자책 PDF](e-book/ebook.pdf) 또는 [웹 읽기본 HTML](e-book/ebook.html)을 내려받으세요. HTML은 `e-book/assets/`도 함께 같은 상대 위치에 둡니다. GitHub 파일 페이지는 앱이나 HTML 실행 화면이 아닙니다.
- **도구 사용하기:** [새 실행 ZIP](https://github.com/jhheo51-arch/AB-Test/releases/download/tool-rollout-report-20261123/AB_Test_Workspace_rollout_report_20261123.zip)을 내려받아 압축을 풀고 `launch.cmd`를 실행하세요. Windows와 Python 3가 필요합니다. 실행 창에 표시된 로컬 주소를 Chrome/Edge에서 엽니다. [실행 안내](tool/app/README.md)
- **사용법 보기:** [시연 영상 MP4](tool/app/help/walkthrough.mp4)를 내려받거나, 실행한 앱의 **시연 영상 보기**를 누르세요. GitHub에서 바로 재생되지 않으면 파일 페이지의 다운로드 버튼을 이용하세요.

기본 CSV 확인·통계 계산은 LLM 없이 사용할 수 있습니다. 선택 기능인 LLM 설명에는 별도의 Hermes 설치·프로필·모델 인증 설정이 필요하며, 연결 설정과 이용 비용은 사용자 환경에 따릅니다. 자유로운 자연어 설계 대화는 아직 제공하지 않습니다.

## 보관 원칙

- 전자책은 GitHub 현재 트리에 버전 표시 없는 최신본 한 세트만 둡니다.
- 이전 판과 제작 입력, 원자료 및 감사 기록은 로컬에 보존하고 Git 추적에서 제외합니다. 기존 Git 커밋 이력은 지우거나 재작성하지 않습니다.
- 본문은 재개발하지 않고 실제 오류와 읽기 장애만 최소 수정합니다. 출판과 판매는 진행하지 않습니다.
- 전자책 사례는 교육용 합성 자료입니다. AI 검수 및 자동 검사와 실제 독자시험 또는 현장 효용은 다릅니다.
- 도구는 실험 한 건의 설계와 분석을 다룹니다. 고객 DB 관리나 실제 발송 및 범용 CRM 플랫폼으로 확장하지 않습니다.

## 이용 조건

저장소 공개는 프로젝트 전체에 오픈소스 라이선스를 부여한다는 뜻이 아닙니다. 재사용·수정·재배포 전 자료별 이용 조건을 확인하세요. 포함된 글꼴·라이브러리에는 각각의 라이선스 고지가 적용됩니다. 프로젝트 전체의 별도 라이선스는 아직 지정하지 않았습니다.
