## 시각 편집

본문 각 장은 PDF에서 새 쪽에 시작하며, 웹 읽기본에서는 구분선과 간격으로 나눕니다. 표지의 중복 방법론 표기를 정리하고 완료 효과, 철회, 기록 대사, 고객군, 공유 용량의 다섯 데이터 그림을 다시 구성했습니다. 본문과 통계표의 내용은 유지했고, 목차와 색인 쪽수 및 PDF 링크는 새 조판에 맞췄습니다.

## 두 가지 읽기 경로

- **이어 읽는 실무 본문:** 서문과 전체 장에서 같은 실험의 질문, 근거와 판단문이 달라지는 과정을 따라갑니다.
- **찾아 읽는 통계 참고 해설:** [실무 질문별 안내](ebook.html#practical-question-index)에서 시작하거나 [용어와 약어 색인](ebook.html#term-index)을 이용하세요. 핵심 개념 36개가 질문, 정의, 사용 조건, 결과 해석, 오해 방지, 보고 문장과 관련 개념 및 계산 근거를 설명합니다.

전권 편집과 AI 의미 대조, 실제 Chrome 독서 기능 및 PDF 조판 검사를 수행했습니다. 이는 새로운 통계 재계산이나 실제 사람의 독자시험이 아닙니다. 기본 계산 자료와 그림, 글꼴 및 별도 판단 기록 양식은 유지했습니다.

GitHub 현재 트리에는 버전 번호 없는 최신 한 세트만 보관합니다. 이전 판, 원자료, 제작 입력과 감사 기록은 로컬 보관 대상이며 삭제하지 않습니다. Git의 기존 커밋 이력은 재작성하지 않았습니다. 본문에 나오는 실험 계획과 데이터의 버전 표기는 근거 식별자이므로 유지했습니다.

HTML을 내려받아 읽을 때는 assets 폴더도 같은 상대 위치에 둡니다. Markdown 그림은 figures 폴더를 사용합니다. 글꼴과 라이브러리의 이용 조건 고지는 assets에 보존합니다.

저자 요청에 따라 서문과 전체 장의 서술을 개정하고, 기존 핵심 개념을 독립적으로 찾아 읽을 수 있는 통계 참고 해설로 확장했습니다. 본문의 기존 실험 수치와 통계표, 코드, 각주와 자료 경계는 보존했습니다. 사례의 고객과 성과는 교육용 합성 자료이며 실제 독자시험, 독립된 사람의 감수 및 현장 효용 입증을 완료한 것은 아닙니다. 기존에 공개한 계획 파일의 줄바꿈에 따른 역사 해시 차이도 해결된 것으로 바꾸지 않았습니다.

표지와 본문 강조색은 현대오토에버 [공식 로고 SVG](https://www.hyundai-autoever.com/common/images/typea-logo.svg)와 [공식 웹사이트 CSS](https://www.hyundai-autoever.com/common/css/common.css?ran=20260701)의 색을 참고했습니다. 회사 로고나 워드마크는 사용하지 않았으며, 색상 참고는 회사의 공식 발행이나 후원을 뜻하지 않습니다. 일부 중립색과 옅은 배경은 읽기 대비를 위한 제안값입니다. 별도의 판단 기록 양식은 기존 기능과 배포 바이트를 유지했습니다.

파일 무결성은 저장소 루트에서 `python scripts/check_latest_ebook.py`로 확인합니다. 이 검사는 본문의 통계 재감수나 실제 독자시험이 아닙니다.
