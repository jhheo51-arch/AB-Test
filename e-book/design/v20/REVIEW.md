# v0.20 편집 검토

저자가 지정한 세 단계의 실제 적용을 완료했다. 이 판은 97쪽 저자 검토본이며, 최종 출간 승인본이 아니다. 상세 전후와 실행 범위는 DEVELOPMENT.md, 순서 재생은 MANUSCRIPT_CHANGES.json과 integration_validation_v20.json을 따른다.

## 편집 판단

반복 설명 열 곳을 압축한 뒤, 2~4장에서는 같은 설계 기록에서 비교 조건과 적용 범위, 현재 행동이 어떻게 바뀌는지 연결했다. 이 예시는 결과 전 계획 단계라고 명시해, 아직 관측하지 않은 효과나 실제 발송 승인을 꾸미지 않았다. 원래의 주된 통계 설명과 여섯 사례는 유지했다.

8장에서는 문제를 읽을 때 이미 보이던 판단 열과 분류를 제거하고, 필요한 설계 조건은 먼저 제시했다. 10장에서는 유지할 근거와 다시 열 근거를 선택한 뒤 기존 해설과 새 피드백을 대조한다. 새 통계나 필수 작성 항목을 늘리는 대신 기존 과제의 순서와 질문을 바꾼 개발이다.

내용을 압축했으므로 책 전체가 더 짧아졌다고 말하지 않는다. 대상 문단은 2,558자에서 1,641자로 줄었지만 연결 예시와 과제를 보강해 전체 판은 95쪽에서 97쪽이 됐다. 학습 향상은 실제 수행시험으로 확인해야 한다.

## 실제 확인

정식 PDF 조판, 등록된 세 단계의 순서와 본문 재생, 보존 입력과 장 및 완성문, 기존 수치 문자와 읽기 전용 SQL, 표지 및 그림의 계산된 경계와 정렬, 실제 각주와 쪽수 및 탐색 검사를 통과했다. 새 텍스트 위치를 찾아 개별 페이지 이미지를 생성했고 일부 변경 판면을 실제로 확인했다. 완성 결정문은 79쪽 한 면이다.

이는 AI 지원 편집과 기술 검사다. 새로운 전체 통계 추론의 재실행, 독립적인 사람 검수, 실제 독자 수행시험이나 전권 시각 전수 심사가 아니다. 과거 차단된 PDF 인용 전수 대조와 전권 contact sheet 재생성은 실행하지 않았다. 계산 값과 그림을 유지한 사실이 실제 현장 효용을 입증하지도 않는다.

## 남은 범위

서로 다른 설계와 원자료를 구별하는 독자의 실제 수행, 일부 절 끝과 표 및 결정문 주변 여백, 저자의 최종 문체, 역사적 계획 동결의 증거 수준, 권리와 최종 제출 규격은 별도로 확인해야 한다. 이번 세 단계 이외의 6장 재구조화와 11장 저자 목소리 전면 개작은 실행하지 않았다. 기존 작성 양식과 보조 계산 자료도 이전 판의 보존본이다.

v19 원자료와 이번 개정의 기준 바이트는 보존했다. 후속 GitHub 반영 요청에서는 원격 폴더 정리 이후의 경로를 별도 대응표로 연결하고, 바뀐 메타데이터와 생성 코드의 원래 바이트는 동결 사본으로 남겼다. 본문과 PDF는 수정하지 않았다.
