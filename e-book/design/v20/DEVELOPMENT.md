# v0.20 실제 개정 내역

## 적용 순서와 범위

저자가 지정한 순서인 반복 설명 압축, 2~4장의 같은 기록 연속 수정, 기존 연습의 판단 전이 강화를 그대로 적용했다. v19를 읽어 세 장부를 차례대로 재생했으며 원고와 PDF 및 읽기 묶음, 원자료와 계산 장부는 보존했다. 이 판의 최초 제작은 로컬에서 완료했다. 이후 저자의 GitHub 반영 요청에 따라 원격의 폴더 정리를 보존하며 배포 경로와 동결 입력의 연결을 조정했다. 본문과 PDF는 바꾸지 않았고 외부 제출은 하지 않았다.

| 단계 | 실제 반영 | 확인 근거 |
|---|---|---|
| 1. 반복 설명 압축 | 9장 세 문단, 10장 두 문단, 12장 다섯 문단을 압축했다. 대상 문단 합계는 2,558자에서 1,641자로 줄었다. | 01_COMPRESSION.json과 MANUSCRIPT_CHANGES.json의 첫 단계 |
| 2. 같은 기록 연속 수정 | 2~4장의 일반적인 산출물 안내를 같은 JH Motors 설계 기록을 고쳐 쓰는 예시로 바꿨다. 비교 명세, 적용 범위, 현재 행동이 이어진다. | 02_GUIDED_RECORD.json, 실제 PDF 16~17쪽과 18쪽, 20쪽 |
| 3. 판단 전이 강화 | 8장 문제 표의 답을 드러내는 분류와 판단 열을 뒤 해설로 넘겼다. 필요한 사전 설계 정보는 문제 앞에 두었다. 10장에서는 참조할 근거와 다시 열 근거를 먼저 고르고 해설에서 판단 이유를 대조하게 했다. | 03_TRANSFER.json, 실제 PDF 53~54쪽과 61쪽, 65쪽 |

문자 수는 해당 장부의 교체 대상 문자열을 공백과 문장부호까지 포함해 센 값이다. 책 전체를 그 비율만큼 줄였다는 뜻은 아니다. 연속 수정 예시와 과제를 보강해 정식 PDF는 v19의 95쪽에서 v20의 97쪽이 됐다. 쪽수 증가는 품질이나 학습 효과의 증거로 사용하지 않는다.

## 1. 정의를 다시 설명하기보다 문장을 고치게 했다

p값과 신뢰구간의 기본 설명은 5장, 검정력 설명은 6장에 남겼다. 9장에서는 정의를 다시 외우게 하는 대신 성공 확률로 잘못 쓴 문장과 효과 없음 또는 안전으로 단정한 문장을 어떻게 고칠지 안내했다. 10장은 기록의 층위를 압축했고, 12장은 역할별 요청과 완성문 전 안내의 반복을 줄였다.

통합 검토에서는 C03이 비열등성 한 방식만 의무화하는 것으로 읽히지 않도록 평가 표현을 조정했다. 하위 집필 단계의 글자 수와 검사 기록은 초기 장부 메모로 보존하고 최종 적용 장부와 구분했다. 이는 AI 지원 편집과 의미 대조이지 사람의 통계 승인이나 독립적인 전체 통계 재계산이 아니다.

## 2. 같은 설계 기록을 세 장에서 이어 쓴다

출발점은 편의 안내를 모든 고객에게 보내려는 교육용 기획 초안이다. 실제 결과가 나온 보고문이 아니다.

정화에서는 연락 동의와 적격 대상, A와 B 및 H의 비교, 배정 전체 분모와 개인별 관측을 정한다. 해체와 입체화에서는 현재 전체 범위와 새로운 고객군 정책의 질문을 구분한다. 언어의 전환에서는 효과를 확인한 척하지 않고 설계 준비와 도입 조건, 승인 여부를 구분한다. 기존 여섯 항목 안에서 기록이 바뀌므로 새 양식이나 추가 축을 만들지 않았다.

## 3. 판단할 정보와 해설을 나눴다

8장에서는 조건 가부터 라까지의 계산 결과를 유지하면서 문제 단계에 제시되던 현재 판단을 제거했다. 사전 고객군의 주장과 보정 수준, 다른 집단의 카운트 등 필요한 설계 정보는 해설에서 문제 앞으로 옮겼다. 조건을 모른 채 답을 고르게 하는 문제가 아니다. 이 이동은 숫자 토큰의 다중집합 보존으로 검사했으며 순서 불변 검사라고 보고하지 않는다.

10장에서는 슬롯이 늘었다는 요청만으로 무엇을 참조하고 무엇을 다시 확인할지 먼저 고르게 했다. 해설은 과거 결과를 모두 버리거나 즉시 확대하는 양자택일 대신, 어떤 추가 답이 현재 선택을 바꿀지와 답의 첨부가 승인은 아니라는 경계를 대조한다. 해설과 같은 문장이나 보류라는 단어를 썼는지만 평가하지 않는다.

## 유지한 것

- TRI-V의 세 축과 여섯 항목, 제목 구성과 기존 디자인을 유지했다. 표지는 판명만 0.20으로 바꿨다.
- 본문 1장, 5장, 6장, 7장과 11장은 탐색 앵커와 판명 파일 경로를 제외한 내용 보존 검사를 통과했다.
- 여섯 사례와 다섯 정량 그림의 기존 값은 바꾸지 않았다. 새 통계 추론은 하지 않았다.
- 개별 결과의 비교 가족과 구간 수준, 사전/사후 지위, 보호 의무와 실제 승인 구분을 유지했다.
- 완성 결정문 원문은 그대로 보존하고 실제 PDF 79쪽 한 면에 유지했다.
- 실제 하단 각주 여덟 개와 용어 서른여섯 개, 검색과 왕복 링크를 유지했다.

## 실제 실행 결과

- 정식 빌드: 97쪽, 본문 및 각주 12pt, 본문 그림 13개.
- 통합 검사: 506건 통과. 세 단계 순서와 정확 재생, 동결 입력 64개, 보존 장과 완성문, 수치 이동, 정량 그림 및 탐색을 포함한다.
- 기존 수치 문자: 103건 통과. 집계 SQL은 기존 DB를 읽기 전용으로 열어 장부와 대조했다.
- 기존 정량 그림 다섯 파일의 바이트 일치와 표시값을 대조했다. 그림과 표지의 계산된 글자 경계와 정렬 검사를 통과했다.
- 새 텍스트 위치 여덟 곳을 실제 PDF에서 찾아 개별 페이지 이미지를 생성했다. 그중 16쪽과 18쪽, 53쪽과 65쪽 및 79쪽을 실제 이미지로 확인했다. 전권의 인용 또는 시각 전수 심사는 아니다.
- 지정 판면의 하단 남는 높이 중앙값은 약 13.19mm, 90백분위는 36.34mm다. 일부 절 끝과 표, 한 면 결정문에는 여백이 남는다. 총 흰 픽셀 비율을 뜻하지 않는다.

원본의 역사적 동결 시각을 독립적으로 입증하는 문제, 저자 목소리 추가 편집과 실제 독자 수행시험은 이번 세 단계의 완료와 구분한다. 사람의 최종 교정과 통계 검수, 권리 및 출간 승인도 남아 있다. 과거 차단된 추가 PDF 인용 전수 대조와 전권 contact sheet 재생성은 수행하지 않았다.
