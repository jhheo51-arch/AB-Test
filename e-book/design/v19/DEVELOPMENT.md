# v0.19 실제 반영 내역

## 제목과 표지

장르 표시는 ‘CRM A/B 테스트 실무’, 제목은 ‘그래서, 이 캠페인 계속할까요?’, 부제는 ‘TRI-V로 근거를 점검하고 적용 범위와 다음 행동을 정하는 법’, 저자는 허재혁이다. 바로 앞 종합 답변의 최종 권고를 적용하라는 저자 요청에 따른 구성이다. 초기 제목 교체 후보를 적용한 것이 아니다.

질문형 제목을 버리는 대신 무엇을 다루는 책인지 먼저 읽히게 했다.
TRI-V는 표지의 부제와 별도 큰 표기로 드러내되 새 통계나 실행 보장으로 약속하지 않았다.
본문은 독자가 직접 쓸 문장과 전문 검토 및 실제 승인을 구분하는 방향으로 맞췄다.

| 표지 및 판면 토큰 | 전 | 후 | 근거 |
|---|---|---|---|
| 장르 문구 | CRM A/B 테스트 실무서 | CRM A/B 테스트 실무 | 저자 진행 승인 |
| 장르 글자 크기 | 26 | 48 | 두 판 cover_A.svg의 font-size. SVG 좌표 단위이며 pt가 아님 |
| 제목 구성 | 세 줄, 91 | 두 줄, 84와 104 | 두 판 cover_A.svg |
| 부제 | 차이를 읽고, 실행할 범위를 정하는 법 | TRI-V로 근거를 점검하고 적용 범위와 다음 행동을 정하는 법 | 승인된 추천 구성 |
| 표지 색 | 종이 #F5F1E8, 글자 #142D32, 강조 #125E59, 보조 #4F625F | 유지 | 기존 책의 디자인 제안이며 회사 공식 브랜드 규정이 아님 |
| 본문과 각주 | 12pt | 유지 | 실제 렌더 검증 |
| 판면 | 190×270mm, 여백 위14/오른쪽15/아래16/왼쪽15mm | 유지 | 실제 렌더 검증 |
| 새 대조표 열 폭 | 내용에 따른 자동 배분 | 16% / 45% / 39% | 첫 열이 지나치게 좁아지는 문제를 실제 판면에서 확인해 수정 |

계산한 세 글자색과 표지, 흰 본문, 표 머리 배경의 아홉 조합은 본문 AA 4.5:1과 큰 글자 AA 3:1을 모두 통과했다. 예를 들어 기본 글자와 흰 본문은 14.47:1, 강조와 표지는 6.72:1, 보조 글자와 표지는 5.74:1이다. 이 계산은 전자책 전체의 접근성 인증이 아니다.

## 문제 1. 쉬운 설명과 혼자 완수한다는 기대 사이의 간극

전에는 기본 개념의 설명과 검정 구현, 교정 이력을 같은 흐름에서 읽어야 했다. 이번에는 서문에서 독자가 직접 쓰는 비교 명세와 결과 보고문 및 현재 선택을 설명하는 기록을 먼저 구분했다. 분석 적정성, 고객 보호 평가와 실제 발송 승인은 해당 역할과 확인한다.

5장, 6장, 7장, 8장, 10장, 12장의 독립 문단 11개를 독자용 설명으로 바꿨다. 기존 기술 문단은 부록 A의 ‘분석 담당자와 확인할 계산 방법’에 원문 그대로 보존했고 본문에서 링크했다. 핵심 수치와 비교 가족, 신뢰수준, 사전과 사후의 지위, 비유의와 안전의 차이는 본문에서 지우지 않았다. SQL 코드와 표 자체를 전부 부록으로 옮긴 것은 아니며, 직접 실행을 선택 읽기로 안내한 부분도 있다.

## 문제 2. 정상적인 A/B 절차에 TRI-V가 무엇을 더하는지 불분명함

1장에 ‘이미 있는 근거와 참조할 것’과 ‘현재 비어 있어 추가 확인할 것’을 나란히 놓은 여섯 행 대조표를 추가했다. 기존 여섯 항목을 늘리지 않고, 원 계획을 다시 작성하지 않아도 되는 부분과 선택에 연결해야 하는 미확인 조건을 나눴다. 최종 대조표는 PDF 13쪽에 있다.

첫 집필본은 JSON 필드명을 표 안에 나열했다. 실제 판면 검토 후 이를 완료 비교 목록, 주지표, 지속 배정, 비용 가정과 모형 한계 등 실무 언어로 풀어 썼다. 필드 대조의 근거는 아래와 같다.

| 최종표에서 부르는 근거 | 실제 원 계획의 필드 |
|---|---|
| 완료 비교 목록 | confirmatory_family |
| 배정 고객당 28일 완료 | primary_metric |
| 고객별 지속 배정 | design |
| 완료 비교 보정 | family_alpha, multiplicity |
| 철회 보호 관측 | roles.opt_out |
| 적격 대상 | eligibility |
| 탐색 계약과 합성 재무 결과 | roles.contract, roles.net_contribution |
| 비용 가정과 모형 한계 | economics_assumptions, limitations |
| 로컬 동결 상태에 대한 기록 | actual_pre_registration_status |

원 계획의 동결 주장을 결과 전 동결 시각을 독립적으로 입증한 증거로 바꾸지 않았다. 적절한 표준 절차에서도 같은 결론에 도달할 수 있으며, 기존 기록에 연결까지 있으면 참조하면 된다고 본문에 명시했다. 누락이나 시간의 감소를 실제 입증한 결과는 아니다.

## 문제 3. 판단문은 있지만 회신 이후 어떻게 고치는지 충분히 보이지 않음

9장에 요청, 고의 오류 회신, 재질문, 수정 회신, 같은 여섯 항목의 수정, 최종 판단문으로 이어지는 교육용 사례를 추가했다. 오류 회신 직후 고의 교육용 오류임을 밝히고, 완료 우위와 철회 안전 미확인, 실제 비용 및 운영 승인 미정을 유지했다. 새 현장 일화나 실제 승인을 만들지 않았다.

사례는 PDF 59~60쪽에서 읽을 수 있다. 10장에는 회신을 재사용하는 경계를, 12장에는 미확인 조건을 기존 완성 결정문과 연결하는 문단을 넣었다. 완성 결정문은 PDF 77쪽 한 면에 유지된다. 합당한 보류를 미완성으로 취급하지 않고, 어떤 근거가 도착하면 다시 판단하는지까지 닫았다.

## 실제 검증과 남은 범위

- 프로토타입이 아닌 정식 빌드로 PDF 95쪽을 생성했다.
- 등록된 본문 교체와 삽입의 정확 재생, 과거 판과 원자료 해시, 그래프의 기존 값, 각주와 탐색 등을 다루는 통합 검사 486건을 통과했다.
- 기존 수치 문자 103건과 읽기 전용 DB의 집계 SQL을 대조했다. 새로운 전체 통계 분석이나 독립 통계 검증은 아니다.
- 표지와 본문 그림 13개의 계산된 글자 경계, 중심 정렬과 지정 영역 검사를 통과했다. 실제 독자 이해를 검증한 결과는 아니다.
- 실제 하단 각주 8개, 용어 36개, 목차 쪽수, 웹 읽기본의 검색과 작은 화면 가로 넘침을 확인했다.
- 하단 남는 높이의 중앙값은 지정 판면에서 12.67mm, 90백분위는 34.75mm였다. 모든 쪽의 여백이 작아진 것은 아니며, 표와 결정문을 묶은 쪽 및 절 끝의 여백은 남아 있다. 총 흰 픽셀 비율을 측정한 값은 아니다.
- 표지와 변경 구간을 실제 이미지로 확인했다. 과거 동의 차단된 추가 PDF 인용 전수 대조와 전권 contact sheet 재생성은 수행하지 않았다.
- 실제 독자 수행시험, 사람의 통계 검수, OEM 현장 검토, 권리 검토와 최종 출간 승인은 남아 있다.

이 문서는 v19 변경 구간 중심의 편집 판단과 실행 기록이다. v19 전권을 대상으로 한 새 독립 페르소나 시험이나 출판 적합성 보증이 아니다.
