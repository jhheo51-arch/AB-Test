최종 읽기본은 97쪽이다. 완성 결정문은 이전 판과 문구가 같고 물리 79쪽 한 면에 남는다. 기존 v20 출력과 제작 입력 62개는 SHA-256으로 보존을 확인했다. 편집 5건의 원고 문자 수 합계 변화는 -34자다. 숫자는 유도형 질문 표지 1, 2, 3의 삭제 외에 다중집합이 같으며, 6장의 표 내용과 코드 및 각주를 보존했다. 기존의 정량 계산을 새롭게 바꾸거나 통계적 효율을 입증한 작업이 아니다.

## 조판 조정

첫 조판에서는 결정문이 78쪽으로 당겨졌다. 빈 쪽이나 큰 빈칸을 넣지 않고, 6장 인쇄 본문의 행간만 1.62에서 1.68로 조정했다. 다른 장과 웹 본문의 기본 행간, 12pt 본문, 판면과 여백은 유지했다. 최종 PDF는 97쪽이며 텍스트가 빈 쪽은 없다. 표본 수와 비교 조건의 숫자는 바꾸지 않았다.

## 색과 상호작용

기존 v20 읽기본과 작성 양식의 색과 글꼴을 이어 썼다. 새 대화상자는 ReaderSans를 사용하며 대화상자 안쪽 간격 16px와 조작 간격 12px는 이 기능을 위한 구현 제안이다.

|---|---|---:|---|
| #142D32 | #FFFFFF | 14.471213647545033:1 | 통과 |
| #4F625F | #FFFFFF | 6.471952140609518:1 | 통과 |

대비는 mira_contrast로 계산했다. 새 제어와 안내는 보통 글자 4.5:1 기준을 통과한다. 기존 벡터 그림은 원래 크기로 열며 모바일에서 그림 안을 스크롤한다. 닫기와 Esc, 포커스 제한, 실제 스크롤 복귀를 검사했다. 대비 검사는 전체 접근성 인증이 아니다.

## 실행 결과와 한계

- 정식 Chrome/Paged.js 조판, 쪽수와 PDF 내부 링크, 각주 8개의 호출 쪽 및 실제 표지 번호, 13개 그림 인쇄 글자 크기 검사를 통과했다.
- 기존 수치 문자 검사와 읽기 전용 SQL 검사를 새 원고에 실행했다. 이는 원자료 통계 전체 재감사나 독립 사람 검수가 아니다.
- 확대와 위치 복귀 26개 조합, 실제 클립보드 쓰기와 읽기, 복사 차단 대체 동작, 실제 다운로드의 한글과 줄바꿈 및 여섯 항목 보존 검사를 통과했다. 자동 저장과 외부 전송은 추가하지 않았다.
- 새 판 통합 검사 82개는 이 변경의 보존 및 실행 범위다. 이전 판 506개와 동일한 검사 묶음이나 글 품질 점수가 아니다.
- 다섯 변경 구간의 개별 페이지를 렌더했다. 전권 contact sheet나 차단된 PDF 인용 전수 대조는 실행하지 않았다.
- 최초 하위 편집 메모의 -29자는 부모 통합 교정 전 수치다. 재배열 후 부정확했던 앞 표 참조를 제거했으며 최종 수치는 위 -34자다.
- PDF는 정적이고 확대 기능은 웹 읽기본에 있다. 작성 결과는 직접 복사하거나 저장해야 하며 파일 저장이 실제 승인이나 발송을 뜻하지 않는다.
- 본문 검토와 자동 동작 검사는 실제 독자 수행시험을 대신하지 않는다. 저자 목소리, 사람 통계 검수, 권리와 최종 출간 승인은 별도다. GitHub 커밋과 푸시는 이번 작업에서 실행하지 않았다.

## 선택 이유

기존 벡터 그림을 그대로 확대해 수치와 조건을 축소하지 않고 읽게 했다.
설명은 늘리기보다 기존 결과와 후속 설계를 나누고 독자가 판단 문장을 직접 쓰게 했다.
작성 내용은 명시적으로 가져가게 해 입력 손실을 줄이되 자동 저장과 외부 전송은 늘리지 않았다.
