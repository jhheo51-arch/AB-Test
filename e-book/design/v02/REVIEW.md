# v0.2 편집·계산·출력 검수 기록

## 제공 범위
허재혁 저자 검토본. 읽기 본문, 저자 서사 초안, 계산 실습, 반론 장, 워크북, 시각 진단 카드와 검색 화면을 제공한다. 판매 승인·외부 전문가 검수 완료를 뜻하지 않는다.

## 내용 변경
- 제공된 경력의 선택 이유를 바탕으로 1인칭 저자 서사 작성. 사실로 확인되지 않은 성과·수상·실험 결과·구체 일화를 추가하지 않음. 저자 표현 승인 대기.
- ‘B 승리’를 유효성·통계 근거·사업 가치·채택 가능성으로 분리.
- 기본 합성 데이터에서 실제 완료·예약·거부 비율·효과 구간·p-value 계산. 미보정 결과와 한계를 명시.
- 60개 기존 패턴에 서로 다른 반론 질문, 피할 답변, 요구 증거, 답변 범위, 다음 행동과 실습 연결 상태를 추가.
- 모든 카드의 원인·성과가 실증된 것은 아니며 데이터 실습이 없는 카드는 명시.

## 검증 범위
- 비율 검정·Newcombe 구간 자체 구현을 statsmodels와 1e-12 절대 오차 이내 대조. 집계 뷰를 원본 이벤트 SQL과 대조.
- 별도 미래 설계 예: 9%→11%, 양측 5%, 80% 검정력의 근사 표본 계산. 기존 데이터 사전 계획이라고 주장하지 않음.
- 60개 카드 선택을 전부 실행, 검색·빈 검색·필터·이전/다음·키보드·세 탭·데스크톱/모바일 넘침 검사.
- PDF 본문 한글·저자·기업·첫/마지막 카드·분석값 추출. 카드별 독립 페이지·목차 북마크·페이지 경계 검사.
- 전체 페이지 축소 연락 시트와 대표 카드·계산표·구간 그림·화면을 직접 시각 확인. 텍스트 겹침·잘림을 발견하지 않음. 카드 메모 칸 아래의 여백은 참조·작성용 구성이다.
- 계산 그래프는 실측 합성 표본의 추정/구간을 사용. 카드의 관측→반론→증거→행동 도식에는 가짜 정량 성과를 넣지 않음.
- 본문 팔레트 제안: #162B33 / #526168 / #125E59 / #8B431D, 바탕 #FFFFFF / #F6F4EF. mira_contrast_matrix의 8개 조합 모두 본문 AA 통과, 최저 5.85:1. 색 대비가 전체 접근성 검수를 대신하지 않음.

## 편집 설계 선택
시각 유형: Learn/Decide와 참조 라이브러리. 실제 관측과 미확인 설명을 나란히 읽도록 패널 분리. 서로 다른 반론이 동일한 성공 배지로 덮이지 않게 함. 원본 기업의 시각 정체성을 모방하지 않은 저자 편집 디자인 제안.
관습적 AI 장식 10개 자체 점검 결과 0개로 평가. 외부 미적 품질 검증 아님. 불필요한 그라디언트·장식 통계·아이콘·균등 3열 기능 카드를 쓰지 않음.

## 남은 출간 관문
- 저자 1인칭 서사·제목·부제 최종 확인
- 통계/OEM 실무 전문가 및 실제 독자 검토
- 실제 현대자동차·기아의 시장별 상세 공개 근거 장부와 실험 제안 보강
- 카드별 사례·반례·재현 실습의 적용 범위 확대
- 실제 매출·LTV·기여이익의 새로운 자료 없이 관련 성과 주장 금지
- 참고문헌·글꼴·인용·상표·표지·배포처 규격·출판 관련 요건 검수

PDF 목차·북마크는 생성되지만 접근성 태그 전수 검수는 미완료다. 로컬 글꼴 Malgun Gothic의 상업 배포 권리 검토도 별도다. 이 파일을 최종 판매 준비 완료로 표시하지 않는다.
