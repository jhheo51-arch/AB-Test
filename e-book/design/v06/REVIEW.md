저자 허재혁. 방법론 중심 본책을 보존한 50쪽 저자 검토본이다. 새 제목과 말투, 사람의 통계 및 OEM 실무 검토, 실제 독자 테스트와 권리 및 판매처 검수는 완료 전이다.

## 학습 노트의 교정

| 노트에서 주의할 표현 | 반영한 설명 |
|---|---|
| OEC = operational equality control | Overall Evaluation Criterion, 전체 평가 기준 |
| 1-p가 효과가 참일 확률 | p값은 귀무가설과 검정 가정 아래의 극단성 확률, 사후확률 아님 |
| alpha 0.05% | 0.05는 5%이며 개별 발견이 틀렸을 확률과 구분 |
| 신뢰구간 하한은 최악 손실 | 명세한 추론의 구간이며 미래 손실이나 편향의 보장선 아님 |
| Twyman은 작은 성장의 축적 | 놀라운 수치일수록 측정과 비교를 먼저 점검하라는 경험적 경고 |
| 모든 실험은 정확한 50:50 | 사전 비율에 맞는 무작위 배정, 우연한 불균형과 SRM 구분 |
| 오류율은 항상 불변 지표 | 처치가 바꿀 수 있으면 결과이자 가드레일일 수 있음 |
| MDE가 곧 도입 기준 | 계획 검출 효과와 최소 사업 효과 분리 |
| 밴딧이 저표본을 해결 | 정보 부족은 남으며 적응적 배정과 지연 보상에 맞는 추론 필요 |
| 지역 분할은 모두 준실험 | 무작위 군집 설계 가능, 독립 군집 수와 간섭 고려 |
| DID가 외부 요인을 자동 제거 | 동시 비교 집단과 평행 추세 등 식별 가정 필요 |
| A/B는 요소 하나만 변경 | 묶음 정책 비교 가능, 개별 요소의 기여와 구분 |
| 요인설계 표본은 조합 수로만 결정 | 주효과, 상호작용, 셀별 선택 등 목표 대비별로 계획 |
| 수만 명, 실패율 80%, 첫날 중단 10%는 보편 기준 | 출처 맥락과 조건 없이 일반화하지 않음 |

## 근거와 새 이름

Notion 공개 페이지는 마지막 스크롤 상태까지 수집했다. 중첩 블록은 상위 텍스트와 하위 텍스트가 중복될 수 있으므로 수집 문자 수를 학습 분량으로 과장하지 않는다. 연결 영상을 시청한 것 또는 첨부 책의 전문을 읽은 것과 구분한다. Microsoft의 during/post 연재 두 본문은 브라우저에서 읽었고 NIST 블록 설계와 ICH 추정 대상의 관련 구절을 확인했다. 열람 장부는 references/METHOD_REVIEW_v06.json, 사용 범위는 최종 본책 자료 절을 따른다.

인과결 후보는 Marc Studio의 게임 요소 명칭으로 실제 쓰인 사례를 직접 확인했다(https://marc-official.com/88). 이 후보 대신 맥락항법을 우선 제안했다. 맥락항법 정확 표현 검색에서는 같은 방법론의 사용을 확인하지 못했으나 검색 결과가 유사어를 반환했으므로 부재나 독점 가능성을 주장하지 않는다. 상표 조사와 학술 체계적 문헌고찰은 미실시다.

판단은 조건부다. 기존 원칙과 정합적이고 CRM 실무 검토 틀로 발전시킬 만하지만 새 통계 이론이나 현장 우월성이 입증된 방법론은 아니다. 사전 명세, 데이터 품질, 탐색과 확증 분리, 다중성, 비용 가정, 희귀 손상과 운영 용량을 지킬 때에만 실무적 의미가 유지된다.

## 출력 및 계산 확인

- 본책 50쪽, 여섯 사례 유지, 36개 용어 색인 목표와 내부 링크 오류 없음.
- 기존 수치 장부와 원고의 103항목 대조 통과. 새로운 통계 추론을 재실행한 검사가 아니다.
- 신규 구간 그래프는 scenario_results.json에서 직접 생성. 사례 5의 전체는 95% 층화 Wald, 상태별은 97.5% Newcombe라는 차이를 그래프와 본문에 표시.
- 사례 6은 일 60슬롯 조건의 모형 값이다. 막대의 두 열은 각각 다른 단위와 척도이며 상호 높이를 직접 비교하지 않는다. 고정 수요의 비교이지 기대 이익이나 신뢰구간 아님.
- 도구로 계산한 본문색, 보조색, 링크색과 흰색 및 종이색의 여섯 조합은 모두 본문 AA 통과, 최소 5.85:1. 전체 접근성 인증 아님.
- 본문 12pt. 한글, 저자명, 영문 단계명, 여섯 사례 책갈피, 링크 목표, 폰트 바이트 또는 Type3 glyph stream, 페이지 경계와 풋터 검사 통과.
- 모든 페이지 연락 시트와 대표 원문 크기의 고객군 및 순가치 그래프를 눈으로 검토했다. 잘림과 글자 겹침은 발견하지 못했다. A4 PDF의 휴대전화 독서 적합성이나 EPUB 검증은 아님.
- 본문과 PDF의 가운데 점 여섯 종류 모두 0개. 본문의 문단별 소제목은 없으며 용어집의 항목 제목만 탐색 목적으로 유지했다.
- 디자인 자가 진단상 장식성 그라데이션, 카드 격자, 중앙 정렬 남용 등 지정된 열 가지 징후는 0/10. 이는 편집 품질이나 출간 적합성을 인증하는 점수가 아니다.

디자인 선택은 세 가지다. 본문은 연속 서술을 유지해 저자의 판단을 따라가게 했다. 그래프는 정화, 입체화, 언어의 전환이 결론을 바꾸는 사례 곁에 두었다. 용어 설명은 마지막에 따로 모아 본문 흐름을 끊지 않고 필요할 때 돌아가게 했다.

기존 v0.4 워크북과 카드 참조편, 원래 v0.3 DB와 v0.4 분석 장부는 수정하지 않았다. 기술적 출력 검사와 이번 요청의 본문 통합은 완료했지만 저자의 최종 목소리와 제목, 사람 검수와 상업 출간 승인은 별도로 남아 있다.
