# v0.3 데이터·본문 개정 안내

## 이 버전의 목적
기존 카드집을 크게 출력하는 대신, 실험 가능성→적격 모집단→관측 성숙도→지표별 추론→결정 한계를 하나의 본문 사례로 연결한다. 원고의 새 대표 장은 e-book/exports/v03/sample_and_data_chapter_v03.html 및 PDF에 있다. 기존 전체 책 v0.2를 덮어쓰지 않는다.

## 실행 순서
1. `uv run --with scipy --with statsmodels scripts/plan_oem_v03.py`: 기준 비율·효과·오류·기간·다중성·표본 계획 동결. 기존 계획이 있으면 중단.
2. `python scripts/build_oem_v03.py`: 모집단 고정→별도 난수로 배정·전달·결과→스테이징 DB→검사 후 최종 파일 승격. 기존 파일 덮어쓰기 금지.
3. `uv run --with scipy --with statsmodels scripts/analyze_oem_v03.py`: 원본 SQL·수식·라이브러리 대조, 지표별 계획 정보량·보정된 완료 대비·실제 출처 상태 확인.
4. `uv run --with scipy --with statsmodels scripts/simulate_information_v03.py`: 동일 효과·무효과 모형에서 표본만 바꿔 단일 대비의 발견률·거짓 양성을 반복 점검. 본 데이터는 재추출하지 않는다.
5. `python scripts/build_v03_chapter.py`: 데이터 사전과 계산 결과에 연결된 대표 장 생성. Markdown 패키지 필요.

## 주요 파일
- experiment_plan.json: 생성 전에 고정한 교육용 계획과 모수
- sample_size_grid.csv: 단일/세 대비 계획 12행
- data/jh_motors_v03.sqlite: 합성 DB
- data/csv: 테이블·최종 결과·조기 스냅샷
- DATA_DICTIONARY.md: 실제 스키마에서 만든 필드 사전
- generation_report.json: 실제 생성·구조 검사 결과
- analysis_report.json: 분석·표본 가능성·외부 자료의 역할
- metric_readiness.csv: 지표별 계획 검정력
- RESULTS.md: 결과 해설

## 워크플로우 변경: 회사 전체가 아니라 지표마다 판단
G3에 다음 항목을 추가한다.
- 대상/배정 고객 수, 개인별 관측 성숙 고객 수, 사건 수
- 기준 비율·최소 관심 효과·검출 목표·단위·다중성·종료 규칙
- 계획 표본과 실제 유입의 실행 가능성
- 현재 관측의 정밀도와 계획 효과 아래 정보량
- 상태: 계획 가능 / 등록 부족 / 관측 미성숙 / 희귀·미세 효과 정보 부족 / 분석 가정 불일치 / 미확인

낮은 계획 검정력은 관측 자료의 분석 금지나 항상 무효라는 뜻이 아니다. 가정과 방법이 맞으면 추론할 수 있으나 특정 크기 효과의 발견 가능성·정밀도가 부족할 수 있다. ‘표본 충분’도 배정·측정 타당성이나 안전을 보증하지 않는다. G8은 지표별 근거·가드레일·경제성·운영·동의를 별개로 확인한다.

## 실제 자료 이용의 선
외부 출처는 external_sources에 분리한다. 현대차 모델별 판매와 Toyota 보고서는 이전 다운로드 해시와 대조했고, 기아는 판매 라이브러리 목록 확인 단계다. 실제 통계로 연락 동의율·전환율·캠페인 효과·개별 고객을 만들어내지 않았다. 현재 합성 생성은 실제 OEM 데이터의 수치 보정본이 아니다.

## 다음 개발 우선순위
- 같은 고정 모집단에서 정상·무효과·누락·계약 지연·희귀 위험의 대조 사례를 만들고, 각 경우의 판단을 완성 풀이로 연결.
- 실제 권한 있는 CRM 집계/원장에 접근할 수 있을 때 유입·도달·지연·비용·용량을 보정. 불가하면 가정 범위의 민감도와 미지원 상태를 표시.
- 주지표 개선·가드레일 정보 부족이 공존하는 결정 기록을 사례로 집필.
- 본문·진단 참조편·워크북을 분리하는 전자책 개편은 대표 장의 독자 검토 이후 확장.

## 남은 한계
군집·가구 간섭·슬롯 포화·동시 캠페인·취소·출고·실제 회계·장기 LTV는 현재 구현 밖이다. 계약 손익은 고정 가정의 기술적 예시다. 큰 합성 데이터는 실세계 타당성·방법론 효과를 입증하지 않는다. 외부 통계/OEM 실무/실독자/상업 권리 검수 전이다.
