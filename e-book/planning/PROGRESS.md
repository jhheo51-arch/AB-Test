## 최신 파일과 해석 기준
- 통합 요약은 저장소 루트 PROJECT_SUMMARY.md, 실행 확인은 PROJECT_STATUS.json을 따른다.
- 최신 전체 읽기본은 e-book/exports/v12의87쪽 PDF다. 편집 범위와 실제 쪽수는 design/v12/REVIEW.md를 따른다. v0.7은 이전79쪽 판으로 보존한다. 표지와 원고의 실질 확장 및 분량 대조는 design/v07/REVIEW.md, 모의 페르소나 결과는 PERSONA_REVIEW_v07.md를 따른다. 기존 워크북과 카드 및 DB와 수치 장부는 보존했다. 현재 로컬 작업 사본은 원격을 받은 AB-Test-v07 경로다.
- v0.3은 A/B/H와 180일 계약을 포함하는 새 합성 모형이다. 무발송 대비 비교를 지원하되 실제 OEM 효과나 차량 매출·LTV를 입증하지 않는다.
- 다음 절의 무발송군 없음·경로는 v0.1/v0.2 초기 데이터에 대한 이력이다.

## 이전 v0.1/v0.2 데이터 작업의 경계
현재 작업명은 'JH Motors'로 임시 변경한다. 사용자 최종 승인 전이며 실제 기업과 관계없고 상표 이용 가능성을 확인한 이름이 아니다. 원본 v0.1의 JH Motors DB와 문서는 이력 보존을 위해 그대로 두며, 새 실습 파일은 scenarios_v02와 jh_motors_synthetic_data_v02.zip에 있다.
가상 단일 시장·직영 CRM·판매 파트너 연결 모델이며 실제 OEM 운영을 재현하지 않는다.
주 사례는 차량 관심 고객의 시승 안내 메시지 A/B 비교다. 무발송 대비 효과나 차량 매출 증가를 이 비교만으로 주장하지 않는다.
데이터·확률·비용·차량 설정은 모두 교육용 가정이며 시장 평균·기업 실적으로 사용하지 않는다.
DB 기본 실습은 계산과 데이터 구조 학습용이다. 고정된 난수 시드와 생성 규칙을 제공하고 유의성에 따라 시드를 고르지 않는다.
고객의 이름·전화·이메일·실제 VIN·실제 위치 이력은 저장하지 않는다.

## 파일 안내
- scripts/build_db.py: 표준 라이브러리로 DB·CSV·보고서 생성 및 검사
- data/oem_crm.sqlite: SQLite 관계형 DB
- data/csv/: 테이블별 CSV
- data/validation.json: 실제 검사 결과와 실험 요약
- data/manifest.json: 생성 가정·시드·확률·관측 기간
- DATA_DICTIONARY.md: 테이블·주요 분석 원칙

## 실행
프로젝트 루트에서 `python scripts/build_db.py`를 실행한다. 기존 DB가 있으면 덮어쓰지 않도록 중단한다. 재생성은 별도 프로젝트 사본에서 수행한다.


## 저장소 구조 변경
현재 정식 작업 루트는 AB-Test이며 데이터는 e-book/virtual-data/v01 및 v02, 기업 설정은 e-book/virtual-company에서 관리한다. 이전 파일 경로는 과거 작업 이력이며 현재 경로는 루트 README를 따른다. 기업명 JH Motors는 사용자 요청에 따른 임시 제안으로 상표 미검증이다.

## 2026-11-18 v0.13 발견사항 보완
