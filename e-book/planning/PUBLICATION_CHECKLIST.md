# 출판 직전까지의 실행 체크리스트

기준 원고: v0.7, `e-book/exports/v07/ebook_review_v07.pdf`. 이 문서는 이전 제작 이력인 PROGRESS.md와 구분하는 출판 준비의 현재 실행 목록이다. 완료는 결과물과 확인 근거가 있고 필요한 사람의 승인을 받았을 때만 표시한다. AI 모의 평가와 자동 출력 검사를 사람의 검수 또는 실제 독자 시험으로 대신하지 않는다.

## 운영 원칙

- 한 번에 주 작업 한 단계를 진행하고 수정 결과와 미해결 항목을 남긴다.
- [x]는 완료 근거와 승인 기록이 있는 작업만 표시한다. 초안 작성은 승인 완료가 아니다.
- 사람이 필요한 검수는 요청 자료를 준비하고 대기로 남긴다. 검토자를 임의로 선정하거나 유료 의뢰 및 외부 공유하지 않는다.
- 새 원고를 동결한 뒤 기술 수정과 사람의 검토 의견을 반영한다. 승인받은 내용이 바뀌면 관련 승인 범위를 다시 확인한다.
- 원본 DB와 계획 및 지난 판은 보존한다. 재현의 오류를 숨기거나 해시를 고쳐 맞추지 않는다.
- 표지와 판형의 최종 확정은 내용 수정이 안정된 뒤 한다. 페이지 목표를 맞추는 증보는 하지 않는다.

## 현재 집중: PUB-01

독자 약속과 명칭의 확정안은 [PUBLICATION_BRIEF.md](PUBLICATION_BRIEF.md)에 작성했다. 독자와 학습 결과는 기존 원고에서 정리했으며 새로 승인된 것으로 처리하지 않았다. 이번에 먼저 결정할 것은 세 이름의 관계다. 추천안은 상위 방법론 이름을 맥락항법, 실행 절차를 TRI-V로 두고 트리아타시스는 초기 구상의 배경으로만 남기는 것이다. 저자 승인 전이며 본문과 표지의 실제 명칭 치환은 하지 않는다.

## 출판 준비 단계

### PUB-01 독자 약속과 방법론 명칭 확정

상태: 확정안 작성 및 현재 원고 대조 완료, 저자 승인 대기. 담당: 미라 정리, 저자 승인.

- [x] 주독자와 보조독자, 선행지식과 제외 범위를 현재 원고에서 추출한다.
- [x] 학습 결과를 실험 명세, 근거 해석, 결정문으로 구체화한다.
- [x] 세 이름의 관계를 정리한 추천안을 작성한다. 아직 적용하거나 확정하지 않는다.
- [ ] 저자가 명칭 구조와 독자 약속을 승인한다.
- [ ] 승인한 구조를 소개, 표지 문구, 읽기 안내, 본문과 용어 설명에 일관되게 적용하고 확인한다.

완료 기준: 승인 기록이 있고 독자 약속 및 명칭 대응이 실제 원고 전반에서 일치한다.
근거: `PUBLICATION_BRIEF.md`, `../manuscript/reader_route_v07.md`. 승인 기록: 미완료.

### PUB-02 전권 편집과 저자 문체 교정

상태: PUB-01 이후 진행할 주 작업. 담당: 미라 편집, 저자 표현 확인. 필요시 사람 편집자의 별도 검토.

- [ ] 장별 학습 목표와 설명 역할을 한 장부로 정리하고 반복 및 누락을 표시한다.
- [ ] 5장과 6장, 9장과 10장, 12장의 반복 정의와 면책을 줄이되 판단 근거는 보존한다.
- [ ] 독자가 계산과 결론 사이에서 건너뛰어야 하는 구간을 교정한다.
- [ ] 저자 서사의 제공 사실과 개인 해석을 분리하고 만들어낸 일화가 없는지 대조한다.
- [ ] 가운데 점 금지, 용어와 단위, 자연스러운 한국어 및 사례의 연속성을 검사한다.
- [ ] 전후 수정표와 전권 원고를 저자가 검토하고 승인한다.

완료 기준: 전권 편집 기록, 수정 원고와 대조 결과, 저자 표현 승인. 줄인 문자 수나 페이지 수는 합격 기준이 아니다.

### PUB-03 독립적인 통계 검수

상태: 사람 검토자 미선정, 검수 자료 준비 필요. 담당: 미라 자료 준비, 저자가 승인한 독립 통계 검토자.

- [ ] 자료와 명세, 추정 대상, 분모, 가정, 방법과 수치 및 허용 주장을 사례별로 묶는다.
- [ ] 검정과 구간의 방법 차이, 비교 가족, 세그먼트 및 상호작용, 보호 지표와 손익의 검토 질문을 작성한다.
- [ ] 외부 공유 범위와 검토자의 역할 및 비용이 있으면 저자의 동의를 받는다.
- [ ] 사람 검토자가 검토 범위와 발견 사항을 서면으로 남긴다.
- [ ] 지적 사항을 수정하고 미해결 중대 문제와 재검토 결과를 기록한다.

완료 기준: 독립 사람 검토 기록과 지적 사항 처리 장부. 기존 103개 수치 대조나 AI 검토를 이 단계의 완료로 세지 않는다.

### PUB-04 실제 독자 과제 시험

상태: 미실시. 담당: 미라 시험안 준비, 저자가 모집 및 참여를 승인한 실제 독자.

- [ ] 주독자에게 제시할 새 결과표와 과제, 관찰 항목 및 판정 규칙을 시험 전에 고정한다.
- [ ] 설명 없이 주지표, 분모, 효과, 사업 기준과 보호 조건을 나누어 결정문 및 자료 요청서를 작성하게 한다.
- [ ] 참여자의 동의, 자료 보관과 공개 범위를 정한다. 임의 모집이나 외부 전송하지 않는다.
- [ ] 막힌 지점과 도움 요청, 오해와 실제 작성물을 기록한다.
- [ ] 문제가 있는 설명을 수정하고 필요한 재시험을 수행한다.

완료 기준: 실제 과제 수행 자료와 개선 기록. 만족도, 모의 페르소나와 구매 의향을 학습 효과 및 판매 검증으로 바꾸지 않는다.

### PUB-05 CRM과 OEM 실무 검토

상태: 사람 실무 검토자 미선정. 담당: 미라 질문지 준비, 저자가 승인한 실무 검토자.

- [ ] 동의 관리, OEM과 지점의 역할, 예약과 완료, 계약과 출고의 연결을 검토할 자료를 준비한다.
- [ ] 공유 용량, 취소와 재예약 및 대기의 교육 가정과 실제 운영의 차이를 표시한다.
- [ ] 실무 검토자가 부적절한 일반화와 누락한 조건을 기록한다.
- [ ] 수정 의견을 반영하고 사례의 단순화 및 적용 한계를 분명하게 한다.

완료 기준: 실무자 검토와 처리 기록. 공개 자료 조사나 합성 데이터의 정상 실행을 내부 현장 확인으로 세지 않는다.

### PUB-06 자료와 재현 패키지 정리

상태: 읽기 패키지 존재, 전체 제공 범위 미확정 및 계획 바이트 불일치 이슈 열림. 담당: 미라 기술 점검, 저자 제공 범위 승인.

- [ ] 독자에게 제공할 PDF, HTML, 양식, 코드와 합성 DB의 범위를 확정한다.
- [ ] 읽기 전용 점검과 생성 작업, 의존성, 버전 및 기대 출력을 안내한다.
- [ ] 현재 계획 JSON의 LF와 DB 기록의 CRLF 해시 차이를 원본 보존 상태에서 진단하고 배포 방침을 정한다.
- [ ] 정확 바이트 일치와 줄바꿈 표현 동등성을 분리한다. 원래 계획이나 DB 해시를 고쳐 통과시키지 않는다.
- [ ] 별도 깨끗한 작업 환경에서 제공 안내만으로 재현하고 실제 결과와 한계를 기록한다.

완료 기준: 제공 파일 명세와 재현 안내 및 실제 실행 결과, 알려진 이슈의 처리 방침. 현재 읽기 ZIP의 정상 열림은 전체 계산 환경 재현을 뜻하지 않는다.

### PUB-07 인용과 권리 검토

상태: 글꼴 OFL 자료와 출처 장부 일부 존재, 전권 검토 전. 담당: 미라 장부 준비, 저자 및 필요시 권리 전문가 확인.

- [ ] 인용한 주장과 참고 자료, 직접 인용과 요약, 표와 그림의 출처를 연결한다.
- [ ] 글꼴과 그림 및 외부 자료의 인용, 포함, 상업 배포 조건을 대조한다.
- [ ] 허가나 조건이 불명확한 원자료를 독자 패키지에서 제외하거나 필요한 승인을 받는다.
- [ ] 합성 자료와 실제 기업 정보, 명칭 사용에 대한 오해 가능성을 검토한다.
- [ ] 저자가 해결되지 않은 권리 문제와 제공 범위를 확인한다.

완료 기준: 사용 근거 및 조건이 정리된 권리 장부와 필요한 허가 기록. 폰트 삽입이나 URL 기재만으로 전권 권리 확인을 완료했다고 하지 않는다.

### PUB-08 표지, 판형과 판매 파일 확정

상태: A안 추천 적용, 최종 표지와 유통 경로 승인 전. 담당: 저자 선택, 미라 제작과 검증.

- [ ] 주 유통 경로와 읽기 기기를 정한 후 해당 공식 제출 요건을 확인한다.
- [ ] PDF와 EPUB 등 필요한 형식을 정하고 표지, 제목, 부제와 파일 구성을 승인한다.
- [ ] 실제 목표 기기에서 본문, 표와 그림, 목차와 색인 및 검색과 복사를 확인한다.
- [ ] 판매 소개의 약속이 본문과 제공 파일을 넘어가지 않는지 대조한다.
- [ ] 업로드 전 최종 파일 검사 결과를 보관한다. 실제 게시나 결제 작업은 별도 승인 범위다.

완료 기준: 저자 시각 승인과 선택한 판매처의 공식 규격 및 실제 기기 검수. HTML의 가로 넘침 검사를 전자책 기기 전체 검증으로 세지 않는다.

### PUB-09 최종 교정쇄와 출간 승인

상태: 앞 단계의 미해결 조건 때문에 대기. 담당: 미라 교정 준비, 사람 교정 및 저자 최종 승인.

- [ ] 내용이 안정된 최종 원고로 PDF 또는 배포 형식을 다시 생성한다.
- [ ] 오탈자와 표기, 숫자와 단위, 표와 그림, 쪽수와 상호참조를 전권 대사한다.
- [ ] 검토 의견의 미해결 사항과 변경에 영향을 받은 이전 승인을 재확인한다.
- [ ] 최종 파일, 버전, 해시와 제공 목록을 동결한다.
- [ ] 저자가 최종 배포 파일과 소개문을 승인한다.

완료 기준: 모든 필수 조건에 완료 근거가 있고 저자의 최종 승인 기록이 있다. 미완료를 제외한 채 출판 직전 또는 판매 준비 완료라고 표시하지 않는다.

## 변경 기록

- v0.7을 기준으로 출판 준비의 실행 체크리스트를 만들고 PUB-01 확정안을 작성했다.
- 기존 PDF와 분석 수치 및 DB는 이 체크리스트 작성 과정에서 수정하지 않았다.
- 다음 갱신은 저자의 명칭 결정과 PUB-01 원고 반영 결과를 근거로 한다. 문서를 만든 일을 출판 준비 완료로 계산하지 않는다.
