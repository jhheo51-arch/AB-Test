# 저자 방법론과 편집 기준

현재 대표 이름은 맥락항법이며 TRI-V는 이를 실행하는 절차다. v0.8부터 저자가 진행 승인한 이 구조를 사용한다. 초기 구상의 이름 트리아타시스(Tri-Ataxis)는 1장의 배경 한 문단에만 남긴다. 아래 과거 판의 설명과 초기 원문 명칭은 이력으로 보존하며 최신 이름을 다시 되돌리는 근거로 쓰지 않는다. 2026년11월16일 제공한 `pasted_content_2026-11-16_08-46-55-414_0f762e.txt` 원문과 대화 기록을 다시 확인했다.

정화(Purification)는 Variable Control, 해체와 입체화(Prism)는 Vector Segmentation, 언어의 전환(Translation)은 Value-Linked Decision에 대응한다. 이 이름과 연결을 유지한다. 초기 원문에 있던 Value-Vector Navigation은 같은 구상의 부연으로 한 번 설명하고 별도 이론을 추가해 독자의 용어 부담을 키우지 않는다.

저자의 배경은 마케팅에 관심을 둔 경영학 전공과 마케팅 트랙, 거시적 시야를 위한 정치외교학 복수전공, 정보통신 병과와 인사 업무 경험이다. 방법론을 설명하는 문제의식의 배경으로 쓴다. 제공되지 않은 현장 일화나 A/B 실험의 성공 성과를 발명하지 않는다.

원문의 ‘완벽한 신호 추출’, ‘평균은 언제나 거짓’, ‘기존에 없던 이론’, 어원과 성과의 단정은 확인된 사실로 옮기지 않는다. 세 축을 없애는 대신 비교와 측정, 사전 집단 효과, 사업 가치와 위험을 연결하는 저자 방법론으로 정확하게 설명한다.

v0.4는 승리 검증과 사례에 무게가 실리며 트리아타시스가 본문에서 사라졌고 TRI-V는 짧은 소개에 그쳤다. v0.5는 들어가며와1~4장에서 관점과 실행을 먼저 다루고, 통계와 표본을 그 도구로 배치하며, 모든 사례와 마지막 판단에서 다시 적용한다. 방법론 이름만 추가하는 수정으로 끝내지 않는다.

이번 문체 기준은 일반 책의 연속 서술이다. 정상적인 문단은 유지하되 문단마다 소제목을 달지 않는다. ‘질문과 계약’, ‘원자료’, ‘반론’, ‘판단’, ‘독자 과제’가 매번 반복되는 틀을 풀어 설명을 연결한다. 세부 학습 양식이 필요한 경우 별도 보조자료에 둔다. 새로운 본문과 표, 도표, 표지에서 가운데 점 문자를 쓰지 않는다.

AI가 관여하지 않은 척하거나 탐지 불가능을 약속하지 않는다. 상투적인 대조 문장과 과한 선언, 가짜 현장감을 줄이고 구체적인 데이터와 저자의 질문으로 문장을 고친다. 저자 표현의 최종 확인은 사용자에게 남긴다. 기존 검증 수치와 통계적 한계는 윤문하면서 바꾸지 않는다.

이 기록은 이번 집필의 기준이다. 실제 출력과 검증 여부는 각 판의 build_manifest와 validation을 따른다. 이전 판은 보존하고 새로운 본책만 갱신한다. 과거 워크북과 카드 참조편까지 함께 윤문했다고 보고하지 않는다.
