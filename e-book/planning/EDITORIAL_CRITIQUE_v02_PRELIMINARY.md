# v0.2 전자책 자체 비평 — 서점 비교 전 1차 감사

## 판정
현재 파일은 상업적 실무 단행본보다 ‘개념 요약 + 진단 워크북’에 가깝다. PDF가 열리고 한글이 나오며 코드가 통과한 사실을 독서 경험·구매 가치·시장 적합성과 혼동하지 않는다. 76쪽을 완성도 지표로 제시한 이전 설명은 적절하지 않았다.

## 직접 확인한 자료
표지 PDF 이미지, CRM-017 카드 이미지, PDF 검증 JSON, 진단 카드 JSON을 다시 확인했다. 계산된 구성 지표는 SELF_AUDIT_METRICS.json에 기록했다.
- 전체 76쪽 중 카드가 60쪽, 약 78.95%다.
- 데이터 실습 연결을 명시한 카드는 CRM-001·007·011·021이다. 연결이 있다는 것이 완전한 풀이·실증을 의미하지 않는다.
- 나머지 카드에는 별도 데이터 실습 미구현이라고 표시된다. 이는 정직한 표기지만 구매자가 기대하는 완결된 사례집과는 거리가 있다.

## 핵심 문제
### 1. 책의 약속과 실제 본문이 다르다
CRM A/B 테스트 플레이북이라는 넓은 약속에 비해 설명·풀이가 짧고, 사례의 결과·오류·수정·재실험이 끝까지 전개되지 않는다. 유형 수와 질문 수가 학습 깊이를 대신한다. ‘모든 경우’를 약속하는 대신 커버리지·적용 불가 조건을 제공해야 한다.

### 2. 카드의 여백과 반복이 워크북의 인상을 만든다
직접 본 CRM-017은 짧은 진단 문구, 반복되는 네 단계 상자, 두 줄 메모 칸과 큰 하단 공백으로 구성된다. 참조·작성 도구로는 쓸 수 있지만, 실무서의 한 페이지를 읽는 정보·사례 밀도와는 다르다. 색과 테두리를 바꾸어도 본문 부족은 해결되지 않는다.

### 3. 경쟁 원인 목록은 있지만 원인을 구별하는 과정을 보여주지 않는다
‘저의도 유입·랜딩 장벽·품절·매출 지연’이라는 후보를 제시한 뒤, 어떤 표·SQL·분석으로 하나씩 반박하거나 남기는지 설명이 부족하다. ‘필요 증거 확인’이라는 답변은 현업에서 바로 실행하기에 추상적이다. 대표 카드는 원본 행→집계→추론→경영 판단→후속 실험까지 풀어야 한다.

### 4. 표지는 임시 문서 표지에 가깝다
현재 표지는 저자 검토본·버전·영문 메타·적용 기업·합성 실습 설명을 함께 담는다. 검토본 표시 자체는 필요하지만 판매용 표지의 독자 효용·제목 식별을 강화하는 장치와는 다르다. ‘A/B 테스트’의 가시성이 본제보다 낮다. 작은 썸네일에서 누가 어떤 문제를 해결하는 책인지 검증해야 한다.

### 5. 고정 A4 PDF 하나로 독서와 작성을 모두 해결하려 했다
인쇄 워크북과 휴대기기 읽기용 책은 다른 레이아웃을 필요로 한다. HTML의 가로 넘침이 없다는 테스트는 스마트폰에서 고정 PDF를 읽기 좋다는 증거가 아니다. 재유동 EPUB·읽기용 PDF·인쇄 워크북의 역할을 분리하고 실제 판매처 규격과 목표 기기에서 검수해야 한다.

### 6. 저자의 전문성은 이름보다 검증 기록으로 쌓아야 한다
커리어 서사는 문제의식을 설명한다. 실제 기업 실험을 운영한 실적이나 통계적 전문성의 증거로 확장하지 않는다. 저자 제안 용어는 학습에 필요한 만큼만 쓰고, 잘 알려진 원칙·저자 판단·합성 가정·미확인을 구별한다.

## 유지할 자산
- ‘B가 이겼다고요? 어떤 근거로요?’라는 중심 질문.
- 예약 신호와 주지표 불확실성이 충돌하는 실제 계산된 합성 사례.
- 현대차·기아를 고려한 OEM 고객 여정의 구체성.
- 동의·안전·누락·관계·운영을 함께 보는 판단 구조.
- 데이터·계산 재현성, 저자 서사에 대한 사실 경계.

## 우선 수정 세 가지
1. **본문을 책답게 다시 편집:** 대표 사례에서 관측→반론→증거 확보→계산→결정→후속 실험을 끝까지 설명. 영향 큼·수정 비용 큼.
2. **책·카드·워크북 분리:** 핵심 카드를 본문에 선별 배치하고 전체 카드 라이브러리는 별책/웹 보조자료로 이동. 영향 큼·수정 비용 중간.
3. **판매용 읽기 표본 검증:** 표지·목차·도입·대표 장·표·도식·각주의 대표 묶음을 목표 기기에서 확인한 뒤 전체 조판. 영향 큼·수정 비용 중간.

## 도구 조사 중간 결과
Hermes 공식 문서에서 스킬·플러그인·MCP 확장을 확인했다. 실제 카탈로그 검색에 ebook 스킬, pdf 스킬 후보가 존재한다. 설치·본문 검토 전이므로 EPUB 변환이나 출판 품질을 보증하는 도구라고 소개하지 않는다.
OpenDesign MCP 목록 조회는 응답했고 doc/docx/pdf/minimax-pdf/canvas-design과 출판·편집 디자인 관련 항목을 확인했다. 별도의 로컬 mira_setup status는 Docker 실행 중, Open Design 컨테이너 없음·프로필 토큰 없음으로 응답했다. 두 경로를 동일한 연결이라고 단정하지 않고 실제 생성·내보내기는 아직 검증 전으로 표시한다. 사용자 승인 없는 설치·재연결은 하지 않는다.

## 다음 비교의 원칙
서점별 현재 범주 순위와 누적 판매량, 종이책과 전자책, 사용자 평가 수를 구분한다. 접근한 소개·목차·미리보기 범위를 기록한다. 많이 팔리는 이유를 표지나 레이아웃 하나로 인과 설명하지 않는다. 인기 도서의 판매 이력은 이 책의 수요 증거가 아니다.
