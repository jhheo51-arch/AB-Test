# v0.21 이후 수정 범위

## 현재 결정

저자 허재혁은 v0.21을 기준으로 본문 개발을 마무리하고, 검수에서 발견한 오류와 실제로 읽다가 막히는 부분만 수정하기로 했다. 이는 출간 승인이나 사람의 통계 검수 완료를 뜻하지 않는다.

기준 읽기본: `e-book/exports/v21/ebook_review_v21.pdf`
기준 원고: `e-book/exports/v21/ebook_review_v21.md`
기준 웹 읽기본: `e-book/exports/v21/ebook_review_v21.html`
기준 묶음: `e-book/packages/JH_CRM_ebook_reader_v21.zip`

## 수정할 것

- 오탈자, 잘못된 참조, 수치 및 표기 불일치, 계산이나 해석의 오류
- 합성 자료와 실제 성과, 사전 조건과 사후 가정, 분석 결과와 실제 승인 경계의 잘못된 표현
- 실제 읽기 중 비교 대상이나 문장의 뜻을 파악하기 어려운 구간, 설명 사이의 끊긴 연결
- 글자나 표의 잘림과 겹침, 읽기 어려운 그림, 링크나 조작의 실제 오류

## 더하지 않을 것

새 사례, 추가 이론, 방법론의 확장이나 재명명, 새 필수 기록 항목과 기능은 추가하지 않는다. 취향 차이나 막연한 개선 가능성만으로 전면 윤문하거나 장을 다시 구성하지 않는다. AI가 제안한 읽기 장애 후보는 실제 독자가 겪은 문제로 기록하지 않는다.

## 수정 절차

발견 위치와 실제 증상을 기록하고, 오류나 읽기 장애인지 확인한 뒤 필요한 범위만 고친다. 수정 전후와 이유를 남기고 영향을 받은 수치, 조판, 링크와 동작을 다시 검사한다. 이미 통과한 검사라도 수정의 영향 범위에서는 재확인한다. 이전 판과 원자료 및 감사 기록은 보존한다.

완성 결정문의 내용과 한 면 구성 및 물리 79쪽 보존을 유지한다. 오류 수정과 이 조건이 충돌하면 조용히 내용을 유지하거나 쪽수를 바꾸지 않고 저자에게 알린다.

이 결정은 과거 동의 차단된 PDF 인용 전수 대조와 전권 contact sheet 생성을 재승인한 것이 아니다. 해당 차단과 GitHub 커밋 및 푸시의 승인 대기는 유지한다. 독자 모집, 외부 공유와 게시도 자동으로 진행하지 않는다.

현재 이 문서는 수정 범위를 고정한 기록이며, 새로운 오류 검수를 실행하거나 추가 수정을 완료했다는 보고가 아니다.
