# v21 승인 편집 장부의 초기 검사 기록

이 문서는 하위 편집 초안의 검사 기록이다. 부모 통합 과정에서 재배열 뒤의 부정확한 앞 표 참조를 제거했다. 최종 편집 문자 수 변화는 -34자이며, 79쪽 결정문 보존과 실제 실행 결과는 묶음의 DEVELOPMENT.md와 REVIEW.md를 우선한다.

## 범위와 적용 방법

기준은 `e-book/exports/v20/ebook_review_v20.md`이며 검토 근거는 `e-book/review/development_review_v20/CONTENT_REVIEW.md`다. 사용자가 승인한 세 편집만 담았다. `EDITORIAL_EDITS.json`은 `id`, `before`, `after`, `reason`으로 구성한 배열이다. 배열 순서대로 현재 문자열에서 `before`가 정확히 한 번 있는지 검사하고 한 번만 치환한다. 완성 원고를 별도 저장하거나 기준 원고를 수정하지 않았다.

원고 바이트 SHA-256: `6d26b68d0c7a025acdfa346593b02c1eb848e9b4ea7be97745e8518127e11b54`

문자 수는 LF 줄바꿈을 포함한 문자열 길이다. 전체 변화는 -29자이며, 완성 결정문 앞까지의 변화도 -29자다. 앞부분 분량의 큰 변동을 피했지만 문자 수가 같아도 조판 줄바꿈은 달라질 수 있다. 79쪽의 결정문 한면 유지와 실제 쪽수는 이 장부만으로 확인하지 않았으며 빌더의 조판 확인이 남아 있다.

6장은 기존 결과와 후속 설계를 섞지 않는다. 앞 표의 단일 비교와 기존 완료 세 대비 보정을 구분하고, 후속 설계가 별도 교육용 조건이라는 원문을 유지했다. 마지막의 일반적인 대안 나열은 세 선택의 반복 대신 비교, 대상, 지표 변경이 포기하는 질문을 드러내는 서술로 줄였다. 표의 위치는 바뀌지만 각 표 블록의 내용은 그대로다.

11장의 선택 이유는 이 책의 합성 사례를 구성한 이유다. 현장 경험이나 실험 성공을 추가하지 않았다. 기존 이력 문단과 프로젝트 경계, 각주, 한계, 효용 검증 조건은 그대로 두었다. 허재혁의 저자 표기, 세 축과 여섯 항목의 체계는 변경하지 않았다. 이름 설명을 합쳤으며 그 과정에서 세 축의 영어 명칭과 의미를 유지했다.

12장에서는 관측값을 없애 질문을 쉽게 만드는 대신 완료 하한과 철회 p를 각 주장의 근거로 판단하게 했다. 어떤 확인을 고르든 다른 미확인 조건과 보호 의무를 지우지 않는다. 회신별 행동은 작성할 분기이며 실제 회신이나 승인 기록이 아니다. 해설은 특정 확인 하나만 정답으로 요구하지 않는다. 원래 966~970행의 현재 보류, 역할별 요청, 미확인 답과 실제 승인 경계 및 980행의 기록 연결 안내는 그대로다.

## 재생 및 보존 검사 결과

디스크에 저장한 JSON을 읽어 원고 전체에 메모리상 순차 재생했다. 편집 5건 모두 기준 v20에서 단일 출현하며, 각 순차 적용 시점에서도 단일 출현했다. JSON 키 집합도 지정한 네 필드와 일치했다.

숫자 토큰은 `\d+(?:[,.]\d+)*`의 다중집합으로 비교했다. 새 숫자는 없고 삭제는 `1`, `2`, `3` 각 한 번뿐이다. 이는 12장 첫 세 질문의 순번 표지에 대한 명시 승인 예외다. 질문 속 `+0.26pp`, `0.3662`는 새 과제 안내에 보존했다. 6장 변경 블록의 숫자 다중집합은 완전히 같으며 다른 변경 블록에도 숫자 변경은 없다. 이 검사는 숫자의 순서 불변 검사가 아니다.

전권 각주 8개의 전체 HTML 문자열과 순서가 동일했다. 6장 각주도 이동 블록 안에 원문 그대로 남는다. 전권 fenced code는 전체 문자열과 순서가 동일했다. 6장의 표 5개는 표 블록 다중집합이 동일했다. 재배열이므로 표 출현 순서의 동일성을 요구하지 않았다. 원고 전체 앵커 다중집합도 동일했다. 모든 새 `after`에 가운데점 계열 U+00B7, U+2022, U+2027, U+318D, U+22C5, U+30FB가 없었다.

12장 982행의 사용 안내부터 984행의 완성 결정문 제목, 986~992행의 결정문과 마지막 보호 및 승인 경계까지 연속 문자열 전체가 동일했다. 결정문 다음의 빈 줄도 보존했다. 보호 범위는 `다음 결정문을 자신의 사례에 쓸 때는`부터 `# 찾아보기` 직전까지다. 합성 자료, 사후 교육용 기준, 실제 발송 없음, 보호 의무와 실제 승인 구분을 새로운 성과나 승인 주장으로 바꾸지 않았다.

재생 검사 뒤 원본의 바이트 SHA-256이 위 값과 동일함을 확인했다. 원고, PDF, 빌더와 다른 스크립트는 수정하지 않았다. 기존 PDF 인용 전수 대조와 전권 contact sheet는 실행하지 않았다. PDF를 열거나 생성하지 않았고 Git 변경 명령, 커밋, 푸시는 실행하지 않았다. 이번 작업이 쓴 파일은 이 폴더의 두 편집 장부뿐이다.
