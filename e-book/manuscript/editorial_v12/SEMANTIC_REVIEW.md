# v0.12 한국어 윤문 의미 보존 검토

## 판정

**핵심 통계 해석과 실제 승인 경계는 대체로 보존됐다. 다만 보호 의무의 행동 강도가 약해진 대목 1건(Medium), 안전 판단의 현 상태를 덜 명시한 요약 1건(Low)이 있어 무조건적인 의미 동등 판정은 하지 않는다.**

특히 12장의 추가 확인을 행동 분기로 바꾼 문단은 보호 평가와 필요한 설계·정보량을 전제로 두고, 조건 충족 후에도 실행이 아니라 **승인 요청**으로 연결한다. 비열등성 설계가 없는 탐색 결과를 안전 승인으로 바꾸거나, 미승인 제한 적용을 이미 실행한 것으로 바꾼 표현은 확인하지 못했다. 그러나 별도 보호 문단에서 원문의 명시적 **중단 사유**를 포괄적인 **대응**으로 바꾼 것은 복원이 필요하다.

이 문서는 원고 작성과 구분된 검토 작업에서 수행한 **AI 텍스트 비교 검토**다. 실제 사람의 검수·전문가 승인·외부 독립기관 검증이 아니며, 모델 간 독립성이나 오류 독립성도 보증하지 않는다.

## 1. 범위와 확인 방법

- 원문: `e-book/exports/v11/ebook_review_v11.md`의 1장, 5장, 6장, 12장 전체.
- 수정문: `e-book/manuscript/editorial_v12/ch01.md`, `ch05.md`, `ch06.md`, `ch12.md` 전체.
- 변경 장부: 같은 디렉터리의 `EDIT_CHANGES.json`에 기록된 전후 문단과 이유 29건. 아래 변경 번호는 `changes` 배열의 1부터 시작하는 순번이다.
- 실제 원문과 수정문을 모두 읽고 변경 문단뿐 아니라 앞뒤에 남은 제한·설계·결정문까지 대조했다. 장부의 수정 이유나 자동 검사 통과를 의미 보존의 증거로 대신 사용하지 않았다.
- 프로그램으로 장부 항목 수와 각 전후 문단의 실제 출현을 확인했다. 5장 7건, 6장 7건, 12장 14건, 1장 1건이며 모든 전후 문단은 해당 원문·수정문에 각각 한 번 존재했다.
- 원문 SHA-256은 장부의 `f2117f7a250b42c97972e4bbf314e3925661b3e820d6452976b829d303a88706`과 일치했다.
- 장부 치환으로 실제 수정 장을 재구성해 비교했다. 1·5·6장은 앞뒤 공백을 제외하고 일치했고, 12장은 문단 사이 빈 줄 한 줄의 제거만 추가로 확인됐다. 미기록 내용 변경은 확인되지 않았다. 네 장의 표 행과 fenced code는 원문과 동일했다.
- 숫자 토큰 순서와 영어 용어 집합 보존은 제공된 검사 결과를 참고했다. 이번 의미 판정은 분모·추정 대상·대비·조건·주장의 강도·실행 권한을 별도로 읽은 결과다.

### 심각도 기준

- **High**: 통계 결론이나 실행 권한을 뒤집거나, 근거 없는 안전·사업 성공 또는 실제 승인을 만들어 내는 변경.
- **Medium**: 핵심 의무·가정·행동 경계를 국소적으로 약화하여 다른 행동을 허용할 수 있는 변경. 주변 문맥의 보완 여부를 함께 판단한다.
- **Low**: 장 전체의 결론은 유지되지만 요약·단독 인용에서 오해 가능성이 늘어난 변경.
- **문제 미발견**: 읽은 문맥에서 실질적 의미 변화를 찾지 못했다는 뜻이며 완전한 동등성 보장은 아니다.

## 2. 구체적 발견 사항

### S-01 — 중단 사유가 일반적 대응으로 완화됨

- **Severity: Medium**
- 변경 20, 12장 보호 문단.
- 위치: 원문 753행 → `ch12.md` 70행.

**Before**

> 신규 적용에 필요한 보호 질문과 허용 한계를 후속 계획에 명시하고, 법적 권리 침해나 중대한 피해는 통계적 유의성을 기다리지 않는 중단 사유로 둔다. 이 원칙은 사후 0.2pp 예시와 별개다.

**After**

> 후속 계획에는 신규 적용에 필요한 보호 비교와 허용 한계를 명시한다. 법적 권리 침해와 중대한 피해는 통계적 유의성을 기다리지 않고 대응하며, 이는 사후 0.2pp 예시와 별개다.

**의미 차이와 영향**

원문은 법적 권리 침해 또는 중대한 피해를 운영의 중단 사유로 정한다. 수정문은 대응 시점은 유지하지만 대응 종류에서 중단을 빼므로, 조사·통보 등만 하고 운영을 지속하는 행동도 문장 자체로는 배제하지 못한다. 이는 단순한 면책 문장 축소가 아니라 보호 행동의 강도 완화다. 원문의 ‘나’를 ‘와’로 바꾼 것을 두 조건의 동시 충족 요구라고 단정하지는 않지만, 각 사유가 독립적으로 중단 근거가 된다는 명시성도 줄었다.

`ch12.md` 86행의 ‘안전상 운영 중지’와 106행의 ‘성과 유의성과 무관하게 보호 절차를 실행’이 위험을 줄인다. 그렇더라도 해당 피해를 **중단 사유로 둔다**는 원문의 연결을 완전히 복원하지는 않는다. 이 때문에 High나 실제 승인 조작으로 판정하지 않고 Medium으로 남긴다.

**권고 — 원고에는 미반영**

해당 문장에서 ‘법적 권리 침해나 중대한 피해는 통계적 유의성을 기다리지 않는 중단 사유로 둔다’는 행동 강도를 복원한다. 보호 평가·승인 요청 분기는 유지하되 이 의무를 일반적 대응으로 대체하지 않는다.

### S-02 — 관계 안전이 아직 통과되지 않았다는 현 상태가 요약에서 약해짐

- **Severity: Low**
- 변경 7, 5장 마지막 요약.
- 위치: 원문 231행 → `ch05.md` 45행.

**Before**

> 사업 최소 효과의 확정 충족은 별도이며 관계 안전도 통과했다고 말할 수 없다.

**After**

> 사업 최소 효과를 확정 충족했는지와 관계 안전을 통과했는지는 별도 판단이다.

**의미 차이와 영향**

원문은 사업 기준과 안전을 분리하면서, 안전 통과를 주장할 수 없다는 **현재 증거 상태**도 직접 남긴다. 수정문은 둘을 별도로 판단하라는 절차 설명으로 바뀌어, 안전의 현 상태는 이 한 문장만으로 알 수 없다. 회의용 요약만 떼어 쓰면 ‘별도 판단에서 이미 통과했을 수도 있다’는 여지를 남긴다.

다만 41행의 ‘차이를 발견하지 못했다는 결론을 안전 확인으로 바꾸지 않는다’, 43행의 사전 비열등성 설계 요구, 45행 마지막의 ‘미확인 조건까지 채우지 않는다’가 남아 있다. 따라서 안전을 실제 통과했다고 바꾸거나 장 전체의 통계 결론을 뒤집은 것은 아니다.

**권고 — 원고에는 미반영**

요약에도 ‘관계 안전은 통과했다고 말할 수 없다’ 또는 그와 동등한 현재 상태를 남긴다. 별도 판단이라는 원칙과 미확인이라는 상태를 함께 적는 편이 원문에 가깝다.

## 3. 12장 행동 분기 집중 확인

### 3.1 보호 평가·설계·정보량은 분기에 남아 있음

변경 24, 원문 769행 → `ch12.md` 86행.

**Before**

> 관계 위험을 확인할 설계와 정보량이 갖춰지지 않으면 신규 확대는 열지 않는다.

**After**

> 실제 도입 기준을 지지하는 근거와 보호 평가, 운영 가능 범위가 갖춰지면 제한 적용이나 새 실험의 승인을 요청한다. 보호에 필요한 설계와 정보량이 부족하면 확대를 열지 않고 그 확인을 우선한다.

**판정: 문제 미발견。** 근거·보호 평가·운영 가능 범위를 양의 분기 조건으로 세우고, 보호 설계와 정보량이 부족한 경우 확대를 열지 않는 음의 분기도 유지했다. ‘승인을 요청한다’는 승인 완료나 실행 사실이 아니다. 새 실험의 비교 정책·배정·결과 창·표본·분석·보호 조건을 다시 고정한다는 문장도 남았다. 단순 모니터링을 증분 효과의 실험으로 대체하지 못한다는 구분과 유의해질 때까지 원 실험을 연장하지 않는 규칙도 보존됐다.

‘독립 대조군 실험’이라는 표현 자체는 ‘증분 효과의 실험’으로 축약됐지만 같은 문단에 비교 정책과 배정 재고정이 있고, 통제 없는 모니터링을 효과 실험으로 승격하는 허용은 확인하지 못했다.

다음은 원문과 수정문에 그대로 남은 핵심 제약이다.

  > 더 근본적으로 원 계획에는 비열등성 한계와 대응 분석 설계가 없다. 이 양측 탐색 구간으로 정식 안전 통과나 실패를 판정하지 않고, 의미 있는 악화를 배제할 증거가 부족하다고 적는다.

**판정: 문제 미발견.** 양측 비유의 결과를 비열등성 안전 통과로 바꾼 변경이나, 사후 +0.2pp를 원래 사전 보호 기준으로 둔 변경은 확인하지 못했다. S-01은 이 통계 설계 부재와 별개로 보호 행동의 강도가 약해진 문제다.

**판정: 문제 미발견.** 선택을 바꾸지 않는 분석의 생략을 보호 평가나 의무 대응의 생략 승인으로 확장하지 않았다. S-01의 중단 사유 약화는 별도로 고쳐야 한다.

## 5. 유지된 구조와 숫자 의미

- TRI-V의 세 축인 **정화 / Variable Control**, **해체와 입체화 / Vector Segmentation**, **언어의 전환 / Value-Linked Decision**은 유지됐다. 네 번째 축이나 별도 검정법을 추가하지 않았다.
- 1장의 여섯 기본 기록 표는 동일하다: **지금 결정할 것**, **V1 믿고 쓸 근거와 제한**, **V2 적용 대상**, **V3 현재 선택**, **추가 확인 또는 생략**, **다시 검토할 조건**. 12장의 연결 설명이 이 표를 대체하거나 칸을 추가하지 않는다.
- 완료의 +0.93pp와 구간 [+0.26,+1.61]pp는 정한 완료 가족·분석 가정 아래 우위의 근거이며, +0.5pp 사업 최소 효과의 확정 충족으로 바뀌지 않았다.
- 철회의 탐색 구간과 p는 악화 없음의 확률이나 안전 통과로 바뀌지 않았다. +0.2pp는 사후 교육 기준이며, 같은 숫자의 탐지 표본 계획을 비열등성 설계로 재해석하지 않았다.
- 고객 수와 사건 수, 배정 전체 분모, 개인별 관측 창, 완료의 가족 보정과 철회·계약·손익의 탐색 지위가 유지됐다.
- 하루 등록 상한을 시승 수용 용량으로 바꾸거나, 계약·합성 순기여액을 실제 출고 이익·장기 가치로 바꾸지 않았다. 새 성과 수치·현장 경험·실험을 만들어 냈다는 변경은 확인하지 못했다.

## 6. 한계와 후속 처리

이 검토는 지정 네 장의 한국어 서술이 v11에서 v0.12로 바뀌면서 생긴 의미 이동을 판단한 것이다. 원문의 모든 통계 주장 자체가 옳다는 인증이나 책 전체 검증이 아니다. DB 원장·분석 코드·난수 생성·검정력·구간·법률 준수·회사 승인 기록을 재실행하거나 현장에서 확인하지 않았다. 원고가 기술한 기존 DB 확인 사실을 이번 검토자가 새로 수행했다고 주장하지 않는다.

전후 문단 대조와 문맥 검토에서도 AI가 함의를 놓칠 수 있다. 따라서 ‘문제 미발견’을 통계적 정확성·안전·수익·현장 적용의 보증으로 사용해서는 안 된다.

**권고 결론:** S-01은 의미 보존을 위해 복원하고 S-02는 회의용 요약의 명료성을 위해 보완한 뒤 해당 문단을 다시 대조한다. 이 보고서는 수정 권고만 남겼으며 수정 원고·코드·변경 장부는 변경하지 않았다. 생성한 파일은 이 `SEMANTIC_REVIEW.md`뿐이다.
