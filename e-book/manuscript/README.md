# 원고

저자 허재혁. 최신 읽기본은 `e-book/exports/v05/ebook_review_v05.md`와 같은 이름의 PDF다. 트리아타시스를 중심으로 새로 집필한29쪽 본책이다. 이전 원고와 보조자료는 보존했다.

`methodology_v05.md`는 들어가며와 방법론1~4장, `numbers_and_cases_v05.md`는 통계와 표본 및 사례1~3, `winner_cases_456_v05.md`는 사례4~6, `decision_and_sources_v05.md`는 마지막 판단과 자료 부록이다. 실제 계산 표와 도식은 빌드 때 기존 검증 결과에서 삽입한다.

본문은 장 제목과 여섯 사례 제목만 남긴 연속 서술이다. 가운데 점을 쓰지 않으며 트리아타시스와 TRI-V의 연결을 사례까지 유지한다. 저자 표현의 최종 확인과 사람의 통계 및 실무 검토는 아직 남아 있다.

v0.4의54쪽 본책과17쪽 워크북,60쪽 카드 참조편은 지난 판이다. 이번 윤문은 본책에 적용했으며 과거 보조자료까지 고쳤다고 간주하지 않는다.
