# 최소 기록 적용 예시

작성자가 고정 반례 P01에 적용한 예시다. 사람의 시간 절감 또는 실제 실행을 관찰한 기록이 아니다.

**실험과 기존 문서**

P01 / counterexample_fixture.json의 common_assumptions와 P01 / COUNTEREXAMPLE_RESULTS.json의 P01. 실제 승인 책임자는 미지정.

**지금 결정할 것**

현행 A 유지와 같은 적격 범위의 B 전환 가운데 B를 실행 후보로 넘길지 판단한다.

**V1 믿고 쓸 근거와 제한**

교육용 측정 가정 아래 완료 차이 +3.00pp, 95% 구간 [+1.75, +4.25]pp. 보호 단측 상한 +0.222pp는 예시 한계 +0.50pp 아래. 각 출처는 위 JSON 참조. 실제 기업의 결과가 아니다.

**V2 적용 대상**

배정과 분석 및 적용 모집단의 적격 조건과 정책이 같다는 가정. 효과 균일성이나 다른 대상과 장기 적용은 주장하지 않는다.

**V3 현재 선택**

실행 후보. 예시 성과와 보호 조건은 충족하지만 실제 승인과 발송은 수행하지 않았다. 승인 책임자 지정과 기존 승인 절차는 별도다.

**추가 확인 또는 생략**

현재 선택을 위해 목적 없는 세분화와 금전 모형은 추가하지 않는다. 실제 승인, 보호 및 감사 의무는 기존 경로를 따른다. 새로운 데이터 수집을 자동 요구하지 않는다.

**다시 검토할 조건**

대상과 접촉 정책, 측정 또는 용량과 간섭 가정이 바뀌거나 새로운 보호 위험이 생기면 근거와 범위를 다시 본다.
