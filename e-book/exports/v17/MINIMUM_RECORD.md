이미 작성된 계획과 분석은 링크로 재사용한다. 최소 양식이라는 이유로 실험 명세를 생략하지 않는다. 링크에서 대비, 적격 대상과 동의, 배정 및 분석 단위, 주지표와 분모, 관측 및 종료, 비교 가족과 다중성, 사업과 보호 기준을 확인할 수 없으면 먼저 그 공백을 보완한다.

| 기록 | 한 문장 또는 기존 근거 링크 |
|---|---|
| 지금 결정할 것 | 가능한 대안과 적용 범위를 적는다. 전체 전환, 제한 적용, 현행 유지와 새 검증 중 무엇을 판단하는지 먼저 정한다. |
| V1 믿고 쓸 근거와 제한 | 주지표와 보호 지표의 결과 위치, 사용할 수 없는 근거가 있으면 범위를 적는다. |
| V2 적용 대상 | 배정, 분석, 적용 대상이 같으면 같다고 적는다. 다르면 차이와 근거만 적는다. |
| V3 현재 선택 | 실행 후보, 조건부 실행 후보, 추가 확인, 미확대 또는 운영 중단 제안. 보호와 실제 승인 상태를 함께 적는다. |
| 추가 확인 또는 생략 | 어떤 확인 결과가 어떤 선택을 바꿀지 적는다. 필요하면 담당과 기한을 연결하고 생략하면 이유와 예외를 남긴다. |
| 다시 검토할 조건 | 어떤 관측이나 가정 변화가 선택을 바꿀지 적는다. 추가 분석 중단, 통계적 실험 종료와 운영 중지를 구분한다. |

## 필요한 경우에만 상세 기록을 연다

- 측정이 제한되면 해당 주장과 종속 지표, 복구 검사만 추가한다.
- 적용 대상이나 정책이 달라지면 사전과 사후, 확증과 탐색 및 필요한 직접 집단 비교만 추가한다. 적절한 사전 확증 근거가 이미 있으면 무조건 재실험을 요구하지 않는다.
- 비용과 용량의 불확실성이 선택을 바꿀 수 있으면 범위의 근거와 민감도만 추가한다. 범위를 정당화하지 못했으면 확인을 생략하지 않는다.
- 필요한 계약, 보호 조건 또는 실제 승인이 없으면 누락을 임의로 채우지 않고 확인 책임과 현재 제한을 적는다.

상세 기록이 필요하면 기존 v0.2 양식을 해당 부분만 참조한다. 모든 실험에서 전체 상세 양식을 다시 작성하지 않는다. 보호와 권리 대응, 법정 감사와 다른 사업 목적의 확인은 선택 불변만으로 면제되지 않는다. 실행 후보는 실제 실행이나 사람의 승인을 대신하지 않는다.

B를 채택하지 않았다는 이유로 A가 모든 대안 중 최적이라고 쓰지 않는다. 이번에 비교한 대안과 범위 안에서 현행을 유지하는 선택과 최적성의 증명은 다르다. 추가 분석을 그만하는 판단은 사전에 정한 실험 종료 규칙을 바꾸거나 보호 대응을 늦추는 근거가 아니다.
