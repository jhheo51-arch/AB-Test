# JH Motors — 가상 기업 설정 v0.1

저자: 허재혁. JH는 저자명과 연결되는 작업명으로 선택했다. 기업명은 임시 제안이며 실제 기업·상표를 확인한 것이 아니다.

## 학습용 가정
- 단일 시장의 가상 승용차 OEM. 수도권·중부·남부 권역에 12개 판매 접점.
- SUV·세단·크로스오버 차종. 실제 브랜드의 모델·가격·성능을 재현하지 않는다.
- 직영 CRM과 판매 파트너의 예약·시승 결과를 고객 ID로 연결하는 단순 모델.
- 전체 여정: 관심 등록 → 시승 예약 → 시승 완료 → 상담 → 계약 → 출고 → 보유·정비 → 교체.
- 현재 구현은 시승 예약·완료·취소·수신 거부까지. 계약·매출·LTV는 미구현.

## 실험
수신 동의가 있고 시승 이력이 없는 잠재 고객에게 A 차량 가치 안내와 B 시승 편의 안내를 고객 단위 무작위 배정한다.
주지표: 배정 후 28일 내 시승 완료 / 배정 고객 전체. 전달 실패도 포함한다.
보조지표: 예약. 가드레일: 수신 거부. 무발송 대조군이 없어 무발송 대비 효과를 주장하지 않는다.

## 현실의 경계
가구 중복·접점 수용량·군 간 간섭·계약 지연·장기 소유 관계는 아직 모델링하지 않았다. 실제 배정 설계나 OEM의 영업 구조를 대표하지 않는다.
모든 확률·비용·고객 이벤트는 교육용 합성 가정이다.
