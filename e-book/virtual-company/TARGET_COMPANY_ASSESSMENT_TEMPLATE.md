# 희망 기업 CRM 평가 템플릿
저자: 허재혁. 공개 정보에 근거한 외부 관찰·실험 설계 제안이며 해당 기업의 내부 감사/실제 캠페인 성과 평가가 아니다.

## 1. 평가 범위
- 기업·브랜드·시장·조사 날짜:
- 고객 여정·채널·고객군:
- 평가 질문:
- 실제 기업 관찰과 합성 예시 구분:

## 2. 근거 장부
| 주장 ID | 공개된 사실·직접 관찰 | URL·문서·페이지 | 자료 기준일·확인일 | 추정·해석 | 아직 알 수 없는 것 |
|---|---|---|---|---|---|

공식 공시·공식 정책·직접 확인한 공개 여정과 제3자 주장을 구분한다. 마케팅 문구는 실제 성과 증거가 아니다. 로그인·유료·내부 자료는 권한 없이 접근하지 않는다.

## 3. Company Profile
판매 구조 / 고객·가구·차량 단위 / 데이터 연결 / 동의·개인정보 / 채널 / 장기 구매 주기 / 운영 수용량 / 비용·마진 / 트래픽 / 조직 권한 / 현재 실험 방식.
각 항목은 known·estimated·unknown·not_applicable·unsupported 중 하나와 근거를 기록한다.

## 4. 고객 여정 관찰
| 단계 | 공개적으로 관찰한 접점 | 고객의 가능한 장벽(가설) | 관찰하지 못한 내부 상태 | 제안 지표 |
|---|---|---|---|---|

## 5. TRI-V 적용
### V1
대상·동의·배정 단위·대조·지표 정의·기간·표본 계획·추적·검사·운영 권한. 공개되지 않은 배정 품질을 실패라고 단정하지 않는다.
### V2
사전 고객군 가설·효과 차이의 근거·탐색과 확증·다중성. 실제 집단별 효과가 없으면 가설로 표시한다.
### V3
비용·가치·관계·운영 위험·최소 관심 효과·판단 기준. 실제 원가와 효과가 없으면 시나리오 가정으로만 계산한다.

## 6. 제안 실험
- 무엇을 바꾸고 무엇과 비교하는가:
- 실제 실행 가능성·윤리·안전 경계:
- 주지표·가드레일·관측 기간:
- 표본 설계에 필요한 내부 입력:
- 진단 카드 ID와 연결:
- 설계가 답하지 못하는 질문:
- 합성 시뮬레이션 입력·결과의 표기:

## 7. 결론
공개 근거로 말할 수 있는 것 / 추정하는 것 / 말할 수 없는 것 / 추가 내부 데이터 / 다음 검증.
출처·로고·화면·명예·권리 관련 출판 검토가 완료되기 전 실제 기업에 대한 단정적 평가로 출간하지 않는다.
