# 표지와 포지셔닝 검토 자료

공개 표지의 출처와 실제 열람 범위는 SOURCES.json, 제목 판단의 수정과 세 AI 역할 비평의 종합은 SYNTHESIS.md에 기록했다. 페르소나 검토는 실제 독자 인터뷰나 시장 투표가 아니다.

제삼자 표지의 재배포 권한을 확인하지 않았으므로 reference_*.png와 그 이미지를 내장한 BENCHMARK.html 및 POSITIONING_REVIEW.html은 로컬 연구 자료로만 보존하고 GitHub 동기화에서는 제외했다. 원래 파일을 삭제한 것은 아니다. 이 폴더의 해당 HTML을 생성하거나 화면 검사를 실행하려면 출처 자료와 이용 조건을 먼저 확인해야 하며, 이미지가 없는 새 체크아웃에서 실행 가능하다고 보장하지 않는다.

자체 작성한 평가, 출처 목록, 인용 대조 기록과 생성 및 검사 코드는 보존한다. 최신 본책과 읽기 묶음에는 외부 책 표지 이미지를 포함하지 않았다. 최신 개정은 [v19 실제 변경](../../design/v19/DEVELOPMENT.md)을 따른다.
