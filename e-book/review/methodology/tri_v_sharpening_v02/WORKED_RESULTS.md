# 산출물 개정의 조건변형 적용 결과

고정 교육용 자료의 개발 검사다. 실제 사람의 비교시험과 효과 검증은 아니다.

## C01 완료 원장 결함은 어느 주장까지 전파되는가

기존 합성 쿠폰 자료의 교육용 조건변형. 새 현장 실험이나 실제 사전등록 아님. 기록은 완성 예시이며 실제 참여자의 응답이 아님. 완료 원장 불완전과 철회 원장의 독립 대사가 확인됐다는 가상 조건을 추가한다. 실제 원장에서 결함을 발견한 것이 아니다.

| 주장 | 측정 상태 | 추론 상태 | 허용할 문장 | 금지할 해석 |
|---|---|---|---|---|
| completion | limited | not_evaluated | 완료 차이를 현재 근거로 평가하지 않음 | 불완전한 완료 수치로 승자를 선택 |
| profit | limited | not_evaluated | 완료 기반 이익 차이도 현재 근거로 평가하지 않음 | 원본 정답을 알고 있다는 이유로 이익 추정을 사용 |
| withdrawal | available | inconclusive | 독립 대사됐다는 조건에서 철회 비교만 남김. 보호 한계 내라는 근거는 부족 | 완료 원장 결함을 모든 지표 무효로 확대하거나 철회 비교로 전체 안전을 승인 |

**적용 범위:** 현재 실험의 모집단과 대비 안에서만 해석

**현재 선택:** 현재 손상된 근거로 B 확대를 승인하지 않고 완료와 종속 이익의 비교를 보류

**재판단 조건:** 완료 원장의 누락 범위와 복구 결과가 확인됨 / 철회 원장의 독립 대사 가정이 깨짐

**다음 확인:** 완료 누락과 이익 영향 범위를 복구할 수 있는가

필요 자료: 배정 ID별 완료 원천과 집계 경로 대사, 누락 및 중복과 관측 창

담당 역할과 기한: 데이터 원장 책임자 / 미정. 해당 역할이 실제 기한과 재판단 담당자를 정해야 함

수용 조건: 원천과 집계가 고객 단위로 대사되고 잔여 결함의 영향 범위를 명시

충족하면: 해당 지표와 종속 이익만 재추정하고 원 계획 기준으로 재판단

미충족이면: 복구 불가능한 현재 주장은 제한을 유지하고 새 수집 설계를 검토

**지금 생략 검토:** 손상된 완료 결과를 세그먼트와 고급 모형으로 더 세분화

이유: 현재 비교 근거를 복구하지 못하며 원본 정답 유입 위험이 있음

예외: 결함 범위 진단을 위한 분할은 허용. 독립 유효 지표를 폐기하지 않음

| 주장 | 측정 상태 | 추론 상태 | 허용할 문장 | 금지할 해석 |

**다음 확인:** 첫 이용 대상의 후속 정책 검증을 설계할 사업 필요가 있는가

필요 자료: 실제 원가와 적격 대상, 기존 확증 범위, 보호 조건, 정보량 및 운영 용량

담당 역할과 기한: 실험 기획 책임자 / 미정. 해당 역할이 실제 기한과 재판단 담당자를 정해야 함

수용 조건: 정책 대비와 사업 필요가 정의되고 설계 및 책임자가 승인할 수 있음

충족하면: 새 자료를 보기 전에 필요한 후속 검증을 고정

미충족이면: 추가 고객 노출과 데이터 수집을 자동으로 진행하지 않음

**지금 생략 검토:** 좋게 보이는 고객군을 계속 찾아 즉시 적용

이유: 원 실험의 실패를 지우고 선택 편향과 다중 비교를 키울 수 있음

예외: 별도 탐색 목적과 가족을 밝힌 연구는 가능하되 현재 확증으로 쓰지 않음

## C04 정밀 원가 재추정이 현재 선택을 바꾸는가

기존 합성 쿠폰 자료의 교육용 조건변형. 새 현장 실험이나 실제 사전등록 아님. 기록은 완성 예시이며 실제 참여자의 응답이 아님. 기업 부담액의 범위가 가상 검토에서 정당화됐다는 조건이다. 실제 재무 검증이 아니다. 소비자 쿠폰과 결과는 그대로이고 비용 분담 및 처리비를 포함한 기업 순부담만 변한다.

| 주장 | 측정 상태 | 추론 상태 | 허용할 문장 | 금지할 해석 |
|---|---|---|---|---|
| profit_range | available | supports_decrease | 가상으로 근거가 확인된 기업 순부담 범위 안에서 각 조건부 구간의 상한도 음수 | 가정 범위 밖의 실제 비용이나 모든 금전 불확실성까지 해결했다고 주장 |

**적용 범위:** 현재 실험의 모집단과 대비 안에서만 해석

**현재 선택:** 전체 B 확대를 제안하지 않음

**재판단 조건:** 부담액 범위의 정당화가 철회되거나 실제 비용이 범위 밖임 / 완료 원장, 대상 구성 또는 비용의 적용 단위가 바뀜 / 현재 미확인인 보호와 운영 조건에 새 정보가 생김

**다음 확인:** 정당화된 범위와 측정 조건이 계속 유지되는가

필요 자료: 범위 산출 근거와 실제 정산의 예외, 완료 원장의 변화

담당 역할과 기한: 재무 검토 책임자 / 미정. 해당 역할이 실제 기한과 재판단 담당자를 정해야 함

수용 조건: 제시 범위와 비용 단위 및 측정 조건이 유지

충족하면: 현재 B 미확대 판단을 위해 정밀 비용 점추정을 더 요구하지 않음

미충족이면: 범위와 모형을 다시 정당화하고 민감도를 재계산. 이것만으로 B 승인을 내리지 않음

**지금 생략 검토:** 현재 전체 B 미확대 결론만을 위해 순부담액을 정밀 점추정

이유: 정당화된 범위 안에서 해당 선택의 근거 방향이 바뀌지 않음

예외: 범위 근거 미확인, 다른 정책 질문, 실제 결산과 법정 감사 및 보호 의무는 생략하지 않음

## 비용 가정의 실제 재계산

고객 쿠폰은 1만원으로 고정하고 기업의 완료당 순부담만 바꾼 사후 민감도다. 분담 및 처리 비용 변화가 고객 반응과 다른 조건을 바꾸지 않는다고 가정한다.

| 완료당 기업 순부담 | 고객당 이익 B-A | 조건부 95% 구간 |
|---|---|---|
| 8,000원 | -1,200원 | [-1,697, -703]원 |
| 10,000원 | -1,600원 | [-2,084, -1,116]원 |
| 12,000원 | -2,000원 | [-2,472, -1,528]원 |

설정한 범위의 조건부 상한 최대는 -703원이다. 범위의 정당성이 확인됐다는 교육용 조건 아래 현재 B 미확대 판단을 위해 정밀 원가 점추정을 더 요구하지 않을 수 있다. 범위 자체를 확인하지 못했거나 별도 보호와 결산 의무가 있으면 생략할 근거가 되지 않는다.

완성 기록은 TRI-V 4개와 표준 참조 4개 모두 같은 규칙을 충족했다. 고의 오류 10개는 해당 규칙에서 거부됐다. 사람의 관찰 자료는 0행이다. 이 수치를 정확도나 시간 절감률로 바꾸지 않는다.
