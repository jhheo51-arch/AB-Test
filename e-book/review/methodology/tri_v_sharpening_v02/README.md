# TRI-V 산출물 v0.2 저자 검토 묶음

먼저 `DIRECTION_AND_OUTPUT_CONTRACT.md`에서 전후 변경을 보고 `WORKED_RESULTS.md`에서 적용 결과를 읽으세요. `DECISION_RECORD_TEMPLATE.md`는 실제 작성용 빈 양식입니다. `FAIR_COMPARISON_PROTOCOL.md`는 표준 절차의 참조 정의와 비교의 한계 및 아직 수행하지 않은 사람 시험의 준비 기준입니다.

이 묶음은 저자와 개발 검토용입니다. 완성 기록과 검사 답을 포함하므로 실제 참여자에게 전체 묶음을 주지 않습니다. 기존 독자 시험을 시행하거나 대체한 것이 아닙니다. 이번 작업에서 실제 참여자를 모집하거나 외부 공유하지 않았습니다.

`WORKED_RECORDS.json`과 `REFERENCE_WORKED_RECORDS.json`은 같은 정보와 결론을 갖는 개발용 완성 예시입니다. 사람의 응답이 아니며 표준 절차가 실제로 더 느리거나 오류가 많다는 증거가 아닙니다. 검사기는 이 예시와 함께 설계했습니다. 고의 오류가 거부되더라도 독립 검수, 일반 오류 검출 성능 또는 실무 효과의 입증이 아닙니다.

원자료는 앞선 가상 서비스 쿠폰 사례의 고객별 고정 입력입니다. 측정 제한과 적용 요청 및 비용 범위는 따로 밝힌 교육용 조건변형이며 원자료를 변경하지 않습니다. 비용 범위 안의 조건부 구간은 실제 원가의 신뢰구간이 아니고, 소비자 혜택 변경의 행동 반응이나 모든 금융 불확실성을 반영하지 않습니다. 원가 범위가 정당화되지 않았으면 확인을 생략하지 않습니다. 철회 score 계산은 기존 계산 JSON을 출처와 함께 재사용했으며 새 스크립트가 그 검정을 독립 재계산한 것은 아닙니다.

`OBSERVATIONS.csv`는 실제 관찰 전의 헤더만 있는 파일입니다. 실제 독자의 누락, 총 작업 시간, 확인 비용과 조직 성과가 개선됐다는 주장은 아직 할 수 없습니다. 시행 주체와 최종 판단은 저자에게 있습니다.

## 재현

ZIP을 풀어 `scripts`와 `e-book`이 있는 프로젝트 루트에서 실행합니다. Python 표준 라이브러리만 사용합니다.

```sh
python scripts/test_tri_v_outputs_v02.py
```

실행하면 기존 합성 CSV의 해시와 주지표 계산을 대조하고 비용 민감도, 완성 기록 검사, 고의 오류 검사를 수행합니다. 실제 사람 관찰이 들어 있으면 개발용 준비 상태 검사에서 멈추므로, 시행 후 관찰을 보존하고 별도 분석 절차로 전환해야 합니다. 관찰을 지워 검사를 통과시키지 마세요.

현재 스크립트는 준비 상태에서 생성 보고서와 ZIP을 갱신합니다. 기존 원자료와 v0.10 읽기본은 쓰지 않습니다. 패키지의 실제 파일 수와 해시는 `PACKAGE_CHECK.json`에 기록합니다. ZIP에는 이 폴더의 검토 파일, 스크립트와 재현에 필요한 이전 사례의 고정 입력, CSV 및 계산 결과를 포함합니다. 전체 전자책과 과거 DB는 포함하지 않습니다.

PDCA는 기존 판단 틀로 남기고 이번 작업에서 확장하지 않습니다. TRI-V 원래 세 축을 유지한 산출물 개정 검토안이며 본책 전체에 적용하거나 출간 승인한 판본이 아닙니다.
