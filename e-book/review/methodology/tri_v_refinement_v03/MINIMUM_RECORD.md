이미 작성된 계획과 분석은 링크로 재사용한다. 최소 양식이라는 이유로 실험 명세를 생략하지 않는다. 링크에서 대비, 적격 대상과 동의, 배정 및 분석 단위, 주지표와 분모, 관측 및 종료, 비교 가족과 다중성, 사업과 보호 기준을 확인할 수 없으면 먼저 그 공백을 보완한다.

| 기록 | 한 문장 또는 기존 근거 링크 |
|---|---|
| 지금 결정할 것 | 무엇을 누구에게 적용할지 정한다. |

| V3 현재 선택 | 실행 후보, 조건부 실행 후보, 추가 확인, 미확대 또는 중단 제안. 보호와 실제 승인 상태를 함께 적는다. |
| 추가 확인 또는 생략 | 필요하면 질문과 조건별 행동, 담당과 기한을 연결한다. 필요 없으면 생략 이유와 예외를 적는다. |
| 다시 검토할 조건 | 어떤 관측이나 가정 변화가 생기면 현재 선택을 다시 볼지 적는다. |

## 필요한 경우에만 상세 기록을 연다

- 측정이 제한되면 해당 주장과 종속 지표, 복구 검사만 추가한다.
- 적용 대상이나 정책이 달라지면 사전과 사후, 확증과 탐색 및 필요한 직접 집단 비교만 추가한다. 적절한 사전 확증 근거가 이미 있으면 무조건 재실험을 요구하지 않는다.
- 비용과 용량의 불확실성이 선택을 바꿀 수 있으면 범위의 근거와 민감도만 추가한다. 범위를 정당화하지 못했으면 확인을 생략하지 않는다.
- 필요한 계약, 보호 조건 또는 실제 승인이 없으면 누락을 임의로 채우지 않고 확인 책임과 현재 제한을 적는다.

상세 기록이 필요하면 기존 v0.2 양식을 해당 부분만 참조한다. 모든 실험에서 전체 상세 양식을 다시 작성하지 않는다. 보호와 권리 대응, 법정 감사와 다른 사업 목적의 확인은 선택 불변만으로 면제되지 않는다. 실행 후보는 실제 실행이나 사람의 승인을 대신하지 않는다.
