# 저자 경험에서 가져온 실무 검토 기준

사용자가 제공한 이미지와 후속 발언을 경험의 출처로 삼는다. CRM LOOP와 Aurora의 원문 발췌는 SOURCE_EVIDENCE.md에 대조했으며 원 분석과 Salesforce 테스트를 이번에 재실행한 것은 아니다. 이미지의 수치와 프로젝트 설명을 경험적 동기로 활용하되 TRI-V의 시간 절감, 누락 감소 또는 무작위 A/B 성과의 비교 증명으로 바꾸지 않는다. 당시부터 TRI-V라는 이름이나 현재의 양식을 사용했다는 기록은 확인하지 않았다. 다음 항목은 프로젝트에서 통계적 효과가 있었다는 주장보다 무엇을 확인한 뒤 판단해야 하는지를 보여주는 기준이다.

| 이미지에 제시된 경험 | 무엇을 반드시 확인하는가 | 어떤 조건에서 다음 단계로 넘어가는가 | 무엇을 지금 더 하지 않는가 | 근거 상태 |
|---|---|---|---|---|
| 정보통신 소대장으로 군단 노드 연결의 구성과 경로 대안을 여러 차례 시험하고 실패 원인을 기록 | 대안별 조건, 확인한 실패와 선택한 기준을 구분 | 요구 조건을 충족한 근거와 남은 위험을 설명할 수 있음 | 원인 구분 없이 같은 시험을 반복하거나 이를 당시의 무작위 A/B였다고 명명 | 제공 이미지와 저자 진술. 실제 군 기록, 구체 구성, 시험 횟수와 개선 수치는 미확인 |
| CRM LOOP의 정제한 753,458줄과 대상 666명 | 행과 사람의 단위를 구분하고 대상 선정과 제외 근거를 연결 | 적격 조건과 제외 사유를 추적할 수 있음 | 전체 행 수를 실제 발송 인원이나 실험 표본으로 바꾸거나 설명 없는 세분화를 계속함 | CRM LOOP의 고객 가치, 캠페인 기획과 README 원문 확인. 실제 발송 캠페인은 없고 A/B 성과가 아님 |
| MC의 열람률과 미발송 수치를 그대로 믿지 않는 판단 | 이벤트의 의미와 분모, 미발송의 조건과 이유 중 실제 확인한 범위를 확인 | 유효한 지표의 사용 범위와 사용할 수 없는 해석이 구분됨 | 신뢰하지 못하는 열람률만으로 승자를 고르거나 전달된 고객만 남겨 원 배정 비교를 대체함 | 제공 이미지. 구체 계정 구성과 실제 발송, 이벤트 감사는 별도 확인 필요 |
| Aurora의 안전 VOC 생성+2시간과 정보 누락 시 저장 0건 | 생성 기준 응답 기한 계산과 팀장 이관에 필요한 담당 정보의 저장 차단을 확인. 차주와 차량 공란인 접수는 허용 | 원 프로젝트의 시간 조건과 누락 입력 처리 규칙을 실제로 확인하고 그 범위에 한해 판단 | 필수 이관 정보가 없는 입력을 통과시키거나, 보완 가능한 공란까지 이유 없이 모두 차단함 | Aurora PRD의 T4 기한 계산, T7 공란 접수 허용, T8 VOC-H 저장 차단 기록 확인. 이번 재실행과 실제 처리시간 감소 측정은 아님 |

MC의 원 문서를 이번에 특정하지 못했으므로 특정 원인이나 실제 발송을 확인했다고 쓰지 않는다. Aurora의 생성+2시간은 기한 계산 기준이지 생성 후 2시간 이내 실제 처리 완료를 뜻하지 않는다. VOC-H 저장 0건을 모든 누락 입력 차단으로 넓히지 않는다. CRM LOOP의 753,458줄과 666명으로 전환율, 표본 규모나 감소율을 만들지 않는다.

## 쓸 만한지 판단할 관찰 기준

**추적 가능성:** 같은 기록을 읽는 사람이 대상 선정, 지표 사용 제한, 시간과 입력 경계 및 선택의 이유를 원 자료 위치까지 따라갈 수 있는가.

**위험한 누락 방지:** 행과 사람의 혼동, 불신할 지표로 승자 선언, 필요한 입력 없이 진행, 유효한 사전 집단 근거의 불필요한 재실험, 충분한 근거가 있는데도 무기한 보류 같은 오류를 줄이는가.

**정당한 생략:** 선택을 바꾸지 않는 세분화, 정상 경로의 반복 또는 정밀 추정을 생략할 근거를 설명하는가. 보호 대응과 감사 의무는 생략하지 않는다.

**작업 부담:** 안내를 읽고 기존 자료를 찾고 기록하는 시간을 모두 포함한다. 새 양식에 기존 명세를 다시 입력한 횟수와 판단에 쓰이지 않은 추가 확인을 기록한다. 시간 절감과 오류 감소의 수치는 실제 관찰이 있을 때만 제시한다.

이 기준은 이미지의 경험에서 추출한 평가 항목이다. 개선이 이미 입증됐다는 결과표가 아니다. 저자 자신의 과거 작업은 동기와 적용 사례로, 앞으로의 비교 수행은 실제 효용 확인으로 구분한다. 소규모로 적용하고 수정할 수 있으며 모든 조직의 현장 우월성을 출간 선행조건으로 요구하지 않는다.
