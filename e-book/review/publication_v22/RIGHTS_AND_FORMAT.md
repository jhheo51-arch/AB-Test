# v0.22 권리와 제출 형식 검토

## 결론과 범위

출판사에 편집 검토를 요청할 파일과 자료는 있다. 그러나 특정 출판사나 유통처가 정해지지 않았으므로 판매용 규격 적합, 권리의 최종 승인이나 접수 완료로 판정하지 않는다. 이 문서는 실제 파일과 공개 공식 안내를 읽은 AI 검토이며 법률 자문이나 출판사의 승인서가 아니다. 원고와 PDF 및 배포 ZIP은 변경하지 않았다.

## 실제 파일 확인

- PDF 제목은 ‘그래서, 이 캠페인 계속할까요?’, 저자는 허재혁, 문서 주제에는 저자 검토본0.22가 들어 있다. PDF는 97쪽이며 표지와 메타정보 모두 판매 확정본으로 바꾸지 않았다.
- 선언된 판형은 190×270mm이고 실제 PDF 좌표의 환산은 약 190.16×269.92mm다. 브라우저 출력의 수치와 명목 판형을 구분한다. 특정 인쇄소의 허용 오차나 재단 규격을 통과했다고 판정하지 않는다.
- PDF 목차 항목 66개와 링크 545개를 확인했다. 이는 이번에 모든 외부 링크와 모든 인용의 정확성을 검증했다는 뜻이 아니다.
- PDF에는 Type3 글리프 리소스 140개와 Consolas Type0 리소스 한 개가 있다. Type3는 글리프 프로그램이 모두 존재하므로 단순히 TTF로 추출되지 않는다는 이유로 미임베딩이라고 판정하지 않는다.
- ZIP은 45개 항목이고 CRC 검사를 통과했다. PDF와 웹 읽기본, 작성 양식, 그림과 글꼴, 라이선스 및 검수 기록이 있다. 전체 고객 DB는 없으며 파일 목록에서 비교용 제삼자 책 표지 사본은 확인되지 않았다. 읽기 ZIP이 분석 전체를 재현하는 환경이라고 주장하지 않는다.
- EPUB이나 판매처 전용 표지, 판권과 상품 메타데이터를 이번 검토에서 만들지 않았다.

근거: TECHNICAL_RIGHTS_CHECK.json, LICENSE_SOURCE_CHECK.json 및 v22의 기존 package_smoke_v22.json.

## 글꼴 및 도구 라이선스

| 대상 | 실제 확인 | 판정 범위 |
|---|---|---|
| Noto Sans KR WOFF2 | 내장 저작권과 OFL 정보, 동봉 LICENSE-sans.txt 확인 | 동봉 근거 있음. 최종 배포의 모든 조건을 법적으로 승인한 것은 아님 |
| Noto Serif KR WOFF2 | 내장 Adobe 저작권 및 OFL 정보 확인. 동봉 LICENSE-serif.txt의 Google 2012 표기는 현재 Google Fonts 공식 OFL.txt와 전체 텍스트가 일치함 | 내장 저작권과 안내 파일 표기만 달라 보인다는 이유로 잘못된 라이선스로 확정하지 않음. 글꼴 출처와 동봉 기록을 함께 유지 |
| Consolas PDF 서브셋 | 실제 PDF에서 확인. 임베딩 플래그 fsType=8로 편집 가능한 문서 임베딩 표시. Microsoft 공식 FAQ의 문서 임베딩 안내 확인 | Noto 두 글꼴만으로 실제 사용 글꼴 전부를 설명하면 안 됨. 문서 임베딩과 폰트 파일 재배포는 별개. 적법한 사용 환경과 조건 준수 전제 |
| Paged.js | 동봉 MIT 라이선스와 저작권 고지 확인 | 해당 코드 배포 시 고지를 유지. 이 라이선스가 도서 전체의 권리를 대신하지 않음 |

공식 자료의 실제 열람:

- Google Fonts Noto Serif KR OFL: https://raw.githubusercontent.com/google/fonts/main/ofl/notoserifkr/OFL.txt
- Microsoft Font redistribution FAQ의 일반 이용 및 Document embedding 절: https://learn.microsoft.com/en-us/typography/fonts/font-faq

두 주소 모두 이번 조회에서 HTTP 200으로 본문을 읽었다. 설치된 글꼴의 유효한 이용 권한이나 계약 전체를 인증한 것은 아니다. 폰트 원본을 별도 상품처럼 배포하지 않고 현재의 고지와 메타데이터를 보존한다.

## 인용과 고유명, 저자 이력

- 원고 1255~1301행에서 주요 참고자료와 실제 열람 범위 및 용도를 구분한다. 프로젝트 문서와 합성 자료는 현장 성과나 방법론 인증으로 소개하지 않는다.
- 원고의 참고문헌 및 확인 기록이 있다는 것과 모든 직접 인용의 정확성 및 이용 범위가 최종 확인됐다는 것은 다르다. 기존에 동의 차단된 PDF 인용 전수 대조는 이번에도 수행하지 않았다.
- JH Motors와 TRI-V의 명칭 및 최초성, 상표와 출판물에서의 사용 위험을 법적으로 확정하지 않았다. 저자 제안의 교육 방법론 소개와 독점적 브랜드 권리 주장은 구분한다.
- 실제 제조사의 공개 자료를 배경으로 사용한 것과 해당 회사의 승인을 받았다는 것은 다르다. 제휴나 감수를 받은 것으로 보이는 광고 문구를 새로 쓰지 않는다.
- 저자의 이력과 1인칭 경험은 저자 최종 확인 대상이다. 실제 발송 캠페인이나 검증된 방법론 효율로 바꾸지 않는다.
- AI 지원을 받은 제작 과정은 실제 기록과 일치하게 다루고, 투고처가 요구하는 고지에 맞춘다. 사람 단독 집필 또는 AI 비관여라고 보장하지 않는다. 특정 고지 의무가 모든 출판 경로에서 같다고 단정하지 않는다.

## 판매 전에 정할 형식과 승인

1. 출판사 투고, PDF 직접 판매, EPUB 유통 가운데 실제 경로와 제출처를 정하고 그 공식 요구사항을 대조한다.
2. 사람의 최종 원고 교정과 통계 해석 검토를 거친다. 이번 자동 파일 점검이나 AI 편집 의견을 사람의 감수로 표시하지 않는다.
3. 최종 판권과 버전 표시, 표지 및 상품 설명, 파일 형식과 미리보기, AI 고지와 권리 확인을 해당 경로에 맞춰 마감한다. ISBN과 납본 등 적용 사항은 실제 출판 방식과 담당 주체를 정한 후 확인한다.
4. 저자가 최종 배포 파일을 보고 승인한다. 현재 ‘저자 검토본’ 표기를 승인 없이 판매 확정본으로 바꾸지 않는다.

실제 독자시험은 저자가 직접 진행한다는 기존 결정을 유지한다. 독자시험과 OEM 실무자의 검토는 학습 및 실무 적용 주장의 근거를 보완하지만, 이를 모든 출판 경로의 법적 의무라고 설명하지 않는다. 현재 단계에서 새 사례나 이론을 추가할 필요를 뜻하지도 않는다.
