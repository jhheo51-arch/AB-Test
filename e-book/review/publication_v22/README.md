# v0.22 출판 검토 자료

> 현재 목표는 출판이나 판매가 아니라 비공개 GitHub 자료 관리입니다. 이 문서는 당시 검토와 계획의 역사 기록이며 출판 관련 대기 과제는 중단했습니다. 현재 작업은 [저장소 관리](../../maintenance/README.md)를 따릅니다. 중단을 검수 완료로 표시하지 않습니다.

먼저 [통합 출판 검토 결과](PUBLICATION_REVIEW.md)를 읽으세요.

- [전 장 편집 검토](EDITORIAL_REVIEW.md): 서문과 1~12장 독해, 줄 근거와 편집 의견
- [권리 및 제출 형식](RIGHTS_AND_FORMAT.md): 실제 파일, 동봉 고지와 공식 안내 확인 범위
- [현재 검토 체크리스트](PUBLICATION_GATES.md): 준비와 사람 검토 및 최종 승인 상태 구분
- [파일 및 글꼴 점검 기록](TECHNICAL_RIGHTS_CHECK.json)
- [공식 라이선스 자료 열람 기록](LICENSE_SOURCE_CHECK.json)

이 묶음은 AI 출판 편집 검토 기록입니다. 실제 출판사 심사서나 법률 자문, 사람의 통계 감수 또는 판매 승인서가 아닙니다. 원고와 본책은 바꾸지 않았고 외부 접수와 공개 출간, GitHub 반영도 하지 않았습니다.
