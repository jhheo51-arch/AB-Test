# v0.22 출판 검토 체크리스트

이 문서는 과거 제작 이력과 구분한 현재 검토표다. ‘자료 준비’와 ‘실제 검토’, ‘저자 또는 출판사의 승인’을 별개로 기록한다. 자동 검사 수나 쪽수로 완료율을 계산하지 않는다. 출판 경로별 법적 의무를 일괄 확정한 목록도 아니다.

기준: 『그래서, 이 캠페인 계속할까요?』, 허재혁, v0.22 저자 검토본. 본문 개발은 종료했고 오류와 실제 읽기 장애만 최소 수정한다. 제출처 미지정, 외부 발송 미실시, 최종 출간 승인 없음.

## 이번에 할 수 있는 일과 하지 않는 일

이번에는 기존 원고의 출판 편집 가능성과 준비도를 검토하고 근거를 남긴다. 사람 검수와 제출처 선택을 기다리는 동안 새 장이나 사례, 방법론과 기능을 늘리지 않는다. 검토 요청을 외부 접수, 유료 검수 의뢰, 독자 모집, 공개 게시나 GitHub 반영 승인으로 확대하지 않는다.

가장 먼저 정할 출판 관련 미결정은 제출처 또는 유통 경로다. 현재 검토용 원고를 보여 줄 수 있는지와 판매를 시작할 수 있는지는 별개다. 미완료 검수를 숨기지 않고 편집 검토용으로 제시할 수 있으며, 본 체크리스트 자체가 모든 항목의 완료 증거는 아니다.
