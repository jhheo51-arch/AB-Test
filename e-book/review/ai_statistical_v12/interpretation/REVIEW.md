# v0.12 설계·방법·해석 및 표본 계획 검수

## 범위와 판정

**AI 검토 및 기존 코드와 분리한 재계산이다. 독립된 사람의 통계 검수 또는 현장 타당성 검증이 아니다.** 검토 원문은 `e-book/exports/v12/ebook_review_v12.md`이며 아래 위치는 해당 파일의 1-based 줄 번호다. 5·6장 전체, 7장 여섯 사례, 8장 고정 반례, 12장 전체를 실제 읽고 v03 원계획·분석 보고서·반복실험 장부와 비교했다. PDF 조판·페이지 대응은 이 검수의 범위가 아니다.

완료 우위, 사업적 충분성, 관계 보호, 재무 불확실성 및 실제 승인 경계는 대체로 적절하게 분리되어 있다. 표본계획 격자의 수치를 재현했다. 다만 **현재 불균등 A/B 표본 검정력은 두 군 표본수와 계획 확률의 대응이 뒤바뀐 계산과 정확히 일치**한다. 차이는 작지만 근사법 차이라고만 설명해서는 안 된다. 8장 score 비열등성에는 별도 비영 위험차 구현 불일치가 있으며, 해당 범위에만 한정해야 한다. 이번 검토에서 원고를 수정하거나 출판·운영 승인을 수행하지 않았다.

## 발견 사항

### F1 — LOW / 실제 수치 대응 오류: 현재 A/B 검정력의 군별 n 매핑

- 위치: 6장 L268, `analysis_report.json`의 `metric_readiness`.
- 인용: “현재 A/B 고객 수에 원래 계획 효과를 넣은 완료 검정력은 약 87.9%다. 계약 1%에서 1.2% 변화는 약 51.8%, 철회 0.8%에서 1.0% 변화는 약 60.0%다.”
- 실제 A는 21,637명, B는 22,024명이다. 계획 확률 A=.09/B=.10 등에 이 n을 각각 연결해 직접 구현한 양측 정규 검정력과 statsmodels `power_proportions_2indep`는 일치한다. 원 장부 값은 **높은 목표 확률을 nA=21,637에, 낮은 기준 확률을 nB=22,024에 연결**했을 때 모든 readiness 행에서 1e-12 이내로 재현된다. 기존 분석 함수를 읽어 추측한 결과가 아니라, 입력 대응을 바꾼 독립 재계산 결과다. 원 코드 자체의 결함 위치는 이 검토에서 확인하지 않았다.

## 별도 구현에 의한 표본계획 검산

계획값은 `experiment_plan.json`의 기준율·목표율·α·목표 power=.8만 사용했다. 현재 배정 n을 쓰는 계산에서도 관측 사건률은 계획 효과로 대체하지 않았다. 실현 사건 수는 Newcombe 구간 대조에만 별도로 사용했다.

직접 구현한 군당 폐형 근사식:

`ceil([z_(1−α/2)√(2 pbar(1−pbar)) + z_.8√(pA(1−pA)+pB(1−pB))]^2 / (pB−pA)^2)`

수치해는 계획하의 pooled 귀무 표준편차와 unpooled 대립 표준편차를 사용해 양쪽 기각 꼬리를 합하고, 검정력 ≥.8인 최소 정수 n을 이분법으로 구했다. 각 해에서 n−1은 목표에 못 미치고 n은 충족하는 것도 assertion으로 검사했다. 기존 프로젝트의 분석·생성 코드는 import/exec/run하지 않았다.

| 시나리오 | 단일 비교: 폐형 / 수치 군당 n | 3대비 보정: 폐형 / 수치 군당 n |
|---|---:|---:|
| 클릭 .10→.12 | 3,841 / 3,841 | 5,124 / 5,124 |
| 완료 .09→.10 | 13,495 / 13,495 | 18,001 / 18,001 |
| 계약 .01→.012 | 42,693 / 42,693 | 56,946 / 56,946 |
| 철회 .008→.01 | 35,001 / 35,001 | 46,686 / 46,686 |
| 희귀 불만 .001→.0012 | 431,213 / 431,212 | 575,167 / 575,167 |
| 작은 시승 .09→.0909 | 1,594,364 / 1,594,361 | 2,126,620 / 2,126,620 |

12행 모두 원계획의 폐형 및 수치 n과 일치한다. 본문 L243이 희귀 불만·작은 시승에 수치 탐색값을 사용했다고 밝힌 것도 맞다. 1명·3명 차이를 오류로 분류하지 않는다. 폐형식은 작은 반대쪽 기각 꼬리를 생략한 목표식이고 수치식은 두 꼬리를 포함한다.

`power_proportions_2indep`와 직접 검정력의 격자 최대 절대 차이는 **3.3306690738754696e−16**이다. 별도 `proportion_effectsize`/`NormalIndPower` Cohen h 방식도 계산했지만 다른 근사법으로 표시했다. 예를 들어 단일 완료 n=13,488, 3대비 완료 n=17,990으로 pooled-z 계획의 13,495/18,001과 다르다. h 방식과 수치가 다르다는 이유로 원계획을 잘못이라고 하지 않는다.

### 세 대비별 검정력과 공동 검정력

- L266: “그 목표는 각 계획 대비의 검정력이지 세 대비 모두를 동시에 발견할 공동 검정력이 아니다.” 적절하다. Bonferroni는 가족 거짓 양성을 다루며 공동 발견 확률을 자동 .8로 만들지 않는다.
- 원 생성계획은 A=.09, B=.10, H=.06이다. 현재 실현 n에 이 **계획 확률**을 넣으면 B-A 검정력 약 .8787814753, A-H 및 B-H는 수치 정밀도에서 거의 1이다. H 비교를 모두 .09→.10의 1pp 가정이라고 바꾸지 않았다.
- 공유 군으로 인해 대비들이 의존하므로 세 검정력을 단순 곱하지 않았다. RESULTS의 공동 검정력 경계는 주변 확률의 union bound/min bound일 뿐이며, H 대비의 1.0 수치 포화와 부동소수점 때문에 양 경계가 동일하게 보인다. 정확한 공동 검정력을 계산했다는 뜻이 아니다. 정확 이항 공동 검정력·공동 FWER 검증은 미수행이다.

## 설계·방법·해석별 비판적 검토

### 추정대상과 전달·처치 후 선택 — 적절, 현실 일반화 제한 유지

5장 L191 “전달에 실패한 고객도 원래 배정군에 남긴다”, 12장 L711 “완료율에 전달률을 다시 곱하면 같은 제약을 중복 반영하게 된다”는 원계획 `mechanism`의 정책수준 ITT 가정과 일치한다. 대상은 적격 잠재 고객의 28일 고객당 완료 위험차다. 예약자·전달자 조건부 비율은 다른 질문이다. 사례1 L321의 예약자 구성 변화 경고도 적절하다. 실현 계약을 완료 개선의 자동 결과로 읽지 않는다.

현실에서는 ITT가 결과 누락을 자동 해결하지 않으며, 생성확률이 현실의 전달 실패를 정말 포함하는지 별도 추정해야 한다. H는 해당 메시지 미발송이지 전사 CRM 정지가 아니며 원계획에는 다른 캠페인이 모형화돼 있지 않다(L693). 이 한계는 원문이 명시한다.

### 독립성·간섭·군집 — 적절, 사건 수만으로 정당화 불가

5장 L207 “슬롯 경쟁 때문에 B 고객이 A 고객의 기회를 빼앗는 상황도 독립 이항 계산만으로 처리되지 않는다”, 6장 L292 “충분한 고객 수와 충분한 독립 배정 단위 수는 다르다”는 핵심 조건을 지킨다. 원계획도 가구·지점 간섭과 용량을 구현하지 않았다고 적었다. 합성의 독립성과 실제 독립성 확인은 다르다.

사례6 L481은 운영 시스템을 정책 비교 단위로 정하고 L507은 개인 독립 CI/p를 붙이지 않는다. 단일 고정 수요 세계와 공통난수를 독립된 현장 반복으로 보지 않은 점이 적절하다. 용량 민감도 세 점은 신뢰구간이 아니며, 지점/기간 배정·포화도 설계는 향후 검증 제안일 뿐 구현된 효과가 아니다.

### 다중성 — 완료 가족·탐색·선택을 구분

5장 L213–219는 Bonferroni 보정 p와 α/3를 중복 적용하지 않고, 완료 가족이 계약·손익·철회·모든 집단을 보호하지 않는다고 명시한다. Newcombe 구간과 pooled z의 정확한 역관계도 보장하지 않는다. 선택된 최대 효과의 과장까지 보정이 제거한다고 하지 않은 점이 적절하다.

사례5 L461은 상호작용의 명목 95%를 주분석과 합친 공동 확증이라고 하지 않는다. 8장 L570의 두 적용 집단 Bonferroni .025는 두 적용 주장에 대한 관리다. 한 집단에서 **성과와 보호를 모두 충족해야 한다는 결합 적용 주장**은 intersection-union 구조이므로 성과·보호 두 항목이라는 이유만으로 α를 다시 절반으로 나눌 필요는 없다. 단, 각각의 효과를 독립적인 가족 확증 주장으로 판매하려면 다른 다중성 명세가 필요하다. 현재 원문을 무조건 추가 Bonferroni 누락이라고 판정하지 않는다.

### 정규근사·Wilson–Newcombe·희귀 사건 — 직접 재현, exact 보장은 아님

5장 L203은 폭의 직관을 위한 Wald 설명과 실제 Newcombe를 구분한다. 독립 Wilson 경계 결합식을 직접 구현해 세 완료 대비를 statsmodels와 대조했다. B-A [0.2597990454, 1.6084954427]pp, A-H [2.3921156203, 3.6084222463]pp, B-H [3.3134006312, 4.5553817099]pp로 v03 보고서와 일치한다.

6장 L288 “희귀 사건에는 이항 근사의 적절성부터 살피고 사건 구조에 맞는 정확 방법이나 다른 모형을 검토한다”는 적절하다. 희귀율 자체만으로 큰 n 정규근사를 자동 기각하지 않는다. 예컨대 단일 희귀 불만 계획 n=431,212에서 기대 사건 수는 약 431.212/517.4544로 작지 않다. 반면 현재 A/B n에서 그 계획률의 기대 사건은 21.637/26.4288 수준이며 꼬리 정확성·이산성 검토가 더 필요하다. 이 수들은 **계획상 기대 사건**이지 실제 불만 관측 수가 아니다. Newcombe의 경계 안정성이 군집·간섭·선택 누락을 해결하지는 않는다. 근사 CI를 유한표본 exact 가족 포함률 보장이라고 부르지 않는다.

### 보호 비열등성과 사후 사업 기준 — 핵심 경계 적절

5장 L223 “사후 교육용 민감도 가정이지 실험 전 승인 기준이 아니다”, L229 “정식 비열등성 평가는 결과 전에 정한 한계와 단측 유의수준에 맞는 검정 또는 상한으로 설계한다”는 원계획과 일치한다. 원계획 `opt_out`의 역할은 기술적 불확실성이지 NI 설계가 아니다. 완료 하한이 사후 .5pp를 넘지 않는 것을 확정 실패로 보지 않고, 철회 비유의를 안전으로 바꾸지 않는다. 6장 철회 악화 탐지 표본을 NI 표본으로 오인하지 않는다.

8장 고정 반례는 별도 30일·고정 카운트·사업 +1pp·보호 +.5pp 설정이다. 이를 v03의 28일·사후 .5pp/.2pp와 섞으면 안 된다. 해당 카운트의 표본수는 검정력으로 산출한 권장 n이 아니라고 L548이 밝힌다. 성과에서 나 집단의 97.5% 구간과 보호 단측 97.5%는 서로 다른 목적이며 실제 미래 사전등록도 아니다. F2의 작은 수치 불일치가 이 이야기의 논리나 네 상태를 뒤집지는 않는다.

### 손익 불확실성 — 조건부 탐색 해석 적절, 현실 경제성 미검증

사례3 L383 “원가 가정의 오차까지 포함한 구간도 아니다”, L392 “완료에서의 B 우위를 확증 재무 승리로 바꾸지 않는다”는 적절하다. 개인별 완료·계약 결합을 보존해야 하며, 두 사건이 독립이라고 놓고 분산을 더하면 안 된다. 기여액 고정·개인 독립에 조건부인 Welch 구간과 기여액 민감도는 서로 다른 불확실성이다. B-H [+2,620원, 탐색 구간 −1,317~+6,557원]을 확정 이익이라고 하지 않는다.

고정비 배분과 매몰비를 L372/L758에서 구분한다. 실현 사건으로 관측 손익을 읽는 것과 계획률로 검정력을 계산하는 것은 분리돼 있다. 본 하위 검수는 손익 원시 개인자료와 Welch 장부 전체를 새로 재계산하지 않았다. 해당 수치는 원문의 조건부 해석을 검토한 것이며 별도 수치 인증이 아니다.

### 종료·추가 분석 중단·실제 승인 — 명확히 분리

1장 L112 “추가 분석을 멈추는 것, 실험을 종료하는 것, 운영을 중단하는 것은 서로 다르다”, 6장 L294의 사전 순차 설계 원칙, 8장 L572의 유의해질 때까지 고정 실험에 표본을 덧붙이지 말라는 설명은 적절하다. 표본수와 개인 관측 창 성숙도 분리했다. 12장 L713의 조기 스냅샷 수치·DB 시간 하한 대사는 본 하위 검수에서 DB를 다시 열어 확인한 것은 아니다.
