# A/B 전용 방법론 비교 검토 자료

이 자료는 같은 기업형 문제를 PDCA와 TRI-V로 끝까지 풀어 보는 별도 검토안입니다. 기존 v0.10 본책, 명칭, 분석 및 원자료는 변경하지 않습니다.

## 먼저 볼 파일

`walkthrough.html`을 브라우저에서 열어 같은 A/B 문제, PDCA로 풀기, TRI-V로 풀기, 어떤 차이가 있나를 차례로 선택하세요. 각 방법의 단계도 버튼입니다. 외부 로그인과 서버, 외부 스크립트 없이 동작합니다. 인쇄하면 숨긴 단계까지 표시됩니다.

## 사례의 경계

- JH Motors Service는 가상의 자동차 서비스 사업자입니다. 실제 기업의 쿠폰 실험, 내부 성과 또는 원가를 확보한 것이 아닙니다.
- 고객 12,000명의 고정 카운트와 비용 가정으로 만든 교육용 자료입니다. 작성자가 결과를 설계했습니다. 이야기의 실험 전 계약은 실제 미래 결과를 위한 독립 사전등록이 아닙니다.
- 기존 시승 안내 실험과 다른 신규 예제입니다. 과거 실험과 결과를 결합하지 않습니다.
- 취소와 환불을 반영한 30일 순완료 카운트를 입력으로 간주합니다. 실제 취소 원장과 원가 감사, 이후 환불, 장기 가치, 방문 시점 이동, 용량 간섭과 군집 상관은 구현하지 않았습니다. 개인 독립, 비간섭과 원가 고정의 가정 아래 계산합니다.
- 표본 수 12,000명은 사례를 설명하는 고정 입력입니다. 검정력으로 정한 충분 표본이라는 뜻이 아닙니다.
- 현재 대상의 주지표는 고객당 공헌이익입니다. 모든 A/B 테스트의 주지표를 금전 지표로 강제하지 않습니다. 최소 사업 가치 +500원과 철회 한계 +0.30pp도 가상 회사의 예시 정책이며 보편적 판정 기준이 아닙니다.
- 이번 A/B는 쿠폰 없는 같은 안내와 쿠폰 있는 안내의 대비입니다. 미접촉 대조군이 없어 연락 자체의 증분 효과를 추정하지 않습니다.

## 이번 자료의 실제 계산

`design_fixture.json`이 고정 입력입니다. `customer_fixture.csv`는 각 고객의 배정 전 상태, 군, 관측 일수, 완료, 철회, 공헌이익을 담습니다. A와 B 각각 6,000명이며 상태별 3,000명씩입니다.

배정 전체 분모를 유지하고 상태별 절반인 표적 구성의 공헌이익 차이를 추정했습니다. 층내 표본분산을 사용한 정규근사 Wald 구간을 포화 셀 평균 회귀의 HC2 대비와 수치 대조했습니다. 철회는 상태별 비율을 동일하게 설정한 교육용 입력에서 합산 두 군의 score 단측 비열등성을 계산했습니다. 결과는 `calculated_results.json`에 있습니다.

전체 B 확대 거절 제안과 첫 이용 대상의 후속 실험 후보를 구분합니다. 집단 정의가 사전이라는 이유만으로 다중성을 처리하지 않은 집단 결과를 확증으로 바꾸지 않습니다. 첫 이용 대상만 B인 혼합 정책, 장기 효과, 실제 기업의 개선 성과는 확인하지 않았습니다. 실제 실행과 승인을 수행한 것도 아닙니다.

## 두 방법의 개발 범위

ASQ의 PDCA 원형은 Plan, Do, Check, Act와 반복입니다. 이번 A/B 실험 계약, 산출물과 판단 기준은 그 원형의 적용 제안이지 ASQ 공식 신규 방법론이 아닙니다.

TRI-V의 Variable Control, Vector Segmentation, Value-Linked Decision은 유지했습니다. 세 축을 사전에 함께 정하고 실행과 해석 중에 필요한 축으로 되돌립니다. 기본 경로에서는 배정, 분석, 적용 대상의 일치 여부만이라도 적으며 모든 실험에 집단별 심화 분석을 요구하지 않습니다. 새 통계 법칙이나 PDCA 대비 우월성을 입증했다고 주장하지 않습니다.

## 도식 표현의 이유

두 방법에 같은 명세와 결과를 사용해 표현이 아니라 판단 과정을 비교할 수 있게 했습니다.
각 단계에 남기는 산출물을 붙여 설명에서 실무 기록으로 이어지게 했습니다.
실험 결론과 정책 채택을 나누고 대비가 확인된 색을 사용해 상태를 색만으로 해석하지 않게 했습니다.

## 재현

프로젝트 루트에서 실행합니다. ZIP을 풀었으면 그 안의 `scripts`와 `e-book`이 있는 폴더가 루트입니다.

```sh
uv run --with numpy --with scipy --with statsmodels python scripts/analyze_ab_only_methods_v01.py
python scripts/build_ab_only_walkthrough_v01.py
uv run --with playwright python scripts/verify_ab_only_walkthrough_v01.py
```

동작 검사는 설치된 Chrome의 headless 실행을 사용합니다. Python, uv와 필요한 패키지 및 Chrome이 없는 환경에서 무설치 재현된다는 뜻은 아닙니다. HTML 자체 열람에는 이 계산 환경이 필요하지 않습니다.

`interaction_validation.json`은 데스크톱과 모바일의 화면 및 단계 전환, 키보드, 가로 넘침과 스크립트 오류의 검사 기록입니다. 사람의 이해도나 통계 검수 및 현장 효과 검증을 대신하지 않습니다.
