# 참여자 과업지

모든 고객·정책·수치는 합성 예시입니다. 이 도구가 이해하기 어려운 부분을 찾는 것이 목적이며 참여자의 통계 지식을 시험하는 자리가 아닙니다. 모르는 조건은 모른다고 말해 주세요. 고객 원자료·이름·연락처·회사 기밀을 입력하지 마세요.

## 시나리오

가상의 시승 안내에서 기존 방식과 새 방식을 비교했습니다. 팀장은 새 방식을 모든 고객에게 적용해도 되는지 검토 기록을 원합니다. 신규·기존 고객을 함께 검토하려고 합니다.

**예시 설계 기록:** 가명 고객별 한 번만 무작위 배정했고 각자의 정한 관측 기간을 완료했습니다. 결과가 유의할 때까지 연장하지 않고 정한 종료 규칙을 따랐습니다. 신규·기존 구분은 결과를 보기 전에 계획했습니다. 이 조건은 합성 시나리오의 가정이지 실제 실험 인증이 아닙니다. 비용·보호 지표의 결과는 제공되지 않았습니다.

## T01. 다른 이름의 열을 연결하기

`fixtures/SYNTHETIC_CRM_CUSTOM.csv`를 가져오세요. `control`은 기존 A, `treatment`는 새 B입니다. `converted`는 성공 수, `participants`는 배정된 전체 수, `cohort`는 배정 전 고객군입니다. 열 연결과 집계를 확인하고, 위 설계 기록을 근거로 분석해 보세요. 모르겠는 조건은 진행자에게 알려 주세요.

## T02. 결과를 팀장에게 설명하기

전체 결과를 보고, 어느 안이 더 높게 관측됐는지와 통계적으로 어느 안이 우세한지 설명해 주세요. 현재 자료만으로 새 안의 실제 적용을 승인할 수 있는지도 말씀해 주세요. 필요한 화면을 자유롭게 펼쳐 보세요.

## T03. 고객군 차이를 설명하기

신규 고객과 기존 고객을 따로 보고 싶은 상황입니다. 고객군별 판단과 두 고객군의 효과 차이에 대해 현재 화면에서 말할 수 있는 것, 아직 말할 수 없는 것을 설명해 주세요. 해석하기 어려운 용어도 알려 주세요.

## T04. 판단을 기록하고 공유하기

현재 검토 방향, 이유, 적용 전에 확인할 조건과 다시 검토할 때를 기록해 주세요. 팀장에게 먼저 전체 결과만 공유한다고 가정하고 보고서 미리보기와 공유 범위를 확인한 뒤 HTML 또는 PDF로 저장해 보세요. 선택은 실제 적용 승인이 아닙니다.

## T05. 저장·복원과 잘못된 자료 확인하기

프로젝트를 저장하고 새 실험 또는 새 탭에서 복원한 뒤 재분석해 보세요. 해시 기록이 각각 무엇을 대상으로 하는지, 원자료를 다시 검증한 것인지 설명해 주세요.

이후 새 실험에서 `fixtures/SYNTHETIC_IMMATURE.csv`를 개인형으로 가져와 확인해 보세요. 결과를 볼 수 없다면 어디서 막혔고 무엇을 고쳐야 하는지 말씀해 주세요. 오류를 없애려고 행을 임의로 삭제하거나 미관측을 실패로 바꾸지 마세요.

## T06. 설계 진입에 필요한 질문 — 인터뷰

아직 결과 데이터가 없고 어떤 두 안을 비교할지도 정하지 않았다고 가정해 주세요. 현재 화면에서 시작할 수 있는 부분과 부족한 부분은 무엇인가요? 목적·현실 제약을 어떤 순서로 물어보면 도움이 될까요?

현재 앱은 규칙 기반 설계 안내이며 자유로운 후보·계획 생성 대화는 아직 제공하지 않습니다. 없는 기능을 찾는 과제가 아니라 다음 기능에 필요한 질문을 알아보는 인터뷰입니다.
