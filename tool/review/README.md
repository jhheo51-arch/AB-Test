# 사용자 과업 검토 안내

## 현재 상태

이 폴더는 진행 자료입니다. 실제 수행 기록·개인 피드백은 로컬에 보관하며, 독립 실무자 검토를 완료한 것으로 표현하지 않습니다. `SESSION_TEMPLATE.json`의 참가자·관찰·결과는 빈값이며 AI 모의 응답이나 자동화 결과를 참가자 기록으로 채우지 않습니다. 앱 자동검사는 이 검토와 별개입니다.

목표는 CRM 실무자가 입력 → 결과 이해 → 판단 기록 → 공유 → 저장/복원을 실제로 끝낼 수 있는지 관찰하고, 다음 설계 진입 흐름에 반영할 문제를 찾는 것입니다. 범용 CRM 운영이나 마케팅 성과를 평가하는 시험은 아닙니다.

## 준비

- 실행 앱: 별도 전달한 `AB_Test_Workspace/launch.cmd` 또는 `python launch.py`.
- 과업 입력은 `fixtures/`의 **합성 자료**만 기본으로 사용합니다. 고객 자료 반출·업로드를 요구하지 않습니다.
- 참여자에게 목적, 합성 자료 사용, 관찰 내용의 저장/공유 범위를 알리고 동의를 먼저 받습니다.
- 이름·연락처 대신 참여자 코드를 사용하세요. 화면·음성 녹화는 기본으로 하지 않으며 별도 동의가 있을 때만 합니다.
- 참가자에게는 `PARTICIPANT_TASKS.md`를, 진행자에게는 `OBSERVER_GUIDE.md`와 `observer/ENGINE_GROUND_TRUTH.json`을 제공합니다. 정답지를 먼저 보여 주지 않습니다.
- 첫 검토는 저자 본인이 직접 수행해도 됩니다. 이 경우 저자 자기 검토로 기록하고 독립적인 CRM 실무자 검토라고 부르지 않습니다.

## 진행 원칙

정해진 시간 내 성공을 강요하지 마세요. 평소처럼 해 보게 하고, 멈추거나 모르겠으면 그 위치와 이유를 기록합니다. 설명을 제공했다면 개입한 시점과 내용을 함께 남깁니다. 올바른 체크를 대신 눌러 주거나 결과를 외워 말하게 하지 않습니다.

기록할 항목은 과업 상태(미시작/수행/도움받음/중단), 실제 행동, 사용자의 원문 발언, 관찰과 진행자 해석의 구분, 도움, 오독, 다음 개선 후보입니다. 시간·성공률·효율은 실제 측정 전 채우지 않습니다.

T01~T05는 기존 분석 기능의 과업입니다. T06은 구현된 로컬 고정 질문·후보를 사용해 결과 없는 계획을 저장·복원하고 결과 연결을 검토하는 과업입니다. 자유로운 AI 설계 대화가 있는 것처럼 안내하지 않습니다. 현재 실제 사람 과업 관찰은 0건이며 [검토 상태](REVIEW_STATUS.md)를 참조하세요.

## 종료와 다음 단계

관찰 기록에서 개인정보를 제거하고 참여자가 허용한 범위만 공유합니다. 검토를 마치면 과업별 막힘·오독·필요한 질문을 요약하고 설계 진입 요구사항에 연결합니다. 참여자 없이 AI가 대신 과업을 수행한 결과로 실사용자 검토를 완료하지 않습니다.

설계 진입은 상황 설명 → 목적 확인 → 고정 A/B 후보 → 편집 가능한 계획 → 사용자 확인으로 구현했습니다. 실제 관찰 전에는 사용성 개선 가설로 유지합니다. 결과 없는 계획에 수치·승자·실제 승인을 만들지 않습니다. 현재 실제 Chrome 시연(160.16초)에 설계·저장/복원·세 상태 조건·판단을 포함했습니다. 핵심 네 조건의 확인됨은 합성 시연 가정이며 실제 실험 인증이 아닙니다.
