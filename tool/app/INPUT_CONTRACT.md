# 입력·판정 계약

이 계약은 현재 앱의 지원 범위를 설명합니다. 자료·조건의 사용자 확인은 실험 타당성의 독립 인증이 아닙니다.

## 입력과 연결

UTF-8 CSV/TSV 2MiB·50,000행, 열 연결 원본 최대 100열을 지원합니다. 첫 행은 열 이름입니다. BOM과 인용부호 안 쉼표·줄바꿈을 처리합니다. 정해진 간단 문장 외 자유 서술을 임의로 숫자화하지 않습니다.

- 집계형: arm,success,total,segment(선택). 군은 A/B, 정수 0<=success<=total, 같은 군/집단 중복은 오류.
- 개인형: subject_id,arm,outcome,segment/observed(선택). 가명 ID 중복 금지, outcome은 0/1. 관측 상태가 있으면 모두 1이어야 하며 미관측을 실패로 채우지 않습니다.
- 다른 열 이름과 군 값은 사용자가 연결·제외 열을 확인한 뒤 정규 CSV로 변환합니다. 군 이름 외 값은 재코딩하지 않고 오류 행을 삭제하지 않습니다. 원본 observed 열은 생략하지 못합니다.
- 개인 미리보기는 기기 안의 별도 경로이며 집계·분석 반환값과 저장·외부 전송에 원시 행/ID를 포함하지 않습니다.

## 조건과 방법

독립 두 군의 고정 종료 이항 결과를 기본 경로로 합니다. 무작위·독립·관측 완료·고정 종료를 모두 사용자 확인한 경우에 지원 조건 안의 추론을 실행합니다. 불명확한 조건은 기술 통계와 구분하며, 군집·반복·순차·적응·시간·금액 설계를 억지로 분석하지 않습니다. alpha=.05이며 군별 합산 분모 상한은 200000입니다.

Fisher 양측 검정, Wilson 군별 비율 및 Newcombe B−A 명목 95% 근사 구간을 사용합니다. 전체만 사전 비교하면 가족 m=1, 사전 두 집단·직접 차이까지 검토하면 m=4로 Holm 보정합니다. 미지원 가설은 내부 p=1로 가족에 유지하지만 실제 계산값으로 표시하지 않습니다. 명목 구간은 가족 동시 구간이 아니고 Fisher와 완전 쌍대가 아닙니다.

집단 직접 차이는 (B−A)_G1−(B−A)_G2입니다. 네 셀 각각 성공·실패 5 이상일 때 Wald 근사를 제공하며 부족하면 제한합니다. 한 집단만 유의하다는 사실로 집단 효과 차이를 확정하지 않습니다. 사후 집단은 탐색, 결측은 전체에 남기되 집단 확증을 제한합니다.

winner는 방향과 조정 p 기준을 사용해 A/B/hold/not_tested로 구분합니다. hold는 무효과·동등·안전의 증명이 아니며 실제 적용 승인은 별도입니다. 비용·보호 지표 자동 판정은 제공하지 않습니다.

## 저장과 최신성

계획·집계·판단·타입이 명시된 해시 기록을 저장하며 raw rows, ID, 원본 미리보기/열 연결, 모델 출력은 제외합니다. 저장은 8MiB·50000집계 셀, 복원용 CSV는 2MiB 이하입니다. 저장 범위가 추론 범위를 넓히지 않습니다. 내부 형식 식별자는 구형 파일 읽기와 중복 필드 검증을 위해 유지합니다.

입력·연결·조건 변경은 준비/결과 확인을 무효화합니다. 공유·판단 변경은 공유 확인과 인쇄 스냅샷을 폐기합니다. 비동기 파일/해시/계산은 현재 작업의 소유권을 확인합니다. 잘못된 복원은 기존 유효 입력을 보존합니다.

해시는 최초 입력 텍스트 UTF-8, 직전 기록, 이번 계산 CSV를 구분합니다. 복원은 기록 계승이지 원자료 재검증이나 진위·익명성 인증이 아닙니다. 모든 중간 이력을 보관하지 않으며 구형의 대상 미분류 값과 없는 값은 추정하지 않습니다.

## 계산·설명 경계

ABEngine.parseTable은 원시 표를 반환하므로 저장/외부 전송에 쓰지 않습니다. prepare는 cells/issues/format/sourceRowCount, analyze는 상태·전체·집단·직접 차이·가족·issues를 반환합니다. status는 ok/descriptive/limited/unsupported/invalid, CI는 [하한,상한], 집단은 G1/G2입니다. 원래 이름은 기기 안에서 대응합니다.

모델에는 동의·명시적 요청 후 analysis_status,overall_decision,segments,interaction,guardrail,design_user_confirmed,adjustment,issues만 보냅니다. 숫자·CSV·ID·원래 집단명·목적·정책·해시는 추가하지 않습니다. 서버는 명시한 엔진 오류 코드만 허용하고 CLI 전에 미등록 코드를 거절합니다. 검사 범위는 구조/허용 값이지 출처·정확성·임의 요청 익명성 인증이 아닙니다. 모델은 수치를 재계산하거나 새 승자를 선택하지 않으며 출력 실패를 숨기지 않습니다.

고정 fixture·독립 수치 대조·실제 브라우저·다운로드/복원·실제 PDF·별도 압축 해제본을 확인합니다. 합성 자동화는 실제 사용성·전 범위 통계/보안/접근성 인증을 대신하지 않습니다.
