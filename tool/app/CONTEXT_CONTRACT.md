# 실험 맥락·판단·도움말 계약

목적, 성공 사건, 관측 기간, A/B 정책, 분석 대상을 입력부터 결과·보고서까지 연결합니다. 모르는 값을 고객군 이름이나 예시에서 추정하지 않고 미기록으로 남깁니다. 사용자가 기록한 조건과 독립 확인을 구분합니다.

결과는 관측 차이·통계 판정·사업/보호 미확인·다음 확인을 먼저 보여 주며 실험 맥락·계산 근거는 펼쳐 확인합니다. 보고서의 근거는 펼쳐 출력합니다. A/B 기본 카드는 중립적으로 유지하며 고정 색을 승자처럼 읽게 하지 않습니다.

판단 기록은 검토 방향·근거·확인할 조건·재검토 시점을 포함합니다. 통계적 우세와 반대 방향을 선택하면 안내하지만 선택을 바꾸거나 자동 승인하지 않습니다. 미기록은 미기록으로 남깁니다. 입력·조건 변경 후 공유를 다시 확인해야 합니다.

공유에서 집단을 제외하면 원래 이름·집단별 결과·설명·직접 차이 상세도 내보내지 않습니다. 비교 가족의 크기/방법/포함 질문 식별자는 유지합니다. 목적·정책·대상·판단 같은 자유 서술은 별도 공유 내용이며 자동 익명화되지 않습니다.

모델 설명과 로컬 이유 설명을 구분합니다. 새 판단·맥락·해시 필드를 모델 페이로드에 추가하지 않습니다. 빈 군·집단 결측·사후 탐색·invalid의 제한을 실제 엔진 상태에서 읽고 없는 수치·안전·동등·승인을 만들지 않습니다.

시연은 입력 화면 안의 dialog로 열고 닫습니다. 사용자 페이지를 다른 URL로 이동시키거나 새로고침하지 않습니다. 닫기/Escape에서 영상은 멈추고 입력·집계·결과·동의·공유 확인과 스크롤을 보존합니다. 영상은 별도의 합성 자료를 실제 앱으로 조작한 도움말이며 사용자 과업 수행의 증거가 아닙니다.

제품 판 표시는 화면·시연·다운로드 이름에서 숨깁니다. 내부 파일 형식과 엔진/변환 식별자는 검증·호환성에 필요하므로 기술 데이터 안에 유지합니다. GitHub에는 현재 앱과 현재 문서만 두고 이전 자료는 로컬에 보관합니다.
