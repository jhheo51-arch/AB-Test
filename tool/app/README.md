# A/B 테스트 작업실

CRM A/B 테스트의 설계 초안·데이터·결과·한계·판단 기록을 연결하는 로컬 앱입니다. 이 폴더는 현재 사용하는 앱 한 벌입니다. 이전 판과 수정 이력 묶음은 로컬에서만 관리합니다.

## 실행

Windows에서 Python 3가 설치된 상태로 `launch.cmd`를 실행하세요. 또는 이 폴더에서 `python launch.py`를 실행합니다. 표시된 `http://127.0.0.1:포트`를 Chrome/Edge에서 열고 실행 창을 유지하세요. HTML만 더블클릭해서는 Worker와 로컬 설명 브리지를 사용할 수 없습니다. 일반 사용에 Node는 필요하지 않습니다.

## 기본 계산과 선택 기능

- **CSV 확인·통계 계산·판단 기록:** LLM 없이 사용합니다. Python과 브라우저로 실행할 수 있으며 모델 인증이 필요하지 않습니다.
- **LLM 설명:** 별도의 Hermes CLI 설치와 `mira` 프로필, 사용 가능한 모델 연결·인증이 필요합니다. 기존 연결을 사용하는 선택 기능이며 ZIP에 Hermes나 인증정보는 포함하지 않습니다. 설정되지 않았거나 연결에 실패해도 로컬 계산은 사용할 수 있습니다. 모델 호출 비용은 연결한 서비스 조건에 따릅니다.
- **자유로운 자연어 설계 대화:** 아직 제공하지 않습니다. 현재 설계 안내는 규칙 기반입니다.

## 막히면 시연 영상 보기

상단 또는 입력 화면의 **시연 영상 보기** 또는 열 연결 영역의 **원본 값 설정 시연 보기**를 누르세요. 영상은 앱 안의 창으로 열립니다. 닫으면 입력·집계·확인 상태를 유지하고 작업을 계속합니다. 페이지를 다른 주소로 이동시키지 않습니다.

영상은 약 78초, 무음 한글 자막이며 합성 자료로 실제 앱을 조작한 별도 시연입니다. [MP4 내려받기](help/walkthrough.mp4). 원본 값 두 칸 수정은 약 26초부터 볼 수 있습니다. 사용자 과업 완료나 실제 성과의 증거가 아닙니다.

이 영상은 기존 열 연결·분석 안내입니다. 새 **상황부터 설계** 튜토리얼은 아직 추가하지 않았으며 영상 바이트는 보존했습니다.

## 데이터 없이 계획부터 시작하기

왼쪽 **상황부터 설계** → **상황만 있어요 / 기존 계획 정리**를 선택하세요. 상황·목적·대상·기록 가능한 행동·위험·제약에 답한 다음 고정 후보를 선택하고 초안을 직접 수정합니다. 정해진 질문과 후보이며 실시간 AI 의미 분석이나 효과 예측이 아닙니다. 모르는 항목은 비워 두고 상태를 미확인으로 남깁니다.

대상·분석·적용 세그먼트는 별개입니다. 없는 고객 속성·표본·기간을 만들지 않습니다. 프로젝트 저장으로 빈 결과의 계획을 보관하고 새 페이지에서 복원할 수 있습니다. **같은 계획으로 CSV·결과 연결**은 목적·정책·지표·기간·대상을 유지하지만 분석 가정 확인은 해제합니다. 합성 예시는 별개 실험이며 계획을 비우기 전에 확인합니다.

계획을 바꾸면 현재 결과·공유 확인·인쇄 내용을 폐기합니다. 도구에서 결과를 본 뒤의 수정 표지는 남지만 외부 결과 열람·사전 등록이나 전체 수정 이력을 인증하지 않습니다. 설계 자유 서술은 프로젝트에 저장되며 자동 익명화되지 않습니다. 새 설계 전용 서술은 LLM 상태 페이로드나 기본 HTML/PDF에 자동 추가하지 않습니다. 기존 목적·정책·대상은 여전히 결과 보고서에 포함되므로 공유 전 확인하세요.

## 사용 흐름

1. 표를 붙여넣거나 CSV 파일을 가져옵니다. 첫 행은 열 이름이어야 합니다.
2. **데이터 확인하기**를 누릅니다. 열 이름이 다르면 원본 미리보기와 연결 초안을 보여 줍니다.
3. A/B 구분·성공 수·분모·집단 또는 가명 ID·성공 여부·관측 상태 열을 직접 확인합니다.
4. 원본 군 값도 확인합니다. 예를 들어 `control`은 A, `treatment`는 B로 명시합니다. 역할 연결과 군 값 연결은 서로 다릅니다.
5. 값을 수정하면 확인 체크가 해제됩니다. 다시 확인하고 **연결 적용하고 집계 확인**을 누릅니다.
6. 숫자·분모와 실제 설계 조건을 확인한 뒤 분석합니다. 모르는 조건을 체크해 추론을 열지 않습니다.
7. 요약 → 전체/지원 집단 결과 → 필요한 상세를 읽고, 검토 방향·근거·확인 조건·재검토 시점을 작성합니다.
8. 공유 범위를 확인한 뒤 HTML/PDF를 저장합니다. 보고서는 계산 근거를 펼쳐 출력합니다.

**설계 확인 사항 보기**는 기존의 짧은 규칙 기반 안내이며, 왼쪽 **상황부터 설계**의 고정 질문·후보 흐름과 별개입니다. 데이터 확인 버튼과도 다릅니다.

## 입력·계산·저장

- UTF-8 CSV/TSV 2MiB·50,000행, 연결 원본 최대 100열. 성능 보장은 아닙니다.
- 연결 추천은 제한된 별칭 사전이며 의미·실험 타당성 인증이 아닙니다. 모든 데이터 행을 유지하며 군 이름의 명시적 변환 외 값을 임의로 재코딩하지 않습니다.
- 오류·중복·미성숙을 조용히 삭제하지 않습니다. 개인형 원본 `observed` 열을 생략할 수 없으며, 다른 이름의 관측 상태도 올바르게 연결해야 합니다.
- 독립 고정 두 군 이항 결과에 집중합니다. Fisher 양측 검정, Wilson/Newcombe 명목 구간, 계획된 비교 가족의 Holm 보정을 사용합니다. 군별 합산 분모 200,000과 집단·설계 제한은 유지합니다.
- 저장 파일에는 계획·집계·판단·종류를 구분한 해시 기록을 담습니다. 원시 행·가명 ID·원본 미리보기·열 연결·LLM 출력은 담지 않습니다. 프로젝트 8MiB·50,000 집계 셀, 복원 CSV 2MiB 이하입니다.
- 화면·영상·배포명에는 제품 판 번호를 표시하지 않습니다. 구형 저장 파일을 읽고 코드 허용목록을 검증하는 내부 형식/엔진 식별자는 호환성과 안전을 위해 유지합니다.

## 안전한 해석과 설명

관측 순위, 통계적 우세, 사업적 충분성, 실제 적용 승인은 다릅니다. 보류는 무효과·동등·안전의 증명이 아닙니다. 비용·보호 지표는 자동으로 판정하지 않습니다.

LLM은 별도 동의와 버튼 요청 후 기존 Hermes `mira` 연결로 최소 판정 상태를 설명합니다. 수치를 계산하거나 원자료·원래 집단 이름·목적 원문·해시를 전송하지 않습니다. 서버는 알려진 엔진 오류 코드만 허용하고 미등록 값은 CLI 전에 거절합니다. 구조 검증은 임의 요청의 익명성·엔진 출처·사실 정확성 인증이 아닙니다. 연결 실패 시 계산 결과를 유지합니다. 인증정보는 앱에 포함하지 않으며 앱이 인증 파일을 직접 읽지 않습니다.

해시는 최초 입력 텍스트 UTF-8, 직전 계산 기록, 이번 계산 입력 CSV를 구분합니다. 파일 원본 바이트의 독립 인증이나 모든 중간 이력 보관이 아닙니다. 복원 기록은 원자료 재검증이 아니며 구형의 대상 미분류 값은 추정하지 않습니다. 해시는 진위·익명성을 보증하지 않습니다.

자유 서술은 자동 익명화되지 않습니다. 공유 전에 개인정보·기밀·소집단 정보를 확인하세요. CRM 발송/관리와 시간·금액·순차·군집 분석은 제공하지 않습니다.

## 검사와 다음 단계

현재 검사 결과는 `verification.json`, `integration_verification.json`, `design-evidence/`, `tests/`, `evidence/`에 있습니다. 기존 화면·PDF 예시는 [GitHub 저장소의 검증 자료](https://github.com/jhheo51-arch/AB-Test/tree/main/tool/evidence)에 보존하며, 이 별도 예시 폴더는 ZIP에 포함하지 않습니다. ZIP의 정확한 포함 항목은 다운로드 허용목록을 따릅니다.

`python tests/run_integration.py`는 임시 loopback 서버에서 Node와 실제 Chrome 합성 회귀를 실행하고 서버를 종료합니다. Playwright·Chrome, PDF 검사용 PyMuPDF와 Node는 개발 검사 의존성이며 일반 앱 사용에는 필요하지 않습니다. 실제 모델을 호출하지 않습니다. 기존 모델 연결 실증은 과거 기준 기록이며 이번 통합의 재호출이 아닙니다. 합성 자동화는 실제 CRM 사용성·현장 효과·전체 접근성·보안 인증이 아닙니다.

첫 병렬 통합 검사에서 설계 이동 연결과 저장 형식 기대값 오류를 발견해 수정했습니다. 같은 실행의 초기 Worker 준비 대기 실패는 직렬 재실행에서 재현되지 않았으며 일반 성능 문제를 해결했다고 주장하지 않습니다. 최초 기록은 `evidence/integration-initial/`에 보존했습니다.

실제 사용자 과업 자료와 로드맵은 저장소의 도구 진입 문서를 확인하세요. 사람 과업 관찰은 0건이며 구현한 설계 진입도 실제 관찰로 후속 개선해야 합니다. AI 시연을 독립적인 사용자 검토로 계산하지 않습니다.

기존 제안 팔레트·글꼴·간격을 유지했습니다. 시연을 앱 안에 둔 이유는 입력을 잃지 않고 도움을 볼 수 있게 하기 위해서입니다. 영상 후에도 확인과 실제 판단은 사용자에게 남깁니다. 공개 토스 UI 원칙을 참고한 독자 구현이며 공식 TDS·전용 폰트·로고를 사용하지 않았습니다. Pretendard 라이선스는 `fonts/LICENSE.txt`에 보존합니다.
