# 가상 정기점검 A/B 테스트 공유 보고서

**원래 입력의 자동 판단은 확대 보류입니다.** 정기점검 안내를 받은 두 군을 배정 후 28일 동안 관측하는 가상 사례입니다. 분석 도구가 내보낸 공유 보고서의 입력값과 판단을 옮겼습니다.

## 실험과 적용 범위

| 항목 | 원래 사례 |
| --- | --- |
| 실험 대상 | 마케팅 수신에 동의했고 30일 안에 정기점검이 예정된 가상 차주입니다. 기존 예약자와 필수 안전 고지 대상은 제외했습니다. |
| 분석 고객군 | A군 전체와 B군 전체의 집계를 비교했습니다. 고객군별 집계가 없어 **고객군별 효과는 미확인**입니다. |
| 적용 범위 | **확대 보류.** 실제 적용 대상과 범위는 미확정입니다. |

## 판단에 쓴 입력값

| 고객 수 | A군 관리 필요성 안내 | B군 예약 편의 안내 |
| --- | ---: | ---: |
| 최초 배정 | 15,482명 | 15,603명 |
| 방문 완료 | 1,416명 | 1,597명 |
| 수신 철회 | 129명 | 139명 |

- 방문 완료율의 최소 개선폭은 **+0.500%p**, 수신 철회율 증가의 허용 상한은 **+0.200%p**로 입력했습니다.
- 센터 수용량과 비용은 각각 **미확인**으로 입력했습니다.
- 가상 사례에서는 무작위 배정, 고객별 독립성, 관측 완료, 사전 종료 기준을 확인한 상태로 설정했습니다. 방문 완료율의 차이는 사전 지정 3개 비교를 보정한 약 98.33% 신뢰구간으로, 수신 철회율의 차이는 별도의 95% 신뢰구간으로 검토했습니다.

## 확대를 보류한 이유 4가지

1. **방문 완료율 개선폭이 충분하다고 판단하기 어렵습니다.** B군은 A군보다 +1.089%p 높았지만, 신뢰구간의 보정 하한은 **+0.286%p**로 최소 개선폭 +0.500%p에 못 미쳤습니다.
2. **수신 철회율 증가가 허용 범위 안이라고 판단하기 어렵습니다.** B군과 A군의 차이는 +0.058%p였고, 95% 신뢰구간 상한은 **+0.265%p**로 허용 상한 +0.200%p를 넘었습니다.
3. **센터 수용량이 미확인입니다.** 확대 시 예상되는 방문을 센터에서 감당할 수 있는지 확인이 필요합니다.
4. **비용이 미확인입니다.** 추가 발송과 운영에 드는 비용을 확인해야 합니다.

## 입력을 바꾸면 판단은 어떻게 달라지나요?

B군의 방문 완료를 **1,597명에서 1,680명으로**, 수신 철회를 **139명에서 120명으로** 바꿨습니다. 두 군의 배정 인원과 A군의 결과, 비교 방식은 원래 가상 사례와 같습니다.

| 수치 기준 | 변경 후 결과 | 판정 |
| --- | ---: | --- |
| 방문 완료율 개선폭의 보정 하한이 +0.500%p 이상 | **+0.808%p** | 충족 |
| 수신 철회율 증가의 95% 신뢰구간 상한이 +0.200%p 이하 | **+0.135%p** | 충족 |

두 수치 기준을 충족한 상태에서 **센터 수용량과 비용**의 확인 상태만 바꿔 비교했습니다.

| 센터 수용량 | 비용 | 자동 판단 |
| --- | --- | --- |
| 미확인 | 미확인 | **확대 보류** |
| 조건 충족 확인 | 미확인 | **확대 보류** |
| 미확인 | 조건 충족 확인 | **확대 보류** |
| 조건 충족 확인 | 조건 충족 확인 | **확대 검토 가능** |

표의 확인 상태는 가상 입력입니다. 기준 비교에는 반올림 전 수치를 사용합니다.
