# 가상 정기점검 A/B 테스트 공유 보고서

**자동 판단은 확대 보류입니다.** 정기점검 안내를 받은 두 군을 배정 후 28일 동안 관측하는 가상 사례입니다. 분석 도구가 내보낸 공유 보고서의 입력값과 판단을 옮겼습니다.

## 판단에 쓴 입력값

| 고객 수 | A군 관리 필요성 안내 | B군 예약 편의 안내 |
| --- | ---: | ---: |
| 최초 배정 | 15,482명 | 15,603명 |
| 방문 완료 | 1,416명 | 1,597명 |
| 수신 철회 | 129명 | 139명 |

- 방문 완료율의 최소 개선폭은 **+0.500%p**, 수신 철회율 증가의 허용 상한은 **+0.200%p**로 입력했습니다.
- 센터 수용량과 비용은 각각 **미확인**으로 입력했습니다.
- 가상 사례에서는 무작위 배정, 고객별 독립성, 관측 완료, 사전 종료 기준을 확인한 상태로 설정했습니다. 방문 완료율의 차이는 사전 지정 3개 비교를 보정한 약 98.33% 신뢰구간으로, 수신 철회율의 차이는 별도의 95% 신뢰구간으로 검토했습니다.

## 확대를 보류한 이유 4가지

1. **방문 완료율 개선폭이 충분하다고 판단하기 어렵습니다.** B군은 A군보다 +1.089%p 높았지만, 신뢰구간의 보정 하한은 **+0.286%p**로 최소 개선폭 +0.500%p에 못 미쳤습니다.
2. **수신 철회율 증가가 허용 범위 안이라고 판단하기 어렵습니다.** B군과 A군의 차이는 +0.058%p였고, 95% 신뢰구간 상한은 **+0.265%p**로 허용 상한 +0.200%p를 넘었습니다.
3. **센터 수용량이 미확인입니다.** 확대 시 예상되는 방문을 센터에서 감당할 수 있는지 확인이 필요합니다.
4. **비용이 미확인입니다.** 추가 발송과 운영에 드는 비용을 확인해야 합니다.

두 수치 기준을 충족하고 센터 수용량과 비용을 확인했을 때 확대를 다시 검토합니다. 기준 비교에는 반올림 전 수치를 사용합니다.
