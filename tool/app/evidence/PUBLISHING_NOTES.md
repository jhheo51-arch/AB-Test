# 통합 배포 검증 메모

기존 원격 앱을 기준으로 설계 기능을 통합하는 동안 추가된 최신 사용 안내도 병합했습니다. 최신 원격의 전자책, 루트 안내, 기본 계산과 선택적 LLM 기능의 구분을 되돌리지 않았습니다. 현재 공개 저장소에 반영한다는 사용자 확인 후 배포를 진행합니다.

부모 단계의 최초 재포장 검사에서 모바일 도움말 닫기 후 스크롤 가능 검사만 실패했습니다. 기록은 `packaging-initial/interface_scroll_before_close_event.log`에 보존합니다. 기존 앱은 native dialog의 close 이벤트에서 이전 스크롤 위치를 복원하는데, 검사는 그 이벤트를 기다리지 않고 새 스크롤을 요청했습니다. 해당 검사에 native close 이벤트 관측 대기를 추가했습니다. 영상의 즉시 정지와 입력 및 동의 상태 보존 검사는 이 대기보다 먼저 유지했습니다. 실제 앱의 동작 코드는 이 검사 조정으로 바꾸지 않았으며, 일반적인 사용자 스크롤 결함을 수정했다고 주장하지 않습니다.

수정한 검사로 전체 직렬 통합 21개 스크립트를 재실행해 모두 통과했습니다. 도움말 및 인터페이스 84개 검사도 통과했습니다. 기존 병렬 Worker 준비 시간 초과의 일반 원인은 여전히 미확정입니다. 마지막 ZIP의 별도 압축 해제 실행 결과와 정확한 바이트 해시는 `../../downloads/package_verification.json`을 따릅니다. 실제 모델 호출과 사람의 과업 관찰은 수행하지 않았습니다.
