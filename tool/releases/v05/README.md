Windows + Python 3가 필요합니다. 압축을 풀어 `launch.cmd`를 실행하고 출력된 loopback URL을 여세요. Node는 일반 사용에 필요하지 않습니다. LLM 설명은 별도 기존 Hermes 연결·동의가 필요합니다.

ZIP은 CRC와 전체 멤버 바이트를 대조했고 별도 추출본에서 새 흐름 37개를 재실행했습니다. 합성 검사이며 실제 사용자 효과나 전체 보안 인증이 아닙니다. ZIP은 검증한 원본 바이트를 유지합니다. 따라서 ZIP README의 마지막 GitHub 미반영 문구는 생성 당시 기록이며 현재 원격 동기화 여부는 이 저장소의 현재 문서를 우선하세요.
