# 최신 배포본

[AB_Test_Workspace.zip](AB_Test_Workspace.zip)을 내려받아 압축을 풀고 launch.cmd를 실행합니다. Windows + Python 3가 필요합니다. [앱 안내](../app/README.md)와 [시연 영상](../app/help/walkthrough.mp4)을 참고하세요.

이 폴더에는 현재 배포본만 둡니다. 내부 형식 식별자는 구형 파일 읽기와 검증에 필요하므로 유지하며 사용자용 판 번호는 표시하지 않습니다. 합성 자동화·별도 압축 해제본 검사 범위는 [검증 기록](package_verification.json)을 참조하세요. 사용자 입력·개인 피드백은 배포본에 포함하지 않습니다.
