## 포트폴리오에서 연결된 실행본

[AB_Test_Workspace.zip](AB_Test_Workspace.zip)을 내려받아 압축을 풀고 launch.cmd를 실행합니다. Windows + Python 3가 필요합니다. [앱 안내](../app/README.md)와 [시연 영상](../app/help/walkthrough.mp4)을 참고하세요.

아래 검증 기록은 이 폴더의 기존 ZIP에 해당합니다. 명시적 동의 후 별도 로컬 열 연결 템플릿을 내려받고 새 CSV에서 후보를 재사용할 수 있습니다. 원본 군 값·연결·숫자·조건은 다시 확인해야 하며 템플릿 지문도 익명성 보장이 아닙니다. 고정 합성 CSV 다운로드는 현재 입력을 바꾸지 않습니다. 현재 영상은 기존 설계·조건·분석 흐름이며 템플릿 사용법은 앱 안내를 확인하세요. 데이터 없는 **상황부터 설계**, 계획 저장·새 페이지 복원·결과 연결을 포함하며 로컬 고정 질문·후보이지 자유로운 AI 의미 분석이 아닙니다. 기존 영상은 현재 설계·조건 기록을 포함한 실제 Chrome 조작 영상(160.16초, 무음 한국어 자막 26구간)으로 교체했습니다. 내부 형식 식별자는 구형 파일 읽기와 검증에 필요하므로 유지하며 사용자용 판 번호는 표시하지 않습니다. [정확한 파일 허용목록](PACKAGE_ALLOWLIST.json), CRC·원본 바이트 대조와 별도 압축 해제본의 실제 Chrome 검사 결과는 [검증 기록](package_verification.json)을 참조하세요. 실제 모델 호출과 사람 과업 관찰은 이번 통합에서 각각 0건입니다. 사용자 입력·개인 피드백은 배포본에 포함하지 않습니다.


확인됨·아님·모름 조건 질문과 선택 근거 기록을 포함합니다. 모름은 추론을 허용하지 않으며 집단 사전성은 전체 추론과 별개입니다. 메모는 로컬 JSON에만 저장하고 공개 HTML/PDF·LLM 전송에는 제외합니다. 구형 true는 구형 사용자 확인, false는 모름으로 복원합니다. 독립 검증이나 증빙 진위 검사가 아닙니다. 영상에서 핵심 네 조건의 확인됨은 합성 시연 가정이며 실제 실험 인증이 아닙니다.
