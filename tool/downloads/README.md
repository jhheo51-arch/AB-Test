# 최신 배포본

[AB_Test_Workspace.zip](AB_Test_Workspace.zip)을 내려받아 압축을 풀고 launch.cmd를 실행합니다. Windows + Python 3가 필요합니다. [앱 안내](../app/README.md)와 [시연 영상](../app/help/walkthrough.mp4)을 참고하세요.

이 폴더에는 현재 배포본만 둡니다. 데이터 없는 **상황부터 설계**, 계획 저장·새 페이지 복원·결과 연결을 포함하며 로컬 고정 질문·후보이지 자유로운 AI 의미 분석이 아닙니다. 기존 열 연결 영상은 보존했고 설계 튜토리얼은 추가하지 않았습니다. 내부 형식 식별자는 구형 파일 읽기와 검증에 필요하므로 유지하며 사용자용 판 번호는 표시하지 않습니다. [정확한 파일 허용목록](PACKAGE_ALLOWLIST.json), CRC·원본 바이트 대조와 별도 압축 해제본의 실제 Chrome 검사 결과는 [검증 기록](package_verification.json)을 참조하세요. 실제 모델 호출과 사람 과업 관찰은 이번 통합에서 각각 0건입니다. 사용자 입력·개인 피드백은 배포본에 포함하지 않습니다.


확인됨·아님·모름 조건 질문과 선택 근거 기록을 포함합니다. 모름은 추론을 허용하지 않으며 집단 사전성은 전체 추론과 별개입니다. 메모는 로컬 JSON에만 저장하고 공개 HTML/PDF·LLM 전송에는 제외합니다. 구형 true는 구형 사용자 확인, false는 모름으로 복원합니다. 독립 검증이나 증빙 진위 검사가 아닙니다. 기존 영상에 새 조건·설계 튜토리얼은 추가하지 않았습니다.
