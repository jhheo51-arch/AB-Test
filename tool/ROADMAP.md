# 남은 과제와 현재 상태

현재 앱은 [app/](app/README.md), 사용 절차는 [도구 진입점](README.md)을 확인하세요. GitHub에는 현재 앱·현재 문서·현재 배포본만 유지하고 이전 자료는 로컬에 보관합니다. 아래 향후 우선순위는 제안이며 실제 검토·승인 완료를 뜻하지 않습니다.

## 완료·확인한 범위

- R01: 알려진 엔진 오류 코드 허용목록과 CLI 전 미등록 코드 거절. 구조/허용 값 검사는 익명성·출처·사실 정확성 인증이 아님.
- R02: 탐색+결측 복합 제한, 실제 빈 군, invalid 설명 구체화. 숫자 재계산·실제 승인 없음.
- R03: 최초 입력 텍스트·직전·현재 CSV 해시를 구분. 구형 기록은 대상을 추정하지 않으며 원자료 재검증/모든 중간 이력 보관은 아님.
- 열 연결·요약·판단 기록·저장/복원·HTML/PDF·동의 후 실제 설명 연결.
- 페이지 내 시연 창: 입력을 잃지 않도록 URL 이동 없이 열고 닫기. 닫기/Escape에서 영상 정지·상태 유지 검사.
- 데이터 없는 설계 진입: 고정 질문·후보·제안/미확인/사용자 확인, 계획만 저장·복원, CSV 연결, 결과 열람 후 변경 표지. 실제 AI 의미 해석·승자 예측·사전 등록 인증은 아님. 현재 실제 Chrome 시연에 설계·저장·새 페이지 복원·CSV 연결을 포함.

현재 자동검사는 [검증 요약](app/verification.json)과 각 검사 결과를 참조하세요. 합성 검사와 실제 사용자·현장 효과는 다릅니다.

## 다음 작업 전 경계 수정

설계/입력의 여러 줄 맥락, 가져온 근거·맥락의 CRLF/CR 원문 보존, null/빈 집단의 CSV 직렬화 충돌 거절, 현재 계보 없는 중복 해시의 거절 및 구형 미분류 해시 보존, ZIP의 검토 문서 경로를 수정했습니다. [경계 회귀](app/fix-evidence/semantic/BROWSER_VERIFICATION.json)와 [통합 검사](app/integration_verification.json)를 별도로 확인하세요. 기존 통계·방법 게이트를 완화하지 않았으며 성능 전반 개선이나 사람 과업 검증을 뜻하지 않습니다. 기존 영상을 현재 앱 실제 Chrome 시연(160.16초)으로 교체했습니다. 반복 사용의 첫 묶음으로 선택적 로컬 열 연결 템플릿, 한정 CRM 별칭·원본 군 값 안내, 고정 합성 CSV 다운로드를 구현했습니다. 현재 영상은 기존 설계·조건 흐름을 그대로 보존했으며 템플릿 튜토리얼은 아닙니다. [새 연결 검사](app/column_profile_verification.json)와 [개인정보·재확인 경계](app/profile-evidence/IMPLEMENTATION_NOTES.md)를 확인하세요.

## 다음 순서

구현한 설계 진입과 기존 분석 과업의 막힘·오독을 실제 사람에게 관찰받는 것이 다음 단계입니다. 현재 계획 안내는 로컬 고정 질문·후보이며 자유 생성 대화가 아닙니다. 사람 관찰은 0건입니다. 고객 원자료 반출·녹화는 검토의 기본 조건이 아닙니다. 개인 피드백은 별도 허락 없이 GitHub에 게시하지 않습니다.

이전 대용량 도구 대기 실패와 시간 초과를 범용 성능 해결로 표현하지 않습니다. 현재 회귀에서 큰 파일 표시를 기다리는 자동화 상한을 명시해 재검사하며, 분석 조건·지원 상한을 완화하지 않습니다. 실제 시간 절감·성과·전체 보안/접근성 인증을 주장하지 않습니다.

CRM 발송·고객 관리·자동 적용·무제한 세분화·시간/금액/순차/군집 분석으로 범위를 자동 확장하지 않습니다. 제품 정책은 [기준안](prd/BASELINE.md), 실제 계약은 [입력 계약](app/INPUT_CONTRACT.md)과 [맥락 계약](app/CONTEXT_CONTRACT.md)을 참조하세요.
