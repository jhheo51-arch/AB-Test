# CRM A/B 테스트 작업실

**[현재 앱](app/README.md) · [첫 MVP 실행 ZIP](https://github.com/jhheo51-arch/AB-Test/releases/download/tool-rollout-report-20261123/AB_Test_Workspace_rollout_scope_mvp_20261124.zip) · [시연 영상](app/help/walkthrough.mp4) · [남은 과제](ROADMAP.md)**

CRM 전체 운영이 아니라 A/B 테스트 설계·분석·판단을 돕습니다. 실제 실험은 외부에서 수행하고 기기 안에서 입력·계산·판단 기록을 연결합니다.

공개된 시작 화면 바로가기 실행본의 원래 [Release ZIP](https://github.com/jhheo51-arch/AB-Test/releases/download/tool-rollout-report-20261123/AB_Test_Workspace_rollout_shortcuts_20261123.zip)도 유지합니다. 기존 저장소 ZIP은 같은 세 버튼과 R08 수정을 결합해 검사한 파일입니다. [현재 ff6d463 기준 검증](app/startscreen-evidence/IMPLEMENTATION_NOTES.md).

## 처음 사용하기

새 실행 ZIP을 풀고 `launch.cmd`를 실행하세요. Windows와 Python 3가 필요합니다. 실행 창을 유지하고 출력된 loopback URL을 여세요. HTML만 더블클릭하는 방식은 지원하지 않습니다. 일반 사용에 Node는 필요하지 않습니다.

앱의 **시연 영상 보기**를 누르면 도움말 창이 열립니다. 입력과 결과를 유지한 채 닫고 계속할 수 있습니다. 원본 군 값의 예시는 A=control, B=treatment이며 값을 고친 뒤 확인 체크를 다시 선택해야 합니다. 영상은 별도 합성 자료의 실제 조작 시연입니다.

현재 영상의 구간·재현·원래 녹화 근거는 [튜토리얼 안내](tutorial/README.md)를 참조하세요.

가상 정기점검 사례를 불러오면 방문 완료율과 수신 철회 기준, 센터 수용량과 비용 상태를 한 화면에서 검토할 수 있습니다. 입력과 판단 근거는 프로젝트를 복원하면 다시 계산되며 공유 보고서에도 표시됩니다. [입력과 보고서 사용법](app/README.md#방문-완료율과-수신-철회-기준으로-확대-판단)

데이터가 없으면 왼쪽 **상황부터 설계**에서 상황·목적·대상·측정·위험·제약에 답하고 고정된 A/B 후보를 선택하세요. 자유로운 AI 의미 분석이 아니라 기기 안의 정해진 질문과 편집 가능한 제안입니다. 대상·분석·적용 세그먼트를 별도로 기록하고, 결과 없는 계획도 저장·새 페이지 복원할 수 있습니다. 같은 계획으로 CSV 결과를 연결하되 실제 배정·관측·종료·사전성은 별도 확인합니다. 계획 확인은 분석 조건을 자동으로 켜지 않습니다.

열 연결·전체/지원 집단 계산·요약·판단 작성·집계 저장/복원·범위 확인 후 HTML/PDF와 동의 후 LLM 설명을 제공합니다. 도움말 동작은 유지하고 영상은 **현재 설계·조건 기록을 포함한 실제 Chrome 조작 시연(160.16초)**으로 교체했습니다. [현재 통합 검증](app/integration_verification.json)과 [검토 상태](review/REVIEW_STATUS.md)를 참조하세요. 실제 사람 과업 관찰은 0건이며 자동화를 사용자 효과나 전체 보안/접근성 인증으로 세지 않습니다.

## 입력·복원 경계 수정

설계와 분석 맥락의 여섯 항목은 여러 줄을 지원하고, 가져온 CRLF/CR 근거·맥락은 해당 항목을 편집하기 전까지 원문을 보존합니다. 같은 군의 null/빈 집단이 CSV에서 겹치는 파일과 현재 계보 없는 중복 해시는 복원 전에 거절합니다. 구형 미분류 해시는 원래 범위를 유지합니다. ZIP 검토 문서는 공개 소스 링크와 실제 오프라인 기록 위치를 구분합니다. [회귀 결과](app/fix-evidence/semantic/BROWSER_VERIFICATION.json)를 참조하세요. 경계 수정 후 교체한 시연을 보존하고 선택적 로컬 열 연결 템플릿·원본 군 값 안내·고정 합성 CSV 다운로드를 추가했습니다. [재사용 절차와 개인정보 경계](app/README.md#같은-csv-형식의-열-연결을-다시-쓰기)를 확인하세요. 현재 영상은 새 템플릿 튜토리얼이 아닙니다.

## 실행 환경과 오류 복구

한글·공백 경로의 실행, 점유 포트의 명시적 거절, 두 인스턴스와 종료/재시작, 키보드 핵심 흐름, 별도 200% 확대·320/390px, 대용량 경계·취소·복구를 실제 Windows/Chrome에서 합성 자동화로 점검합니다. [환경·관측 결함·최소 수정·미실시 범위](app/r08-evidence/IMPLEMENTATION_NOTES.md)를 확인하세요. 상태 검사 수는 실제 실행 장부에서 자동 동기화합니다. 실제 스크린리더 음성이나 모든 약한 기기의 성능·사람 사용성 검증은 아니며 모바일에 200%를 함께 적용한 추가 초협폭 가로 넘침은 남아 있습니다.

## 배포 관리

새 실행본은 GitHub Releases에 올리고, 다운로드 폴더의 ZIP은 기존 포트폴리오 링크용으로 보관합니다. 이전 판·중복 스냅샷·과거 ZIP·초기 초안은 로컬에 보관합니다. 일반 Git 커밋 이력은 유지하며 강제 재작성하지 않습니다. 화면·시연·사용자 안내에는 제품 판 번호를 표시하지 않습니다. 저장 파일 호환성·엔진 코드 허용목록·해시 검증을 위한 내부 식별자는 유지합니다. 전자책·다른 영상 작업은 별도 영역이므로 이 정리에 포함하지 않습니다.


## 실행 조건을 모를 때

무작위 배정·독립·개인별 관측 완료·고정 종료에 **확인됨 / 아님 / 모름**으로 답합니다. 기본값은 모름이며 네 항목 모두 확인됨이 아니면 추론을 열지 않습니다. 집단 기준 사전성의 아님·모름은 집단을 탐색으로 제한하며 유효한 전체 추론까지 막지는 않습니다. 계획 확인은 이 상태를 자동 확인하지 않습니다.

선택 근거 메모(항목당 1,000 UTF-16 코드 단위)는 사용자 진술이며 독립 검증이 아닙니다. 메모는 로컬 프로젝트 JSON과 로컬 결과의 계산 방법에만 담고 공개 HTML/PDF·최소 AI 전송 정보에는 넣지 않습니다. 개인정보·비밀값을 적지 마세요. 상태와 메모를 바꾸면 이전 결과·확인·공유·인쇄를 폐기합니다.

구형 파일의 체크 true는 ‘구형 사용자 확인’으로 유지하고 근거를 만들지 않습니다. false는 ‘미확인/모름’이며 ‘아님’으로 바꾸지 않습니다. 새 실제 입력에는 합성 가정·메모가 이어지지 않습니다. 현재 영상은 계획 저장·복원부터 모름/합성 가정과 판단까지 보여 줍니다. 핵심 네 조건의 확인됨은 오직 합성 시연 가정이며 실제 실험 인증이 아닙니다. 자세한 호환 정책은 [입력 계약](app/INPUT_CONTRACT.md)을 참조하세요.
