# CRM A/B 테스트 작업실

**[현재 앱](app/README.md) · [최신 ZIP](downloads/AB_Test_Workspace.zip) · [시연 영상](app/help/walkthrough.mp4) · [남은 과제](ROADMAP.md)**

CRM 전체 운영이 아니라 A/B 테스트 설계·분석·판단을 돕습니다. 실제 실험은 외부에서 수행하고 기기 안에서 입력·계산·판단 기록을 연결합니다.

## 처음 사용하기

최신 ZIP을 풀고 launch.cmd를 실행하세요. Windows와 Python 3가 필요합니다. 실행 창을 유지하고 출력된 loopback URL을 여세요. HTML만 더블클릭하는 방식은 지원하지 않습니다. 일반 사용에 Node는 필요하지 않습니다.

앱의 **시연 영상 보기**를 누르면 도움말 창이 열립니다. 입력과 결과를 유지한 채 닫고 계속할 수 있습니다. 원본 군 값의 예시는 A=control, B=treatment이며 값을 고친 뒤 확인 체크를 다시 선택해야 합니다. 영상은 별도 합성 자료의 실제 조작 시연입니다.

## 현재 자료

- [앱·검사 소스](app/), [실행/지원 안내](app/README.md), [검증 요약](app/verification.json).
- [제품 합의·문답](prd/README.md), [로드맵](ROADMAP.md).
- [사용자 과업 자료](review/README.md): 합성 CSV, 진행자 가이드, 빈 기록지. 실제 개인 피드백은 로컬에서 관리합니다.

데이터가 없으면 왼쪽 **상황부터 설계**에서 상황·목적·대상·측정·위험·제약에 답하고 고정된 A/B 후보를 선택하세요. 자유로운 AI 의미 분석이 아니라 기기 안의 정해진 질문과 편집 가능한 제안입니다. 대상·분석·적용 세그먼트를 별도로 기록하고, 결과 없는 계획도 저장·새 페이지 복원할 수 있습니다. 같은 계획으로 CSV 결과를 연결하되 실제 배정·관측·종료·사전성은 별도 확인합니다. 계획 확인은 분석 조건을 자동으로 켜지 않습니다.

열 연결·전체/지원 집단 계산·요약·판단 작성·집계 저장/복원·범위 확인 후 HTML/PDF와 동의 후 LLM 설명을 제공합니다. 기존 열 연결 영상의 바이트와 도움말 동작을 유지했으며 **새 설계 기능의 튜토리얼은 이 영상에 추가하지 않았습니다**. [현재 통합 검증](app/integration_verification.json)과 [검토 상태](review/REVIEW_STATUS.md)를 참조하세요. 실제 사람 과업 관찰은 0건이며 자동화를 사용자 효과나 전체 보안/접근성 인증으로 세지 않습니다.

## 배포 관리

이 도구 영역에는 **최신본 하나만** 둡니다. 이전 판·중복 스냅샷·과거 ZIP·초기 초안은 로컬에 보관합니다. 일반 Git 커밋 이력은 유지하며 강제 재작성하지 않습니다. 화면·시연·사용자 안내에는 제품 판 번호를 표시하지 않습니다. 저장 파일 호환성·엔진 코드 허용목록·해시 검증을 위한 내부 식별자는 유지합니다. 전자책·다른 영상 작업은 별도 영역이므로 이 정리에 포함하지 않습니다.
