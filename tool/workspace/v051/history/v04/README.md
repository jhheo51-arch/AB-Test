# A/B 테스트 작업실 v0.4

## 실행

이 폴더의 **launch.cmd**를 더블클릭하세요. Python과 최신 브라우저가 필요하며 서버 창을 열어 둡니다. `index.html`만 더블클릭하는 앱이 아닙니다. 기존 v0.3은 별도 폴더에 그대로 보존했습니다.

## 이번 개선

가상 페르소나 검토의 우선 과제 F01·F02를 구현했습니다.

1. **실험 맥락 인계**: A/B 정책 설명, 성공 사건, 관측 기간, 분석 대상, 목적을 결과·HTML 보고서·PDF에 연결합니다. A/B 비율 카드에도 정책 이름이 붙습니다. 미기록한 설명과 대상은 추정하지 않습니다.
2. **이번 결과의 이유**: 전체 보류, 개별 검정 기준 충족 후 Holm 보정에서 보류, A/B 우세, 설계 미확인, 빈 분모, 집단 결측, 탐색 집단, 직접 차이 미지원·보류·근거 있음의 설명을 구분합니다.
3. **다음 확인**: 결과 상태에 따라 확인할 기록·원래 계획·보호 조건·적용 범위를 안내합니다. 실험을 유의할 때까지 연장하거나 자동 적용하라고 권하지 않습니다.

설명은 `narrative.js`가 **실제 엔진 결과를 읽어 기기 안에서** 만듭니다. 새 통계 검정을 실행하거나 AI가 숫자를 만드는 방식이 아닙니다. 선택적 실제 AI 설명은 별도 버튼·동의로 유지합니다. 새 정책·대상·목적과 로컬 설명을 모델에 추가 전송하지 않습니다.

## 저장·공유

- 새 프로젝트 파일은 `format: ab-local-project, version: 3`입니다. 대상 필드가 포함됩니다.
- 구형 `version: 2` 프로젝트도 읽습니다. 대상 정보가 없으면 빈값·미기록으로 표시합니다. 구형 앱은 새 형식을 읽지 못할 수 있으므로 새 파일은 v0.4에서 여세요.
- 대상·정책 등 서술을 바꾸면 이전 결과와 공유 확인이 무효화됩니다. 재분석 후 새 설명과 기록을 사용합니다.
- 집단 상세를 공유에서 제외하면 집단별 수치·판정 이유·직접 집단 차이 설명은 보고서에서 제거합니다. 단, 사용자가 적은 정책·목적·분석 대상은 공유됩니다. 민감정보가 있는지 직접 확인해야 합니다.
- 원자료·개인 ID·LLM 출력은 기본 프로젝트·보고서에 포함하지 않습니다. 집계·작은 집단도 민감할 수 있습니다.

## 검증

- 기존 브라우저 흐름 **43개** 통과. 실제 모델 호출과 실패 주입을 구분합니다.
- 새 맥락·설명·저장·복원·공유 범위·HTML 이스케이프·최소 전송의 브라우저 검사 **19개** 통과.
- 실제 엔진 결과를 사용하는 설명 분기 검사 **18개** 통과.
- 수학 엔진 smoke **19개 시험 그룹**, 독립 일반 사례 **224개** 대조 통과. 상호작용은 수치 5개, 정보량 차단 5개, 공개 API 상한 차단 1개를 구분합니다.
- 정책·대상·지표가 실제 PDF 텍스트에 전달되는지 확인했습니다. 기본 합성 보고서는 **3쪽, 최소 글자 12pt**입니다. 임의의 모든 사용자 문서가 같은 쪽수인 것은 아닙니다.
- `engine.js`와 `worker.js`는 v0.3과 바이트 단위로 같습니다.

핵심 증거는 `BROWSER_VERIFICATION.json`, `DECISION_VERIFICATION_v04.json`, `PDF_VERIFICATION.json`, `VERIFICATION_v04.json`입니다. 실제 사람의 사용성 시험·현장 성과·전체 보안/접근성 인증은 아닙니다.

## 파일

- `index.html`, `app.js`: 사용자 입력·화면·저장·공유 연결
- `narrative.js`: 판정별 로컬 설명과 이스케이프된 실험 맥락
- `theme-v03.css`, `decision-v04.css`: 유지한 시각 토큰과 새 맥락·설명 스타일
- `tests/narrative_smoke.cjs`, `tests/verify_decision_v04.py`: 새 기능 검사
- `history/v03/`: 이전 판의 문서·검증 기록. 현재 판의 검증으로 혼동하지 않도록 분리
- `screenshots/v04_*.png`: 현재 판의 실제 화면
- `screenshots/V04_CONTEXT_REPORT.pdf`: 맥락 전달을 검증한 합성 시험 PDF
