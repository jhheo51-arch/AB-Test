# A/B 테스트 작업실 — 로컬 MVP v0.2

CRM A/B 테스트의 **입력 → 검증된 계산 → 결과·집단 차이 → 선택적 LLM 설명 → 판단 기록·공유**를 실제로 연결한 로컬 앱입니다. 기존 v0.1 클릭 데모를 보존한 새 버전입니다. 상용 제품이나 보안·통계 전 범위 인증본이 아닙니다.

## 실행

1. 이 폴더의 **launch.cmd**를 더블클릭합니다. 이 컴퓨터에 Python이 있어야 합니다.
2. 브라우저가 열리면 합성 예시 또는 표·CSV로 시작합니다. 서버 창을 닫으면 앱 연결도 끝납니다.
3. `index.html`만 더블클릭하지 마세요. Worker와 설명 브리지 때문에 loopback 서버로 열어야 합니다.

터미널에서는:

```text
python launch.py
```

`launch.py`는 사용 가능한 빈 포트의 `127.0.0.1`에만 엽니다. 공개 배포·외부 터널은 없습니다. 기존 Hermes CLI를 PATH 또는 Windows 설치 위치에서 찾습니다. 인증 파일은 앱이 직접 읽지 않으며, 실제 설명 요청이 성공해야 모델 연결을 확인한 것입니다. CLI를 찾지 못해도 표·계산·보고서는 사용할 수 있습니다. 필요하면 `AB_HERMES_EXE`에 CLI 실행 파일 경로만 지정할 수 있습니다. 키·토큰을 넣는 변수가 아닙니다.

## 가장 짧은 체험 경로

- **합성 집단 표로 체험 → 입력값 확인 → 숫자·조건 확인 → 분석**.
- 예시의 체크 표시는 합성 가정입니다. 실제 실험 기록이나 무작위성을 증명하지 않습니다.
- 실제 파일·새 입력으로 바꾸면 이전 결과와 예시의 추론 확인을 해제합니다. 조건이 모르면 체크하지 않고 기술 통계만 볼 수 있습니다.
- 전체 결과와 각 집단의 비율, B−A 위험차, 원래·조정 p값, 명목 구간, 직접 집단 차이를 구분합니다.
- LLM 설명은 결과 화면에서 **전송 상태 미리보기 확인 → 별도 체크 → 실제 설명 요청** 순서입니다. 기존 모델 사용량이 발생할 수 있습니다.
- 정리·공유에서 판단과 재검토 조건을 기록하고, 범위를 확인한 뒤 HTML 다운로드 또는 인쇄/PDF를 사용합니다.

## 실제 지원과 제한

|구분|현재 지원|
|---|---|
|집계 입력|CSV/TSV, BOM·인용부호·인용 줄바꿈, A/B 전체 또는 주요 속성 두 집단|
|개인 입력|가명 ID별 한 행, 이항 결과, 관측 완료 여부 확인·중복 검증|
|간단 문장|정해진 `A: 1000명 중 130명 성공` / `B: 1000명 중 150명 성공` 형식만 파싱|
|계산|양측 Fisher, Wilson·Newcombe 명목 95% 구간, Holm 가족 보정, 조건부 직접 위험차 차이|
|설계 안내|규칙 기반 확인 사항과 목적·정책·지표 기록. 결과 없는 계획도 프로젝트 저장 가능|
|LLM|기존 Hermes mira 프로필의 실제 호출로 상태 설명. 자유 자연어 설계·후보 생성은 아직 미연결|
|저장|계획·확인한 집계·판단 JSON 다운로드와 복원. 원자료·개인 ID·LLM 출력 제외|
|공유|읽기 전용 HTML, 브라우저 인쇄/PDF. 공개 링크·자동 배포 없음|

초기 상한은 **UTF-8 2MiB·50,000 데이터 행·각 군 전체 200,000명**입니다. XLSX, 연속형·시간·금액, 순차·적응·군집·반복·교차 설계, 다수 정책은 이 경로에서 지원하지 않습니다. 전체 비교와 주지표가 사전 계획된 단일 이항 실험을 전제합니다. 사후 선택한 전체 지표를 이 경로의 확증 결과로 사용하지 마세요.

무작위·독립·성숙 관측·고정 종료는 사용자 확인이지 별도 인증이 아닙니다. 사후 집단은 탐색 기술 통계로 제한합니다. 한 집단만 유의하다고 집단 차이를 주장하지 않습니다. `hold`는 동등성이나 안전 증명이 아닙니다. 명목 구간은 Holm 동시 구간이 아니며 Fisher와 완전히 쌍대인 구간도 아닙니다. 보호·경제성·실제 적용 승인·자동 발송은 별개입니다.

## 데이터와 설명 경계

- 표·CSV는 브라우저 Worker에서 파싱·집계·계산합니다. raw CSV 수신 API가 없습니다.
- LLM에는 숫자·집단 이름·목적·파일명·ID가 아니라 **판정 상태, G1/G2 판정, 한계 코드**만 보냅니다. 자격증명은 HTML·프로젝트·보고서에 넣지 않습니다.
- 설명을 안 쓰면 원자료·계산에 대해 외부 호출이 필요하지 않습니다. 설명을 쓰면 기존 Hermes와 그 모델 제공자의 처리·기록 정책이 적용됩니다. 자격증명 저장소를 앱이 직접 읽지 않는 것과 모델 실행 자체가 인증을 사용하는 것은 구분합니다.
- 구조·근거 키·숫자 금지 검사는 의미의 완전한 검증이 아닙니다. LLM은 원래 계산을 변경하지 않습니다. 실패하면 실패 메시지와 규칙 설명을 유지합니다.
- 프로젝트·공유에는 집계가 들어갑니다. 집계·작은 집단도 민감할 수 있습니다. 목적·판단에 민감정보를 직접 적지 마세요. 그룹 상세는 공유에서 기본 제외하며, 원자료는 저장하지 않아 복원 뒤 원자료의 중복·성숙 검증을 다시 할 수 없습니다.
- 분석 후 입력·조건을 고치면 결과·확인을 무효화합니다. 이 변경 관리는 보안 감사 로그나 사전등록 인증을 대신하지 않습니다. 새로 고침하면 미저장 입력이 사라집니다.

## 근거와 검증 파일

- `FLOW_REVIEW.md`: 기존 화면의 직접 브라우저 검토와 우선 수정 세 가지.
- `INPUT_DECISION_CONTRACT.md`: 입력·추론 게이트·판정·LLM 계약.
- `engine.js`, `worker.js`: 실제 브라우저 계산 경로.
- `tests/engine_smoke.cjs`: 파서·오류·경계·수학 smoke 검사.
- `tests/generate_reference.py`, `golden_reference.json`, `REFERENCE_NOTES.md`: 별도 SciPy/statsmodels 기준과 재생성 조건.
- `tests/compare_reference.cjs`, `ENGINE_REFERENCE_VERIFICATION.json`: 엔진과 독립 기준 대조. 최종 수량·차이는 해당 보고서 확인.
- `tests/verify_browser.py`, `BROWSER_VERIFICATION.json`: 실제 Chrome 회귀검사. live 모델 호출과 주입한 실패 시험을 구분.
- `LLM_BRIDGE_VERIFICATION.json`: 서버 보호와 합성 상태의 실제 모델 연결 검사.
- `VERIFICATION.json`: 최종 전달 점검과 파일 해시.
- `screenshots/`: 실제 데스크톱·모바일 화면, 합성 보고서 HTML/PDF.

```text
node tests/engine_smoke.cjs
node tests/compare_reference.cjs
python tests/verify_browser.py --url http://127.0.0.1:<실행한포트>
```

마지막 명령에 `--live-llm`을 추가하면 실제 모델 사용량이 발생합니다. 브라우저 시험에는 Playwright와 Chrome이 필요합니다. 앱 실행 자체에는 Python 표준 라이브러리와 최신 브라우저만 필요합니다. 독립 기준 재생성은 별도 검증 환경·버전을 사용하며 설치·실행 방법은 `tests/REFERENCE_NOTES.md`에 있습니다.

### 이번 실제 검증 범위

- 엔진 smoke 19개 시험 그룹 통과. 그중 작은 Fisher 표 1,936개 조합 대조를 포함합니다.
- 독립 기준의 일반 사례 224개에서 Fisher·Wilson·Newcombe·위험차 대조 통과. Fisher 최대 절대 차이는 약 5.50e-13입니다.
- 직접 집단 차이는 수치 대조 5개, 정보량·관측 조건의 추론 차단 5개, 합산 군별 상한의 차단 1개로 구분합니다. 마지막 큰 사례는 수치 검증한 것이 아닙니다. 원래 입력과 기준은 바꾸지 않았고, 최초 비교의 FAIL 보고서는 `tests/ENGINE_REFERENCE_INITIAL_FAILURE.json`에 보존했습니다.
- 실제 엔진의 Holm 가족 m=1 224개와 m=4 10개를 별도 계산에 대조했습니다. 임의 p값 fixture 8개는 별도 알고리즘의 검증이며 엔진 공개 API 직접 시험으로 세지 않습니다.
- 실제 Chrome 회귀검사 43개 통과. 실제 모델 호출과 화면 렌더, 50,000행·50,001행 경계, 원자료 미전송, 저장·공유·변경 무효화를 포함합니다. 주입한 연결 실패는 실제 모델 성공/실패 횟수로 세지 않습니다.
- 선택한 로컬 서버·전송·출력 보호 검사 16개 통과. CLI가 없는 별도 서버의 실제 503 응답도 확인했습니다. 이를 전체 보안 인증으로 부르지 않습니다.
- 합성 보고서는 실제 PDF 2쪽이며, 추출한 최소 글자 크기 12pt입니다.

자동화된 합성 입력 시험은 실제 고객 실험·사람의 사용성 시험·현장 성과·독립된 사람의 통계 심사를 대신하지 않습니다. GitHub 반영과 서비스 게시는 이 로컬 제작에 포함하지 않았습니다.
