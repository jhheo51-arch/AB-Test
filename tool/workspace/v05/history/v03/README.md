## 이번에 바꾼 것

토스 공개 디자인 설명의 명확한 위계·짧은 행동 문구·일관된 의미별 스타일을 참고하되, 작업실에 맞는 독자 화면으로 구현했습니다. 토스 공식 제품이나 TDS 적용 제품이 아닙니다.

- 차가운 중립 배경, 흰 작업 영역, 파란 주요 행동으로 재구성.
- 입력을 왼쪽, 선택적 실험 메모를 오른쪽에 배치. 작은 화면에서는 입력부터 표시.
- 한글 가독성을 위해 Pretendard Variable v1.3.9를 로컬 번들. 실행 중 외부 폰트 호출 없음.
- 결과를 큰 비율 숫자·정렬된 근거 목록·별도 해석으로 분리.
- 결과 상단에 실제로 동작하는 ‘판단 정리하기’ 버튼 추가.
- 합성 출처·추론 제한·전송 동의를 유지하면서 반복 요약을 시각적으로 정리.
- 입력 확인·오류·저장·복원·공유·실제 AI 설명과 PDF 기능 유지.

계산 엔진 `engine.js`와 `worker.js`는 v0.2와 동일합니다. 파일·개인 행은 브라우저에서 처리하며, LLM에는 동의한 판정 상태만 전송합니다. 자유 자연어 설계는 여전히 규칙 기반 안내입니다. 상세 수학 계약은 `INPUT_DECISION_CONTRACT.md`, 기존 구현 설명과 검증은 `history/v02/`를 참고하세요. 이전 문서의 녹색 팔레트는 현재 화면이 아니라 이전 버전 기록입니다.

## 실제 적용 파일

- `index.html`: 작업 화면·문구·상단 행동
- `theme-v03.css`: 현재 디자인. `styles.css`는 이전 버전 호환 파일이며 현재 화면에서는 로드하지 않음.
- `fonts/`: Pretendard Variable 및 SIL Open Font License
- `DESIGN_REVIEW_v03.md`: 참고 근거, 전→후 토큰, 대비·시각 점검
- `BROWSER_VERIFICATION.json`: 새 화면의 실제 Chrome 회귀검사
- `UI_VERIFICATION_v03.json`: 최종 시각·반응형·동작 점검과 파일 해시
