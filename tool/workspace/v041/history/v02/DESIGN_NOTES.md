# 화면·토큰 검토 기록

## 목적과 근거

주요 행동은 **입력 오류와 추론 조건을 확인한 뒤 전체·집단 결과를 해석하고 판단 기록으로 옮기는 것**입니다. Configure를 중심으로 Compare를 연결했습니다. 마케팅 랜딩·실적 대시보드가 아닙니다.

색은 회사 브랜드에서 추출한 사실이 아니라, 앞선 v0.1에서 제안·계산한 팔레트를 현재 `styles.css`에 이어 쓴 제안입니다. 글꼴과 간격도 제품 제안이며 최종 확정은 사용자에게 있습니다. Open Design 등록·게시를 하지 않았습니다.

## 정보 위계·문구·상호작용·간격

- 결론 → 전체 수치 → 집단·직접 차이 → 상세 방법 순서입니다. 원래 p값·조정 p값·명목 구간을 분리했습니다.
- 합성 예시/사용자 CSV/복원 집계의 출처 배지를 유지합니다. 규칙 설명과 실제 모델 설명을 구분합니다.
- 입력·조건 수정은 이전 결과를 무효화합니다. 새 파일·표는 이전 합성 예시의 설계 확인을 넘겨받지 않습니다.
- 공유 전에 별도 확인을 요구하고, 집단 상세를 기본 제외합니다. 제외할 때 숨겨진 가족 JSON의 집단별 p값까지 제거합니다.
- 1440px와 390px 실제 Chrome 화면을 캡처해 확인했습니다. 전역 가로 넘침과 겹침이 없었으며 모바일 표는 내부에서 스크롤합니다. 전체화면 지표가 가독성을 증명하는 것은 아니므로 결과 상단 크롭도 눈으로 확인했습니다.
- 남은 개선 기회: 결론이 제목·요약·설명에 반복되고 모바일 화면이 길어집니다. 현재는 근거와 전송 미리보기를 우선 보존했으며, 실제 사용자 시험에서 접기 기본값과 설명 길이를 검토할 수 있습니다. 오류 설명 일부는 영문 코드·문장입니다.

## 실제 대비 도구 결과

`mira_contrast_matrix`로 계산했습니다. 본문은 AA 4.5:1, 큰 글자는 AA 3:1 기준입니다.

|글자/배경|흰 표면|페이지 배경|보조 표면|
|---|---:|---:|---:|
|본문 `#24342D`|13.09:1|12.02:1|11.22:1|
|보조 `#4D5B55`|7.14:1|6.55:1|6.12:1|
|경고 `#7D3F13`|8.10:1|7.43:1|6.94:1|
|주색 `#245D49`|7.67:1|7.04:1|6.58:1|

이 12개 본문 조합과 흰 글자/주 버튼 7.67:1, 흰 글자/hover `#24342D` 13.09:1까지 **본문 조합 14개 모두 AA 통과**, 큰 글자 AA도 통과했습니다. 대비를 맞추기 위한 색 조정은 없었습니다.

경계 `#7A8780`은 흰색/페이지/보조 표면에서 3.75:1 / 3.44:1 / 3.21:1로 UI 기준을 통과하지만 본문 AA는 실패합니다. 이를 본문에 사용한 실패로 계산하지 않습니다. `#D1D8D2`는 장식 구분선이며 활성 입력의 유일한 경계로 쓰지 않습니다.

## 선택의 이유 — 세 줄

1. 실제 결과가 있는 사용자가 긴 계획 마법사 없이 표·파일부터 검토하도록 배치했습니다.
2. 색보다 결론·수치·한계의 순서와 문구로 상태를 설명해 관측상 1위와 통계·적용 판단을 나눴습니다.
3. 원자료 계산과 모델 설명을 분리하고 전송·공유 확인을 두어, 편리함이 근거 또는 동의의 생략으로 바뀌지 않게 했습니다.

## 재확인할 상태

정상 집계·개인 행, 오류·미성숙·누락, 사후 집단, 조건 미확인, 수정 후 재계산, 모델 성공/실패, 공유 제외/포함, 390px 및 실제 인쇄 PDF를 별도 확인합니다. 실제 최종 시험 수와 결과는 `BROWSER_VERIFICATION.json` 및 `VERIFICATION.json`을 우선합니다. 대비 계산·시각 점검은 전체 접근성이나 실제 사람의 사용성을 인증하지 않습니다.
