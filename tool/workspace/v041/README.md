# CRM A/B 테스트 작업실 v0.4.1

실행 가능한 로컬 개발 스냅샷입니다. CRM 전체 운영·발송이 아니라 A/B 테스트의 입력 검증, 계산, 결과 설명과 판단 기록에 집중합니다. 최종 제품 인증 또는 ZIP 배포 완료 표시는 아닙니다.

## 실행

1. 이 저장소를 내려받아 이 폴더의 `launch.cmd`를 실행합니다(Windows + Python 3 필요).
2. 또는 터미널에서 `python launch.py`를 실행합니다.
3. 출력된 `http://127.0.0.1:포트`를 브라우저에서 열고 실행 창을 유지합니다.

`index.html` 더블클릭으로 실행하지 마세요. Worker와 로컬 설명 브리지가 필요합니다. 분석에는 Node가 필요 없고 회귀시험에는 Node, Playwright, Chrome, PDF 검사 패키지가 필요합니다. LLM은 기존 Hermes `mira` 프로필의 연결을 사용합니다. 해당 환경·인증이 없으면 설명 연결이 실패할 수 있으며 계산 결과는 유지합니다. 인증 파일·토큰은 이 저장소에 포함하지 않습니다.

## 현재 가능한 일

- CSV/표/정해진 자연문장 형식 입력 → 행 검증 → 집계 → 사용자 조건 확인 → 전체·지원 집단 분석.
- Fisher 양측 검정, Wilson/Newcombe 명목 구간, 계획된 가족의 Holm 보정. 보류는 무효과·동등·안전의 증명이 아닙니다.
- A/B 설명·지표·관측 기간·대상·목적과 로컬 이유 설명을 결과/HTML/PDF에 연결.
- 계획·집계의 JSON 저장/복원, 검토한 읽기 전용 보고서 공유.
- 별도 동의와 버튼 요청 후 최소 판정 상태를 실제 LLM으로 설명. 수치 계산은 LLM이 하지 않습니다.

자유로운 상황 설명에서 후보와 계획을 생성하는 전체 대화 제품은 아직 완성되지 않았습니다. 현재 계획 안내는 규칙 기반이며 임의의 CSV 열 매핑, CRM 발송·연동, 시간·금액·순차·군집 실험 분석은 제공하지 않습니다.

## 이번 수정: 기존 감사 W01~W04

| 이전 문제 | 수정 |
|---|---|
| 늦은 파일이 새 표를 덮음 | 파일·표·형식·복원에 공통 입력 epoch와 작업 소유권 적용 |
| 입력 수정 후 옛 보고서가 인쇄됨 | 변경 시 인쇄 DOM/공유 확인 폐기. 브라우저 인쇄 직전 현재 승인 상태로 재생성 |
| 해시 중 수정 후 확인 버튼 잠김 | 해시도 입력 작업으로 관리. 오래된 finally가 새 작업을 해제하지 못하도록 보호 |
| 자체 저장 JSON이 복원에서 거절됨 | `project-schema.js`의 같은 검증/직렬화 계약을 저장·복원에 사용 |

새 입력이나 설명 편집은 진행 중인 입력 작업을 취소합니다. 필요하면 파일을 다시 선택하고 입력 확인을 누르세요. 파일 선택 값은 즉시 초기화해 취소 후 같은 파일을 다시 선택할 수 있습니다. Worker 로딩 실패 후 재시도도 검사했습니다.

CSV는 UTF-8 2MiB/50,000행입니다. 프로젝트 JSON은 8MiB, 최대 50,000 집계 셀이며 복원할 정규 CSV도 2MiB 이하여야 합니다. 저장 가능 범위와 분석 지원 범위는 다릅니다. A/B 각각 합산 분모 200,000, 지원 집단 수 등 **추론 제한을 완화하지 않았습니다**. 긴 집단명·14셀·200,001명 경계는 저장/복원되더라도 미지원 추론을 생성하지 않습니다. 프로젝트 형식 2/3을 읽고 3으로 저장합니다. 새 경계 파일은 구버전 앱에서 거절될 수 있으므로 이 수정본으로 복원하세요.
